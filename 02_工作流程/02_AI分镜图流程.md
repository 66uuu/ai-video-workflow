# 02 · AI 分镜图流程（关键帧生成）

> 分镜图 = 每一个镜头的第一帧。
> 它不是"插图"，是这镜视频的**起点和约束**。I2V 只能在这个构图里动，所以分镜图画错，视频一定错。

---

## 一、本机生图的真实能力

| 项 | 值 |
|---|---|
| 底座模型 | `majicmixRealistic_v7`（SD1.5，2.0GB） |
| 保人物一致 | `IPAdapter Plus` + `CLIP-ViT-H-14` |
| 采样器 | `dpmpp_2m` / `karras` |
| 默认尺寸 | 768×1152（竖屏 2:3） |
| 步数 | 26–28 |
| 单张耗时 | **约 8 秒** |
| 提示词语言 | **英文**（SD1.5 的文本编码器是 CLIP，中文效果差） |

**注意和 I2V 的区别**：生图用英文提示词，I2V 用中文提示词（Wan 用的是 umt5 中文编码器）。这是两套编码器，别混。

---

## 二、三种生图模式

### 模式 A：`t2i` 纯文生图

用在**从零新建**：新角色第一张锚点、新场景主视觉。

```json
{
  "id": "A01",
  "mode": "t2i",
  "prompt": "long empty night road, wet asphalt reflecting sodium streetlights, low fog, photorealistic, soft natural daylight, high detail, no people",
  "width": 512, "height": 768, "steps": 28, "seed": 20261018
}
```

风险：**脸不可控**。所以 t2i 只用于不需要脸的东西（场景、道具、背影）。

### 模式 B：`ref` 挂参考图（主力）

用在**一切有人的镜头**。挂角色锚点，改动只发生在表情、姿态、场景。

```json
{
  "id": "S13",
  "mode": "ref",
  "ref": "E:/灵异悬疑短剧_资产包/04_提示词/_资产锁定/M_LINYAN_面部锚点_v01.png",
  "ref_weight": 0.5,
  "prompt": "1girl, late 20s, black wavy short hair, tired eyes, photorealistic, soft natural daylight, high detail, standing in dim archive room, rows of metal filing cabinets, upper body, looking down",
  "width": 512, "height": 768, "steps": 26, "seed": 20261018
}
```

### 模式 C：场景续图

挂**同一场景的已出图**，`ref_weight` 拉高到 0.7–0.8，只换机位和人物位置。

---

## 三、`ref_weight` 分级表（实测，别凭感觉调）

| 用途 | 权重 | 实测效果 |
|---|---|---|
| 保脸 + **换场景** | **0.45–0.55** | 脸像，场景听话 |
| 保脸 + 同场景换机位 | 0.70–0.80 | 场景和脸都稳，机位变化受限 |
| 只改表情（构图不变） | 0.85–0.90 | 表情变，构图锁死 |
| 从零试风格 | 不用参考图 | — |

**踩过的坑**：S13 要"档案库里的林砚"，权重给 0.8，出来的是**雨夜街头**——参考图把整个场景一起搬过来了。降到 0.5 才对。

一句话：**权重的本质是"我把多少决定权交给参考图"**。换场景就是要把场景的决定权收回来。

## 四、提示词结构（四段，无固定风格）

**本版已移除「风格锚」层。** 不再有任何全剧固定的画风/色调，风格由每条提示词自己决定。

```
第一段｜不变量      （脸/发/瞳/标记，只写角色卡里有的）
第二段｜服装变量    （这一场穿什么）
第三段｜动作/表情   （这一镜在干什么）
第四段｜环境与镜头  （地点/光线/景别/机位，可选）
```

### 关于风格（重要变更）

旧版要求第一层原样复制"暗色电影感厚涂 / 低照度 / 蓝绿冷调"的英文锚。**该要求已废除**，因为它会让所有镜头不分剧情一律变暗变灰。

现在：
- 想要什么画风，就在提示词里直接写（写实、插画、3D、明亮、高饱和都行）。
- 不写也不会出错，模型按内容自行决定。
- **不再有"必须统一"的美术约束。** 同一部片子里不同镜头用不同风格，也是允许的。

### 第一段 · 不变量（林砚示例）

```
1girl, late 20s, black slightly wavy short hair, shoulder length,
pale skin, dark circles under eyes,
small 1cm pale scar at right eyebrow tail,
thin light-colored wristband on right wrist
```

**只写角色卡里有的。** 不要临时加"高鼻梁""鹅蛋脸"这类词——每加一个词，模型就往另一个方向偏一点，30 个镜头积累下来就是换人。

### 第二段 · 服装变量

```
olive-grey beige trench coat over dark sweater, dark trousers
```

服装必须是**变量**，因为它每集可能不一样。写死在不变量里，换装就得重出所有资产。

### 第三段 · 动作/表情

```
upper body, looking down at hands, lips slightly parted, exhausted expression
```

**一镜一个动作。** 写两个动作（"抬头并且转身"），静态图会出成扭曲的中间态。

### 第五层 · 环境与镜头

```
dim archive room, rows of grey metal filing cabinets,
single overhead fluorescent light, dust in air,
medium shot, 50mm, shallow depth of field
```

## 五、任务单 `IMAGES.json` 完整格式

```json
{
  "_说明": "本地生图任务单",
  "jobs": [
    {
      "id": "唯一编码（会进文件名，不能重复）",
      "mode": "t2i | ref",
      "ref": "mode=ref 时必填，参考图绝对路径（正斜杠）",
      "ref_weight": 0.5,
      "prompt": "英文提示词，五层用逗号连起来",
      "negative": "可选，不填用默认",
      "width": 512,
      "height": 768,
      "steps": 26,
      "seed": 20261018
    }
  ]
}
```

### 默认负向词（`gen_image.py` 内置）

```
lowres, bad anatomy, bad hands, text, watermark, signature,
extra limbs, deformed, blurry, ugly, worst quality, jpeg artifacts
```

**负向词不能写"没有 X"。** 实测写 `no ink, clean paper` 结果墨迹真的消失了——负向词里的 `no` 被读成"不要"。要排除某物，用它的正向反义词（`blank, empty`），不要用否定句式。

---

## 六、编码法：防止并行出图互相覆盖

**铁律**：`id` 必须是全局唯一编码，并且**写在提示词最前面**。

原因：并行出图时同秒完成的图会互相覆盖，而 PNG 内不含提示词元数据，被覆盖的图**无法分辨是哪张，只能作废重做**。

做法：

```json
{ "id": "S13", "prompt": "【S13】1girl, late 20s, ..." }
```

工具会用提示词开头的编码推导文件名 → 落盘即 `_S13__xxx.png`，永不撞名且一眼可辨。

**不要依赖 `output_dir` 隔离** —— 并行时会被串掉，实测全落进同一个目录。

## 七、出图之后必做的三件事

### 1. 去水印 / 去文字

AI 出图带水印或乱码中文时，走 `buddy-image-processing` 的 `erase`。

**关键坑**：erase 的输出名是**随机哈希** `processed_image_<hash>.png`，与输入名无关。所以：
- **必须串行执行**，跑完按 `ls -tr`（修改时间升序）排序，顺序即输入顺序，再批量重命名
- 并发跑会破坏对应关系
- 单张约 40 秒

### 2. 中文一律留白（这是设计要求，不是缺陷）

画面里有中文的地方，生图阶段要求**留空**，出来之后人工贴字。

不能用"让 AI 画字"这个方案。AI 出中文一定是乱码，而且乱码在竖屏特写下极其明显。

本剧留白清单：寻人启事 / 里程 / 计价器 / 仪表灯位 / 站牌「13路」/ 涂鸦 / 讣告 / 笔记本字迹 / 录音笔时长。

### 3. 验收：与锚点是同一张脸

肉眼看，不用工具。**"差不多"就是不合格**，重出。

## 八、已知的能力边界（省你反复试的时间）

| 边界 | 现象 | 对策 |
|---|---|---|
| 精确道具交互差 | 要"双手拿着一张旧照片"，两轮都画不出照片 | 不硬要，改导演方案 |
| 风格与商业模型不同源 | 已锁资产是厚涂剧漫，本地是 3D 半写实，**调不平** | 二选一：接受本地风格重出 / 关键帧继续走云端 |
| "不给脸"角色出不了正面 | 负向词对"三视图正面板"完全无效（连测 8 候选全翻车） | 改**背面系三视图**（见下） |
| 中文必乱码 | — | 留白 + 后期贴字 |

### "不给脸"角色的特例解法

本剧小满（全剧 0 次露眼）、白先生（白西装但看不清脸）就是这类。标准正面三视图对它们**完全失效**。

唯一解法：**背面系三视图 + 伞撑开举过头顶遮脸**。

- 三视图内容改成：背面 / 四分之三背面 / 侧面
- 伞顶必须写到明确高度："**伞面完全遮住头部**"
- 写"挡胸口到下颌"＝伞顶只到下巴，脸全露，重出

而且**降 `input_fidelity` 也没用**：背面锚点 + `high` 只能出背面，降到 `medium` 仍出背面。稳定输出的边界就是设定的边界，别追打。

## 九、一条命令跑完

```bat
双击 09_工具脚本\一键生图.bat
```

或手动：

```bat
源机器E盘ComfyUI\venv\Scripts\python.exe gen_image.py --jobs "IMAGES.json" --desktop
```

单张试：

```bat
源机器E盘ComfyUI\venv\Scripts\python.exe gen_image.py ^
  --prompt "【TEST】1girl, portrait, photorealistic, soft natural daylight, ..." ^
  --ref "E:/.../M_LINYAN_面部锚点_v01.png" ^
  --ref-weight 0.5 --width 512 --height 768 --desktop
```

出图落 `04_提示词/_本地生图/日期/`，加 `--desktop` 会同时复制到桌面。
