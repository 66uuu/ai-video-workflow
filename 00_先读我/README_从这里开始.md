## 三十秒看懂这套工具能干什么

```
剧本 → 分镜 → 时间轴(帧级) → 关键帧(SD1.5) → I2V(Wan2.2) → 质检 → 配音 → 合成 → 交付
```

全本机生成，零外部额度。AI 做"翻译"（把意图翻成提示词、帧数、验收标准），本机 GPU 做"执行"。

## 怎么继续干（最短路径）

### 第 0 步：确认机器能跑

```powershell
ComfyUI\venv\Scripts\python.exe "11_本地工具接入指南\bridge\selfcheck.py"
```

它会告诉你 ComfyUI 在不在、模型缺不缺。要手动起服务：`ComfyUI\启动.bat`，浏览器打开 `http://127.0.0.1:8188`。

### 第 1 步：要出图

1. 编一份任务单 JSON（格式见 `02_工作流程/02_AI分镜图流程.md`）
2. 指定输出目录：`$env:IMG_OUT_ROOT="<仓库外的目录>"`
3. 跑 `09_工具脚本/gen_image.py`（或双击 `一键生图.bat`）

### 第 2 步：要出视频

1. 首帧 PNG 放在仓库外
2. 任务条目写清提示词与帧数（`00_通用工作链/01_命令手册.md` 有字段说明）
3. 跑 `batch_local.py --submit-only`，再 `--collect`
4. 可以关掉，ComfyUI 自己排队跑完（队列独立于脚本）

### 第 3 步：要成片

`assemble_ep04.py` 收片 + 统一规格 + 拼接，输出到仓库外。

## 三条必须记住的红线

**1. 帧数必须是 4n+1**
Wan2.2 的硬要求。要 60 帧就传 61 帧，出片后用 ffmpeg 裁回 60。脚本已自动做（`gen_len()`），**手改帧数时别忘**。

**2. 提示词里不许写长相、服装、姓名**
参考图（首帧）已经给了这些信息，文字再写一遍会跟图打架，结果就是换脸。同理不写画风、不写第二个运镜。

**3. 一次只写一个能在几秒内做完的动作**
"走过整个画面"会让人物出画，只剩空景。"肩膀擦过画面边缘、在右三分之一处停住"才对。
