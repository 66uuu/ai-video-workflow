| 路径 | 内容 |
|---|---|

**核心概念**：段（≤15s）→ 切（2–5s）→ 分镜图（每切一张，主图钉 0.00s）。

## 14_无限画布分镜看板（可选）

基于 tldraw（GitHub 最流行的开源无限画布项目）的分镜/时间轴可视化看板，本地离线跑。

| 文件 | 内容 |
|---|---|
| `README.md` | 启动方式、数据源、安全边界 |
| `启动.bat` | 一键启动（首次自动 npm install + build） |
| `server.py` | 零依赖本地服务：静态页 + 读时间轴 JSON + 按镜号匹配首帧图 |
| `frontend/` | Vite + React + tldraw 源码（自定义分镜卡片 shape） |

**用法**：双击 `启动.bat` → 浏览器打开 → 左侧「扫描」列出成果区的 `*timeline*` JSON → 点一个渲染成卡片看板。
**定位**：只做可视化，不回写 JSON、不影响出片链路。
