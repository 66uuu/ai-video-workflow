# AI生成视频专项技能库

本目录是 `AI生成视频` 技能包的专项能力层，来源为桌面上的 `skills` 文件夹。

## 目录约定

- `原始技能库/`：技能包的只读融合副本，保留原目录结构；
- `技能索引.json`：机器可读索引，记录名称、分类、路径、描述和文件哈希；
- `技能索引.md`：人类可读的分类速查；
- `skill_router.py`：按任务关键词检索最适合的专项技能；
- `调用专项技能.ps1`：Windows 快速调用入口。

原始 `你的桌面\skills` 保留不动。本目录是视频工作流的调用副本，不改变原技能包。

## 使用方法

在本目录执行：

```powershell
python skill_router.py search "人物一致性 图生视频"
python skill_router.py search "产品广告 TVC" --video-only
python skill_router.py show "角色一致性引擎"
python skill_router.py rebuild
```

返回结果后，先读取匹配技能的 `SKILL.md`，再根据该技能的输入要求执行。不能因为名称命中就把多个技能的规则混在一起；一个任务先确定主技能，再按需调用辅助技能。

## 路由规则

1. 先判断任务类型：脚本、分镜、人物、场景、风格、广告、电商、图生视频、声音或后期。
2. 主技能只选一个；辅助技能一般不超过三个。
3. 先读 `SKILL.md`，再读该技能引用的 `references/`、`modules/` 或模板。
4. 技能只负责方法和提示词规则，实际图片、视频、日志和成果仍写入桌面 `AI产物\\YYYYMMDD_任务名`，不写回技能包。
5. 任务完成后记录实际调用的技能名称、版本/哈希、输入和输出路径，便于复盘。

## 分类

索引器会按名称和元数据自动归类：

- `脚本与分镜`
- `导演与镜头`
- `人物与资产`
- `视觉风格与场景`
- `广告与电商`
- `动画与漫剧`
- `声音与后期`
- `视频通用`
- `其他待确认`

分类是检索辅助，不是对技能内容的权威判断；使用前仍必须读取技能正文。
