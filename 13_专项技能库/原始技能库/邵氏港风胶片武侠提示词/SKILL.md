# 邵氏港风胶片武侠 · 人物/场景提示词生成

把 1960–80 年代邵氏胶片武侠的视觉审美固化成提示词工艺：换题材、换比例，风格锚点不许丢。

默认目标模型为 **Style Image 8.2**：它不解析 Midjourney 式 `--` 参数，因此全部控制项（画幅、风格倾向）都必须用自然语言写进提示词正文。

两条风格路线，一次只用一条：

- **路线 A · 邵氏年代感**（默认）：浓色棚拍、压暗部、戏剧光。
- **路线 B · 现代审美古风**：胶片质感照留，但光影与色彩改走明亮清透、低饱和，妆造五官与气质都走现代审美。

## 一、什么时候用

用户想要一张胶片武侠质感的人物图或场景图，且希望先拿到一段可直接投喂给指定模型、指定比例的高质量提示词时。也适用于用户直接说“随机来几张”“随便给我出几个人物/场景”的情况（见第五节）。

## 二、输入槽位（可替换，缺哪个问哪个）

| 槽位 | 内容 | 缺省 |
|---|---|---|
| 主体类型 | 人物 / 场景 | 人物 |
| 主体描述 | 人物：身份、性别、年龄区间、造型、动势、持械；场景：空间、标志性元素 | 必填，缺就问；用户明确要求随机时改由第五节的随机池抽取 |
| 风格路线 | 邵氏年代感（路线 A）/ 现代审美古风（路线 B） | 路线 A |
| 目标模型 | 写进节点 `ai_model` | Style Image 8.2 |
| 画面比例 | 写进节点 `aspect_ratio`，并在提示词正文里用自然语言说明画幅 | 16:9 |
| 提示词语言 | 中文 / 英文 | 英文（Style Image 8.2 用英文关键词更稳） |
| 气质分支（可选） | 路线 A：胡金铨文人禅意 / 张彻阳刚惨烈 / 楚原悬疑奇情 / 刘家良硬派洪拳；路线 B：清透飘逸 / 疏离静谧 / 明净疏朗 | 路线 A：通用邵氏武侠；路线 B：清透飘逸 |
| 变体数量（仅随机模式） | 一次生成几条互不重复的提示词 | 3 |
| 飘絮（可选） | 柳絮 / 花瓣 / 落叶等虚化飘絮，可要可不要 | 随机模式下由第五节飘絮池决定 |

只要某个槽位会影响提示词写法（尤其是主体描述与风格路线）而用户没说、也不算随机请求，就先问一句，不要替用户拍板。

## 三、风格锚点

### 3.1 两条路线共有的锚点（都必须落到提示词里）

1. **胶片质感**：35mm 粗颗粒、高光 halation 泛红光晕、四角暗角、做旧划痕与褪色，保留未修片的粗粝感（用 `raw filmic look` 一类自然语言写，不用 `--style raw`）。**两条路线都不许丢。**
2. **场景与搭景感**：片场搭景的手工味（透视略假）、飞檐酒楼、客栈长街、青砖墙、布幡、雾气造纵深。灯笼在两路线中用法不同，见 3.2 / 3.3。
3. **动作**：硬桥硬马、刀光剑影、威亚轻功、风格化浓红血、尘土落叶水花。
4. **镜头构图**：舞台感对称中轴、人物居中、全景为主、推拉摇移带机械感、片头书法大字。
5. **年龄措辞（安全要求，两路线通用）**：所有年轻角色一律写明成年——英文用 `young adult man` / `young adult woman`（或 `adult man` / `adult woman`），中文写「成年男子 / 成年女子」。**禁止** `youth`、`young noble`、`youthful`、`teen`、`girl`、`boy`、`少年`、`少女`、`孩童` 等年龄模糊或暗示未成年的词。只写成年人物时也要确保句中没有残留年龄模糊词。
6. **总纲（路线 A）**：朱砂与墨绿的浓色棚拍世界里，35mm 颗粒裹着烟雾与刀光，侠客衣袂翻飞，在一方手工搭出的江湖中硬桥硬马地见生死。

### 3.2 路线 A · 邵氏年代感

- **色彩**：朱砂红 / 墨绿 / 鎏金黄 + 深褐墨黑暗部；高饱和、低明度。口诀：暗部压死、红色发艳、金色泛旧。
- **光影**：棚拍戏剧光、烟雾中的丁达尔光束、大面积阴影切脸、红灯笼与烛火作画内光源。
- **人物造型与妆造**：交领长衫、束发或高束长发、斗笠披风、玄黑藏青朱红重色，衣袂与广袖被风掀起；面部浓眉硬朗，男角带汗光（不写任何美妆措辞），女角苍白瓷肌配红唇。
- **可选气质分支**：胡金铨文人禅意 / 张彻阳刚惨烈 / 楚原悬疑奇情 / 刘家良硬派洪拳。

### 3.3 路线 B · 现代审美古风

- **色彩**：明亮清透、低饱和；色相仍偏红 / 绿 / 金一路，但全部柔化（绛色柔化、黛青、月白、淡金），保留中间调层次。**不做暗部压死，不做红色发艳**，也不要金箔般的旧金。
- **光影**：明亮清透的柔光与天光为主——窗光、晨昏斜光、匀净环境光、雾中逆光；阴影干净通透、层次可读，**不做大面积阴影切脸**。**不用红灯笼与烛火作画内光源**：灯笼只作静物陈设，不承担照明；需要光源时用天光、窗光或月光。
- **造型**：古风形制保留（交领、广袖长袍、束发或半束长发），但剪裁当代化、以飘逸为主诉求——层叠衣襟、纱 / 缎 / 细麻等轻盈垂感面料、软带束腰而不绷紧、长披帛与飘带随动飞举、衣摆与发丝被风整片扬起（静止站姿也要有布料受力）。**飘逸必须来自实体布料与风的物理关系，不许靠发光特效、悬浮粒子、仙气光晕。**
- **面部妆造与五官（按性别分开写，不许混用）**：
  - **女性角色**：干净通透的底妆、自然眉形、清透眼妆、低饱和唇色（豆沙 / 裸粉）、轮廓精致立体、无油光与汗光、发丝清爽有层次。可用美妆类措辞，如 `clean light makeup`、`soft muted lip color`。仍**不做浓艳舞台妆，不做苍白瓷肌配艳红唇**。
  - **男性角色**：**只写「干净通透的肤色 + 自然眉形 + 自然唇色 + 清晰的成人面部轮廓 + 无油光汗光 + 干净利落的发丝」**，英文如 `clean clear skin tone, natural eyebrows, natural lip color, defined adult facial structure, no shine`。
  - **男性角色禁用女性化美妆措辞**：不得出现 `makeup`、`cosmetics`、`nude lips`、`lipstick`、`eyeshadow`、`blush`、`eyeliner`、`foundation`、`beautified` 等词，也不得写“妆容精致 / 眼妆 / 腮红 / 唇妆”。
- **可选气质分支（现代审美古风气质）**：
  - **清透飘逸**：轻盈、通透、衣袂与发丝带动势，人物像被风托着；眼神清亮疏朗，动作轻而不僵。画面无血腥、无尘土暴土，飘絮与拂动为主要动态。
  - **疏离静谧**：静、冷、远。人物少动作、多留白（负手、侧立、回眸半张脸），眼神望向画外的空处，情绪压住不外放；空间大而人小。
  - **明净疏朗**：干净、透气、有暖意。天光做主光，色调匀净，人物神色平和从容；可带一丝沉静的叙事（等一个人、看一场雨停）。
  - 三者都强调**当代审美的克制感**：不做癫狂、惨烈、滥血与过火表演，也不做现代都市气或时装感；血与暴力只在用户明确要求时才出现，且克制处理。
- **总纲（路线 B）**：明亮清透的低饱和世界里，35mm 颗粒与暗角仍在，柔光裹着薄雾与衣袂，侠客长发飘举，一方搭景江湖里静静立着一个人。

### 3.4 路线边界（不许混用）

- 路线 A 允许压暗、发艳、切脸与灯笼烛火；**不得掺入现代妆造、清透调与飘逸时装化剪裁**。
- 路线 B 允许明亮清透与飘逸；**不得出现暗部压死、红色发艳、大面积阴影切脸、红灯笼或烛火作画内光源**，也不得把妆造写回浓眉汗光与瓷肌艳唇。
- **气质分支与路线绑定**：路线 A 的四类分支（禅意 / 惨烈 / 悬疑奇情 / 硬派）不得用在路线 B；路线 B 的三类气质分支（清透飘逸 / 疏离静谧 / 明净疏朗）不得用在路线 A。用户只给气质分支时，按其归属确定路线：给了「清透飘逸 / 疏离静谧 / 明净疏朗」即走路线 B，给了禅意 / 惨烈 / 悬疑奇情 / 硬派即走路线 A；两者都不给时按缺省路线 A。
- **年龄与妆造安全边界（两路线通用）**：年轻角色一律用 `young adult man` / `young adult woman` 或「成年男子 / 成年女子」，不留任何年龄模糊词（见 3.1 第 5 条）；男性角色在任何路线下都不写女性化美妆措辞。这两条是硬底线，用户要求也不能放宽。
- 两条路线都仍是古风体系：不出现西装、机车服、牛仔、时装秀造型、当代发型打理。
- 两条路线都保留 35mm 颗粒、halation、暗角、划痕与褪色。

## 四、提示词配方（段落顺序固定）

1. **画幅段**：用自然语言写画幅与构图倾向，英文如 `16:9 widescreen cinematic framing, horizontal composition`，中文如「16:9 宽画幅电影构图」。**禁止**写成 `--ar 16:9`。
2. **主体段**：主体类型 + 主体描述 + 年龄（成年措辞）+ 气质分支 + 动势/持械。**场景主体默认无兵器**：不写任何器械，只写空间、氛围与一个叙事焦点。
3. **造型段**：服饰材质与颜色、发型、鞋或披风、被风掀起的衣袂。路线 B 在此写入层叠衣襟、轻盈面料、飘带披帛与发丝扬起的飘逸细节（见 3.3）。
4. **面容与光影段**：按路线二选一——A：半脸隐入阴影 + 暖灯笼光落在轮廓 + 浓眉汗光 / 瓷肌红唇；B：柔光匀净落在脸上 + 通透层次 + 按性别分的妆造写法（女：清透美妆；男：干净肤色 + 自然眉 + 自然唇色，**无美妆措辞**）。**不许把两条路线的面容写法拼在一起，也不许给男性角色写女性化妆造。**
5. **背景段**：片场感古代长街 + 布幡 + 青砖墙 + 雾 + 斜射光束；末尾追加飘絮短语（若本次有飘絮，写法见第五节）。路线 A 的斜射光束来自灯笼烛火与棚灯、可加红灯笼；路线 B 的光束来自天光窗光、灯笼只作陈设不作光源。
6. **风格串**（二选一，直接复用，不作增删以外的改写）：
   - **路线 A**：`Shaw Brothers 1970s wuxia still, 35mm film grain, halation glow, heavy vignette, faded vintage color, saturated vermilion red, gold and emerald green palette, crushed dark brown shadows, slight scratches, theatrical studio lighting, symmetrical stage-like composition, raw filmic look, cinematic, nostalgic`
   - **路线 B**：`Shaw Brothers-inspired 1970s wuxia still, 35mm film grain, halation glow, heavy vignette, slight scratches, faded vintage color, bright airy palette, low saturation, soft even daylight, clean open shadows, misty depth, symmetrical stage-like composition, raw filmic look, cinematic, nostalgic`

**场景版**：把 2–4 段合并成一段场景描写（空间 + 材质 + 光位 + 一个叙事焦点），**默认不含兵器**，焦点用无械物件，如空荡长街上的一盏将灭灯笼、风吹歪的布幡、石阶上倾倒的酒坛、雪地里一行远去脚印；画幅段、背景段与风格串不变（风格串按路线选）。若场景里有人物，同样用成年措辞。只有用户明确要求画面出现兵器时，才写入器械。

## 五、随机生成模式

**触发**：用户明确说“随机 / 随便 / 来几张不同的 / 你自己定”，或只给风格与数量、明确不指定主体时进入。此时**不要**再追问主体描述，直接从下面的池子抽签。**随机默认走路线 A**；用户说“现代审美 / 清透 / 明亮”时才整批切到路线 B（同一批不混用路线），此时气质也从路线 B 的三个分支里抽。

**抽取规则**：每个变体从各池各抽 1 项（人物类型、气质、造型重色、持械、动势、天候、场景、飘絮及飘絮位置），组装成主体段、背景段与飘絮短语；抽到的中文词按目标语言翻译/改写后填入配方。**池中带「少年 / 少女」字样的条目，写入提示词时必须改写成成年措辞**（如「提灯照夜的少女」→ `young adult woman holding a lantern`、「撑纸伞的白衫少年」→ `young adult man with a paper umbrella`）。

**抽到场景主体时**：不抽持械池、不抽动势池，主体段与叙事焦点均默认无兵器（除非用户明确要求出现兵器）；其余池照抽。

- **人物类型池（26 项）**：落魄刀客 / 冷面剑客 / 独臂侠士 / 白衣女侠 / 镖局镖师 / 江湖郎中 / 醉拳老汉 / 撑伞游侠 / 蒙面刺客 / 江湖术士 / 官差捕快 / 老拳师 / 船家女客 / 卖艺刀马旦 / 和尚武僧 / 书生剑客 / **唯美取向 10 项（女 5 / 男 5）**：月下横笛的女子 / 素衣抚琴的女子 / 提灯照夜的少女 / 拈花而立的白衣女侠 / 溪畔浣衣的素衫女子 / 撑纸伞的白衫少年 / 雪夜提灯的素袍男子 / 执卷临风的青衫书生 / 临水持箫的白衣公子 / 松下独饮的素袍男子。
- **气质池**：萧瑟孤冷 / 英气冷艳 / 沉默隐忍 / 癫狂狠戾 / 风流不羁 / 悲情决绝 / 清冷禅意 / 精悍利落 / **唯美取向 5 项**：清冷出尘 / 温婉含愁 / 如梦似幻 / 幽怨清丽 / 淡然隔世。**路线 B 下改从「清透飘逸 / 疏离静谧 / 明净疏朗」三支里抽，并与气质分支槽位保持一致。**
- **持械池**：单刀 / 双刀 / 长剑 / 短匕 / 铁尺 / 长棍 / 三节棍 / 软剑 / 铁伞 / 飞刀 / 长枪 / 空手起势。
- **动势池（10 项）**：拔刀半出鞘 / 横刀而立 / 回身劈斩 / 腾空翻跃 / 蛇形步进 / 雨中立定 / 振袖出掌 / 负手背立 / 策马 / 牵马。
- **天候与时段池**：黄昏斜光 / 夜灯火烛 / 阴雨湿砖 / 晨雾未散 / 风起落叶 / 骤雨水花 / 月色清辉 / 雪后初晴。**路线 B 下「夜灯火烛」改写为夜色清光、灯笼只作陈设。**
- **场景池**：分为两组，抽签时等权选取。
  - **江湖烟火组（10 项）**：客栈长街 / 飞檐酒楼门前 / 青砖围墙小巷 / 雨中石桥 / 竹林棚景 / 破庙大殿 / 山道关隘 / 码头栈桥 / 楼阁回廊 / 酒肆布幡下。
  - **唯美组（10 项）**：月下回廊 / 雪夜梅林 / 亭台水榭映倒影 / 残荷枯塘 / 枫林晚照 / 雾中石阶山门 / 落花小院 / 江畔芦苇荡 / 烟雨长堤 / 竹影映月窗。
- **飘絮池**：柳絮 / 花瓣 / 梧桐叶与落叶 / 细碎纸钱或香灰 / 尘雪微粒 / 无（不加飘絮）。
- **飘絮位置池**：前景 / 中景 / 远景。抽到「无」时不抽位置，本条不写飘絮短语。

**策马 / 牵马写法**：抽到策马、牵马时在主体段写人骑马或牵马的关系与马匹质感（鬃毛、鞍具、蹄下尘泥）；持械照旧可叠（如马上提刀）。马匹只作陪衬，不新增段落、不挤占风格串，仍受角色与字符上限约束。

**唯美取向项的使用**：人物类型池与气质池中的唯美项照常参与等权抽签；唯美人物男女各 5 项，抽签权重相同，避免唯美结果清一色女性。唯美项在路线 A 下按「气质 + 造型 + 光位」写柔美感，在路线 B 下自然契合清透调；但无论哪条路线，都不得靠发光特效或仙气光晕堆仙侠感，也不得写成粉调小清新或现代古风写真。**唯美项的「女子 / 少女 / 少年」等中文写法在落地时一律换成成年措辞。**

**飘絮规则**：

- 飘絮池里含「无」一项，**允许部分变体完全没有飘絮**，不强制每条都有；一批 3 条里通常 1–2 条带飘絮即可。
- 飘絮必须写成**虚化**状态：`soft-focus drifting {柳絮/花瓣/落叶}`、`hazy floating motes`、`blurred airborne particles` 一类自然语言。
- **抽到前景时，必须同时写明虚化程度**，例如 `heavily blurred out-of-focus {飘絮} drifting across the foreground, soft bokeh, shallow depth of field`；禁止写“清晰的前景飘絮”。若想拍清飘絮形态，只能放中景或远景。
- 飘絮只作氛围，不许抢主体：不得遮挡面部与刀光落点，不得写成需要主体“去抓/去接”的情节焦点。
- 飘絮短语写在背景段末尾，不新增段落，不挤占风格串。

**随机模式的额外要求**：

- 一次默认出 3 条变体；同一批内不得重复抽到相同的“人物类型 + 持械 + 场景”组合（场景变体与飘絮不参与该唯一性判定），人物与场景可混排（除非用户指定只要人物或只要场景）。
- 随机只作用于内容，不放松工艺：风格锚点、配方段落顺序、画幅段写法、字符上限全部照旧。
- 池外元素一律不许引入：现代服装、科幻、东洋、欧美元素不出现在随机结果里；超出池子的需求按普通模式向用户确认。
- 用户可叠加限制（如“只要女侠”“只要唯美人物”“都在夜里”“只要唯美场景”“不要飘絮”“飘絮只在前景”“场景里要有兵器”“走现代审美路线、造型要飘逸、气质清透飘逸”），叠加时在该池的剩余项里抽；只说“唯美人物”时，男女唯美项一起抽。

## 六、硬性约束

- **字符数 ≤ 1000**（含画幅段、飘絮短语与风格串），逐条自己数一遍；超了先砍主体段的形容词，再砍背景枚举，最后砍飘絮短语，风格串不动。随机模式下每条独立计算。路线 B 的飘逸与妆造描写优先用短语而非整句。
- **年龄措辞是硬底线**：所有年轻角色一律写 `young adult man` / `young adult woman` 或「成年男子 / 成年女子」；全文不得出现 `youth`、`young noble`、`youthful`、`teen`、`girl`、`boy`、`少年`、`少女` 等词。用户要求也不能放宽。
- **男性角色不写女性化美妆措辞**（硬底线）：`makeup`、`cosmetics`、`nude lips`、`lipstick`、`eyeshadow`、`blush`、`eyeliner`、`foundation` 等词只允许用于女性角色；男性只写肤色、眉形、唇色、轮廓与发型。用户要求也不能放宽。
- **场景主体默认不出现兵器**：场景版与随机抽到的场景变体，正文里不写刀剑枪棍等器械；只有用户明确要求时才写入。
- **一次只用一条路线，且气质分支必须与路线同源**：A 路线配禅意 / 惨烈 / 悬疑奇情 / 硬派；B 路线配清透飘逸 / 疏离静谧 / 明净疏朗。两路线的光影、色彩、妆造、气质写法均不得混搭，也都必须保留 35mm 颗粒、halation、暗角、划痕与褪色。
- **路线 B 的禁项**：不写暗部压死、红色发艳、大面积阴影切脸、红灯笼或烛火作画内光源、癫狂惨烈与滥血；灯笼只作静物陈设。
- **一律不写 `--` 参数**：不出现 `--ar`、`--style`、`--v`、`--niji` 等写法（Style Image 8.2 不解析，只会被当成正文噪声）。比例改为自然语言描述，并同时写进节点 `aspect_ratio`，两处必须一致。
- 风格锚点不许因为换了题材、换了路线或随机抽取就整条消失。
- 中文提示词用于不支持英文描述的场合时，主体/造型/背景段用中文，画幅用中文自然语言，风格串保留英文关键词；中文同样遵守成年措辞与性别妆造规则。
- 换模型时：若目标模型确实支持 `--` 参数，才恢复参数段写法；否则继续走自然语言路线。

## 七、执行步骤

1. **判断补齐槽位**：若用户要求随机，跳进第五节直接抽签；否则先定风格路线与气质分支（缺就问；只给气质分支时按 3.4 反推路线），再缺主体描述/模型/比例就问，一次只问最影响写法的那一个。
2. **写提示词**：按第四节的段落顺序与对应模板填槽，守住字符上限，写完做五项自检：
   - 正文里没有任何 `--` 参数；
   - 面容段、风格串与气质分支同属一条路线；
   - 年轻角色全部写明成年，全文无 `youth / young noble / girl / boy / 少女 / 少年` 等词；
   - 若主角为男性且走路线 B，确认没有 `makeup`、`nude lips` 等女性化美妆措辞；
   - 场景主体无兵器；有飘絮时写成虚化、前景飘絮带散景描述。
3. **建或改节点**：新建用 `create_image_node`（prompt、ai_model=`Style Image 8.2`、aspect_ratio、title、tag）；在已有节点上改动用 `update_image_node`（只接受 `node_key`、`prompt`、`aspect_ratio`、`quality_spec`、`ai_model`、`prompt_template`、`resolved_params`，传 `title` 会报参数错误）。随机模式的多条变体各建一个节点。
4. **不要自行运行**：节点建好即停，把提示词展示给用户。要运行必须先发审批卡（`approve_run_node_once`，node_keys 列出即将运行的节点），用户批准后再逐个运行。
5. **反馈迭代**：用户提修改时只改点名的部分，其余逐字不动（例如只说“换成女侠 + 16:9”，就只重写主体段、面容段与画幅段，风格串与背景段原样保留）；只有用户点名换路线或换气质分支时，才同时调整面容段与风格串。随机模式下的“再换一批”视为重新抽签，只重抽被点名的池，未点名的池保持原值。
6. **被安全审核拦下时**：优先排查 3.1 第 5 条（年龄模糊词）与 3.3 男性妆造措辞，把 `young noble`、`youth`、`girl`、`boy` 等换成 `young adult man / young adult woman`，并删掉男性角色身上的 `makeup`、`nude lips`、`lipstick` 等词后重写该条；不要靠删掉整段造型或降低风格锚点来绕过。

## 八、收尾

一轮结束后向用户回报：提示词全文、字符数、使用的模型与比例、节点 node_key、**用的哪条风格路线与哪个气质分支**；随机模式下额外标明每条抽到的身份 / 气质 / 持械（场景变体写明“无兵器”）/ 动势 / 场景 / 飘絮（含位置与“本条无飘絮”），并说明与上一批不重复；涉及年轻角色时说明已用成年措辞、男性角色未使用美妆措辞；并说明本次未使用 `--` 参数、比例以自然语言 + 节点参数双处落实；询问是否需要调整或运行。
