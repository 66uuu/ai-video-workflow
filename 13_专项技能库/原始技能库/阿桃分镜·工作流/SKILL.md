# 阿桃分镜·工作流（执行层）

> 本Skill与姐妹Skill「阿桃分镜·视觉参考库」配合使用，生成视频时两个必须同时参照。

## 定位
执行层。每集生成视频时必须调用。覆盖工作流程、检查清单、提示词写作规范。

---

## 阿桃人物红线（4条，不可违反）

1. 阿桃敢爱敢恨、跳脱有劲——该哭哭，该笑笑，该闹闹，这是她的性格底色。禁止的是表演式情绪：偶像剧式捂嘴哭/泪眼汪汪示弱/没有原因地对着镜头甜笑/明显演给摄影机看的夸张动作。咧嘴大笑完全可以有，阿桃爱笑，真实情境下的咧嘴大笑就是她。阿桃的一切情绪和动作都是真实发生的，不是表演出来的。克制是她在压力下的选择，不是她的底色。
2. 眼神不直视镜头，视线看向画面内的其他人或远处
3. 台词一字不差，不概括不意译不省略
4. 淡蓝色牛仔裤（第2集起）每段提示词必写，不能丢

## 资产准备规范

- 生成顺序：场景图→道具图→角色图→分镜草图→视频
- 干净分离：场景图绝不出现人物，人物图绝不带道具
- 先盘点再补缺口：每集开始前检查锚点清单，缺什么补什么
- 按需建立：能复用的复用，能派生的派生，不能复用才新建
- 锚点拦截：涉及待确认/未生成锚点的段，禁止进入视频生成，先确认锚点转✅

## 核心工作流程（六步）

### 第一步：布景情绪分析
每个场景必做。分析布景如何服务情绪——不是简单抄布景描写，而是导演思维：布景里每样东西在说什么。

### 第二步：创作脊柱
这集的情绪弧线是什么？明线和暗线分别是什么？情绪最重的落点在哪里？

### 第三步：分镜规划

**3.1 时长预算（按角色+场景选速，不得直接套4.5）**

先判定说话角色与场景情绪，再选语速：
- 阿桃·压迫感（被拒/被推回/情绪积压）：3.2字/秒——说得更慢，每个字更重
- 配角标准对白（会计/镇男/大叔/工作人员）：4.5字/秒
- 爽点/想通/笃定节奏（阿桃）：5字/秒——节奏加快，观众跟着她走

台词字数 ÷ 对应语速 = 台词需要的秒数
台词秒数 + 动作秒数 = 这段总时长
总时长超过15秒 → 必须拆段（15秒为H3平台硬上限）

**3.2 景别规则（竖屏强制规则）**

- 竖屏景别提升一档：想要全景→写中景，想要中景→写近景，想要近景→写特写，想要特写→写极近特写
- 相邻两镜不得同档（中/近/特/极近四选，每镜跳档）
- 不用全景，95%为中景、近景、特写
- 竖屏人物填满画面宽度60%以上
- 例外：表达孤独/渺小/无人注意时，允许中远景（仍非全景），人物占画面<30%，此类镜头不强制提升一档

竖屏补充规则：
- 避免两人左右并排同时入镜，优先越肩或单人+画外音
- 优先垂直方向运动（起身/坐下/抬头/低头）而非水平运动
- 关键信息放在画面垂直中心线，不放左右边缘
- 特写镜头比横屏多停留0.5-1秒

**3.3 首镜规则**
第一个镜头不能是空镜，必须有人物或核心道具在画面里。（空镜头仅用于段间情绪承接，不作单段首镜）

**3.4 动作拆分原则（按冻结时刻，不按句号）+ 动作预算**

**冻结时刻原则：**
按「同一冻结时刻」切——把在同一个时刻可以同时看见的内容放在一格/一镜里。
判断方法：问自己「这两个动作能在同一张照片里同时出现吗？」
- 能：放同一格
- 不能（有时间先后）：切成两格

**动作预算与时长下限（实测规则）：**
一个完整的「互动回合」（如：追上/开口问→对方手势或台词回应→主角反应）至少需要2.5—3秒，不得压到1.3秒这类不足时长，否则模型会吞掉动作。

- 当一个时间段里要塞多个完整互动回合时，按每回合2.5—3秒重新核算；总时长超15秒硬上限就拆段，不允许靠平分短时长硬塞。
- 快剪蒙太奇同样适用：宁可把同类动作拆成两个镜头、每镜2—3秒放1—2个回合，也不要一镜里塞三个完整回合。
- 实测案例：三个问路回合平分进0—4秒（每段1.3秒）→ 动作缺失；正确做法是三问拆成两镜、每镜2—3秒放1—2个问路回合。

### Step 3.5：分镜草图（生成视频前必须执行）

每段视频生成前，必须先出分镜草图，用户确认构图和动作编排无误后，才能进入提示词写作和视频生成。视频提示词必须引用对应草图节点到reference_nodes。

草图格式：
- 每张草图为9宫格铅笔线稿，黑白线条，不上颜色，不上灰度
- 每格对应1个镜头，镜头号连续标注
- 每格标注运镜方式（推/拉/摇/跟/固定）
- 景别大特写与近景交替，禁止连续相同景别

草图叙事规则：
- 非最后一段的最后一格：禁止出现收尾信号，必须保持动作进行中
- 最后一段的最后一格：才可以出现收尾定格

### 第四步：提示词写作规范

**提示词格式要求（最高优先级）：**
提示词必须以视觉参考库「标准样板提示词」为格式模板。所有要素（机位/动作/声音/BGM/台词/否定排除）融合为一段连贯自然语言，禁止分模块列条目。视频内容叙事描述不写进提示词，只写摄影机看到的画面——机位在哪里、看到什么、哪个身体部位在动、声音和BGM如何随动作流动。

**提示词线性顺序：**
4.1强制指令 → 4.3c导演因果链 → 4.3h空间锚点卡 → 4.3d场景动态锁定 → **4.9声音设计分轨块** → 时间轴（含台词绑定/声音点到/BGM融合）→ 否定排除 → 结束状态

**4.1 强制开头指令（一字不差放在最开头）**
你是一个爆款短剧的导演，禁止使用正视图，采用侧视图35度或者45度侧拍，相邻景别之间不允许衔接，避免全景，95%的景别为中景、特写、近景，采用浅景深拍摄。禁止在画面中添加任何字幕、文字或图形符号。拍摄轴线必须保证不越轴，摄像机始终在人物同一侧拍摄，禁止跨越180度轴线。

**人声双轨全局指令（紧跟4.1之后，每段必写）：**
本片有两种人声：角色开口说话时嘴唇动、声音在场景里；内心独白时角色嘴唇闭着不动，但画面外传来这个角色自己说话的声音。

**4.2 四件套（每段必须包含）**
布景 + 人物 + 时间轴 + 否定排除

**4.3a 摄影机视角转换规则**
把「阿桃做了什么」转换成「摄影机在哪里看到了什么」。
错误：「阿桃走进来」
正确：「平视，约胸口高度，50mm焦段，手持，位于阿桃右后方约1米，她走入画面左侧」

**4.3b H3提示词精确写法规范**
机位描述必须包含四个参数（缺一不可）：
- 高度：平视/胸口高度/腰部高度/低角度
- 焦段：35mm（自然感）/50mm（标准）/85mm（压缩感）
- 距离：距人物约X米
- 运动方式：固定/随人物后退/手持跟随/弧线环绕

每秒必须有具体身体部位在动：不能写「她走过去」，必须写「右脚先迈出，风衣下摆随步伐左右摆动，左手持小本贴着大腿」。

**4.3c 导演因果链（每段提示词开头必须写）**
在时间轴之前，先建立本段的导演因果链：
「人物判断/目标 → 动作A → 环境/他人反馈A → 动作B → 反馈B → 最终结果」

**4.3d 场景动态锁定（进入时间轴前必须写）**
- 前景：画面最近处是什么
- 中景：主体人物和核心动作
- 背景：远处空间和环境元素
- 环境持续运动：场景里的动态元素必须持续运动（吊扇持续转/纸角被风掀动）
- 180°轴线：摄影机始终在哪一侧
- 本段禁止出现的元素

**4.3e 竖屏景别规则**
见3.2景别规则（含孤独/渺小中远景例外）。

**4.3f 台词执行约束（硬规则）**
1. 台词只说一次，不得重复
2. 口型与台词严格同步，嘴唇动作与字数匹配
3. 不得新增台词、不得改写台词、不得省略台词
4. 每句台词必须绑定说话人：「[人名]开口，嘴唇动，说『台词原文』——[其他人]不开口」
5. 无对白镜头明确写：「无台词，仅保留呼吸与环境声」

**4.3g 跨段衔接检查（每段提交前必须执行）**
上一段结束状态必须等于下一段开始状态，检查人物位置、手部/道具、服装状态、空间朝向。
每段提示词末尾必须写：「本段结束状态：[人物位置/手部/道具/朝向]」

**4.3h 全局空间锚点卡（每段开头必写）**
在导演因果链之后、时间轴之前写：
【空间锚点 / 场景名】
固定参照物：[不可移动的视觉地标]
人物当前状态：阿桃[位置+朝向+手持物]；[其他角色][位置+朝向+手持物]
光影基调：[光源类型+方向+色温+氛围词]

**角色-背景专属绑定规则（切景别时防背景穿帮）**
切近景/特写时背景必须继承，不能凭空换背景。前置句式：
「在{{场景锚点节点}}场景空间的基础上，保持空间结构与光影一致，将镜头推进至[角色名]的[景别]——[角色名]身后依然是[专属背景描述]，按透视自然虚化，不更改背景元素。」

**4.3i 状态账本+全局对照（每段写完立即更新，强制）**
每段提示词写完后追加状态账本（阿桃位置/朝向、手持物、服装状态、其他角色状态、关键道具状态）。
全局对照：每段账本更新后，将全段终态汇总对照，检查非相邻段的手部/道具/服装漂移。

**4.3j 多角色同框·先合成后动画（2人以上同框必须执行）**
凡画面中出现2个及以上独立角色需要互动时：
第一步：生成静态合成图，reference_nodes依次引用各角色锚点。
第二步：用户确认合成图的角色位置/服装/空间关系。
第三步：把合成图作为start_frame_image_node喂generate_video，prompt只描述动作与运镜。
单角色镜头不需要合成图。若分镜草图已清晰画出多角色站位关系，可直接引用草图作为构图参考，无需单独再出合成图。

**4.3k 表演锁定（每个有台词或重要动作的角色必须写）**
[角色名]表演锁定：不要演成[类型化陷阱]；而要演成[正确表演基调]；关键动作边界[动作上限]。

阿桃通用表演锁定（每段必带，根据剧情选用）：
- 不要演成：偶像剧式捂嘴哭/泪眼汪汪示弱/没有原因对着镜头甜笑/明显演给摄影机看的情绪。真实情境下的咧嘴大笑、跳脱手势、爱张罗的热闹劲儿都可以有。
- 而要演成：真实发生的情绪；压力下的克制是选择不是底色
- 关键动作边界：眼神看向具体的物或人，不飘向镜头；情绪真实，不表演

阿桃微表情动作库（按场景情绪选用）：
压力下克制：「肩膀略前倾，手指抠着纸边，眼神看向对方但没有锁定，嘴唇动了一下才开口」
没争收拾走了：「嘴角抿了一下，没说话，手把东西折好或收好，动作干净，脚已经往门口转」
想通了/笃定了：「眼神一下亮起来，嘴角压不住，脚步已经往门口转，动作利落」
真的高兴：「笑是真的，眼睛也笑，不压着，嘴角抬起来脸颊也跟着动」
真的难过：「眼神先失焦，下眼睑细微颤动；嘴唇慢慢抿住，呼吸变浅，泪水悬在下睫毛处」
愤怒压抑：「目光突然静下来，眨眼变少，下颌线绷紧，鼻翼轻轻扩张，手指无声扣紧手边的东西」
震惊冻结：「呼吸骤然停住，手停在半空，眼睛微微睁大后彻底僵住，瞳孔轻微扩散」
失望：「目光慢慢垂下，鼻息很轻地泄出一口气，嘴角疲惫地落下，眼神不再追问」
释然：「长长地舒了一口气，紧绷的肩膀完全放松下来，脸上浮起淡淡的微笑，抬头望向远方」

**「憋住的节拍」（克制表演的核心，仅在该有的情绪节点加）：**
说完话/做完动作之后，若该段有情绪积压或转折，必须有一个「憋住的节拍」——情绪在身体里没有说出来的那一刻。写法：在时间轴里明确写出「停顿X秒，嘴唇动或不动，呼吸变化」。
判断是否需要：有情绪积压/转折/被拒/想通的段落加；纯动作过渡段不强制加。
克制自检：一镜只放1-2个关键动作；眼睛必须参与情绪；动作和触发之间要有0.3-1秒延迟。

**4.3l 动作拆分原则** 见3.4。

**4.3m 阿桃微表情动作库（禁止用抽象情绪词）**
禁止出现「她很难过」「他非常生气」等抽象词，一律替换为具体短句，每镜只选1-2个。
隐忍悲伤：「眼神先失焦，下眼睑细微颤动；嘴唇慢慢抿住，呼吸变浅，泪水悬在下睫毛处却迟迟不落」
强忍哭泣：「迅速低头，嘴唇死死抿住，喉结艰难滚动一次，鼻息破碎地颤了一下，却没有发出哭声」
震惊冻结：「呼吸骤然停住，手停在半空，眼睛微微睁大后彻底僵住，瞳孔轻微扩散」
愤怒压抑：「目光突然静下来，眨眼变少，下颌线绷紧，鼻翼轻轻扩张，手指无声扣紧手边的东西」
悔恨：「视线看向对方又迅速移开，眉心向内收紧，嘴唇张开却说不出话，伸出的手停在半空」
愧疚：「视线向下躲开，眨眼变慢，嘴角不对称地绷住，肩膀轻轻缩回」
失望：「目光慢慢垂下，鼻息很轻地泄出一口气，嘴角疲惫地落下，眼神不再追问」
释然：「长长地舒了一口气，紧绷的肩膀完全放松下来，脸上浮起淡淡的微笑，抬头望向远方」
专注笃定：「眉头微皱，眼神锁定一点，嘴唇抿紧，身体不自觉前倾」
阿桃·底气不足但还是来试了：「肩膀略前倾，手指抠着纸边，眼神看向对方但没有锁定，嘴唇动了一下才开口」
阿桃·没争收拾走了：「嘴角抿了一下，没说话，手把东西折好或收好，动作干净，脚已经往门口转」

**4.3n 动作-距离匹配验证**
近距离≤1米：推递物品、抓握、触碰、耳语
中距离1-3米：抛掷物品、指向、正常对话
远距离>3米：喊叫、挥手、远距注视
距离不合理时，必须先写移动过渡动作，再写互动动作。

**4.3o 失败修复单变量原则**
生成结果不满意时，先判断失败模块（锚点身份/空间站位/道具状态/动作时序/摄影机/光线/表演/台词/提示词过载），只修改那个模块，其余保留不动。同一镜头连续3次失败：判断是否需要拆镜/先合成图/预建道具图。

**4.3p AI生成难度评级（写提示词前先评级）**
★☆☆☆☆：单人固定镜头，无台词 → 直接生成
★★☆☆☆：单人有台词，或单人简单动作 → 注意口型绑定
★★★☆☆：两人对话，或单人复杂动作 → 先合成图，台词逐句绑定
★★★★☆：两人以上互动，或有道具文字，或快速动作 → 先合成图，道具图预建，考虑拆镜
★★★★★：三人以上同框，或多人复杂互动 → 必须拆镜

**4.3q 人声双轨写法（台词轨 vs OS轨）**

本片有两种人声，写法严格区分：

**台词轨（角色现场开口说话）：**
「[人名]嘴唇动，说『台词原文』——[其他人]不开口」

**OS轨（内心独白/旁白，角色嘴唇不动）：**
标准句式：「[人名]嘴唇始终闭合、没有张合，下巴放松，[给一个占住脸部的具体视觉动作，如：眼神望着窗外稻田微微闪动]；与此同时观众听到[人名]的旁白声音（这是后期旁白，声音不来自场景内、[人名]现场没有开口）：『……』」
- 用「后期旁白、不来自场景内」语义，切断模型「有声音=角色现场说话」的联想
- 闭着的嘴必须给一个明确可见的视觉状态，避免模型自行补嘴型
- 哼歌等无词义发声归台词轨（嘴唇动）

**4.4 情绪信号** 用≥2个具体身体信号锁定情绪，见4.3m。
**4.5 在场角色** 每段写清楚哪些人在画面里，哪些人不在。
**4.6 文字身份锚** 每个出场人物：姓名+{{node_key}}+外貌描述+眼神不直视镜头。
**4.7 否定排除** 凡有漂移风险的元素，正面描述+否定排除双写。

**4.8 时间轴（镜头号+精确秒数必须同时写）**

时间控制以精确秒数为主、镜头编号做结构辅助，二者必须一起写。禁止只写「镜头1/镜头2」让模型自己分配时长——会导致各镜长短随机、动作被吞或拖。

**统一格式：**
「镜头1 [0—3秒] ……」「镜头2 [3—6秒] ……」，每个镜头既给编号又给精确起止秒。

**单镜推荐时长：** 2—6秒，一个镜头只放一个主要动作（一镜一动作）。

纯单动作段也要写秒数；多镜快剪段必须镜头号+秒数齐全。

**4.9 BGM与声音设计（分轨写法，硬规则）**

**need_bgm规则：** 始终显式传need_bgm:true，不依赖默认值，禁止传false。

**声音设计分轨块（每段含声音的提示词，必须在时间轴之前独立写出，自成一块）：**

分四层用标准电影声音术语列清，格式如下：

```
【声音设计】
【环境床 ambient bed】[声源描述]，从第0秒到最后一秒全程持续不断，始终可闻。
【点音效 foley/SFX】[触发动作]→[拟声描述]，[远/近/画外]，[持续/偶发]。（可列多条）
【人声】台词轨：[说话人]现场开口；OS轨：[人名]后期旁白不来自场景内。（按本段实际情况填写）
【混音关系】默认写死各轨绝对音量比例（见下方规则）；动态ducking为可选试验性写法，默认不依赖。
```

**混音关系写法（实测结论）：**
- H3对动态自动压低（ducking）不敏感，不要依赖「人声出现时环境床自动压低」的动态写法。
- 默认改为**写死各轨绝对音量比例**：在分轨块里直接写明各轨的相对音量层级，如「引擎床音量为整体的60%，OS旁白音量为整体的80%，两轨同时可闻，互不遮盖」。
- 若仍想尝试ducking，可作为可选补充写在分轨块末尾，但不保证执行。

**BGM 可听见写法规则（有BGM段必须遵守）：**

只要分镜表要求某段有BGM，目标是「克制但清晰可辨」，不是听不见。必须写清以下四件事，禁止用多重弱化叠词把BGM埋掉：

1. **乐器+演奏法**：写明具体乐器与演奏方式，如「一把钢弦木吉他，手指拨弦，单音旋律，不是和弦扫弦」。
2. **明确时间锚点**：在第几秒、配合哪个动作/哪句旁白进入，拨出什么，如「第4秒第一句旁白时拨出第一个清亮单音，第8秒第二句时再拨两三个音，尾音自然延长」。
3. **绝对音量定位**：用与人声/环境声的具体比例和方位比喻，不用「极轻」这类模糊词，如「吉他清晰可辨，音量约为旁白的三分之一，稳稳浮在风声与环境声之上，但不盖过人声」。
4. **只保留一条不抢戏约束**：写「不盖过人声/旁白」即可；删掉「裹在风声里」「不盖过环境声」「零星几乎听不见」等会让模型把BGM整轨埋掉的多重弱化叠词。

禁止写法示例（会导致BGM消失）：「极轻吉他，几乎听不见，裹在风声里，不盖过任何声音，零星几个音」
正确写法示例：「一把钢弦木吉他，手指拨弦，单音旋律；第4秒旁白起时拨出第一个清亮单音，第8秒再拨两三个音，尾音自然延长；吉他音量约为旁白的三分之一，清晰可辨，浮在环境声之上，不盖过人声」

只有分镜表明确写「无BGM」时才不写BGM；写了BGM就必须让它能被听见。

**正确示例（大巴段，含BGM）：**
```
【声音设计】
【环境床 ambient bed】大巴引擎低沉轰鸣，从第0秒到最后一秒全程持续不断，始终可闻；引擎床音量为整体的50%。
【点音效 foley/SFX】车身颠簸→车窗玻璃哒哒轻响，近，偶发；大爷望窗外→车顶收音机沙沙地方戏曲，远/画外，断断续续；阿桃缩肩→风从窗缝呼呼灌入，近，偶发，吹得窗帘轻响。
【人声】OS轨：阿桃后期旁白不来自场景内，嘴唇闭合；旁白音量为整体的80%，清晰可辨。
【混音关系】引擎床50%、旁白80%、两轨同时可闻互不遮盖；不依赖动态ducking。
```

**静默段（无BGM）正面写法：**
```
【声音设计】
【环境床 ambient bed】[具体持续环境声]，从第0秒到最后一秒全程持续不断，环境声就是本段声音主体。
【点音效 foley/SFX】（按实际填写或写「无」）
【人声】（按实际填写）
【混音关系】（写明各轨绝对音量比例）
```
禁止用否定句：禁止「没有BGM，仅环境音」「这段没有配乐，只有……」——模型注意力会落在「没有」上并丢弃整层声音。

**时间轴内声音点到规则：**
时间轴每个时间窗内，用一句话点出该窗能听到的环境床/点音效（如「引擎床持续，窗帘轻响」），确保声音随动作流动；具体渲染以分轨块为准，时间轴内不重复展开。

**4.10 对白铁律** 台词逐字还原，不概括不意译，绑定说话人口型。
**4.11 动作五要素** 哪只手/哪只脚/哪个部位/做了什么/幅度多大/速度多快。
**4.12 文字写死** 道具上该有文字就有文字，不刻意模糊；禁止的是台词字幕，不是道具文字。需要清晰呈现的文字内容必须提前生成道具图引用。
**4.13 场景引用** 已有参考图的场景一句话点明「参考{{node_key}}场景空间」，不重复描述。
**4.14 美化惯性** 禁止写「高级感」「氛围感」「电影级」等抽象词，改写为镜头可拍的具体描述。
**4.15 皮肤去脏（视频阶段专用）**
常驻声明：「人物皮肤干净通透、暗部提亮不脏、肤色均匀无杂色偏色、自然肤质不油腻不磨皮」
负面词：皮肤发脏、暗部脏污、肤色斑驳、灰绿蜡黄偏色、油腻油光、过度锐化毛孔、磨皮塑料假脸

### 第五步：人物音色规范
见锚点文件 anchors/atao_s2_voice_profiles.md。五维音色描述（缺一不可）：音高/音色质感/共鸣位置/语速节奏/情绪语调。

### 第六步：完整检查清单

**前置：** 布景情绪分析/创作脊柱/台词按角色+场景选速换算/草图已确认/待确认锚点全部✅
**提示词格式：** 以视觉参考库样板为模板/连贯自然语言非分模块/未写入视频内容叙事/草图节点已引用
**分镜：**
- 总时长≤15秒
- 景别跳档（孤独中远景例外合理）
- 台词完整覆盖
- 每个镜头是否镜头号+精确秒数齐全（禁止只给镜头号让模型自定时长）
- 每个互动回合是否给到≥2.5—3秒；是否存在一镜塞多个完整回合导致动作超载（超载则拆镜/拆段）
**四件套：** 强制开头/人声双轨全局指令/因果链/空间锚点卡/场景动态锁定/台词逐句绑定/结束状态/状态账本+全局对照
**视觉：** 机位四参数/每秒身体部位在动/负面清单针对当前场景/光线方向色温/皮肤去脏/多人人人皆动
**动作情绪：** 具体短句非抽象词/距离匹配/难度评级/憋住节拍（仅情绪节点加）
**多角色：** 2人以上合成图或草图站位替代/表演锁定
**时间音频：**
- 时间轴格式正确（镜头N [X—X秒]，镜头号+秒数齐全）
- BGM绑定秒数/need_bgm显式true
- 是否在时间轴之前写了独立【声音设计】分轨块（环境床/点音效/人声/混音关系四层齐全）
- 环境床是否写明「全程持续不断，始终可闻」
- 混音关系是否写明各轨绝对音量比例（默认不依赖动态ducking；若写了ducking标注为可选试验性）
- 有BGM段：是否写了乐器+演奏法+时间锚点+绝对音量比例+只保留「不盖人声」一条约束（无多重弱化叠词）
- 时间轴每个时间窗是否点到了该窗可闻的环境床/点音效
- 每句OS是否在本时间窗内紧贴台词写了闭唇状态+后期旁白语义（不只靠开头全局指令）
**技术规格：** 节点EP0X-SX-内容-版本号/Minimax H3/9:16/720p/need_bgm:true

**红果短剧导演思维（每集开始前必读）**

核心公式：真实困境 × 真实性格 × 观众代入感。

一、钩子设计（每集前3秒必须命中其一）：冲突钩子/悬疑钩子/身份反转钩子/情绪钩子/视觉钩子
二、爽点设计（每集至少一个）：压迫→忍耐→想通→反击→爽点。爽点不是逆袭，是「她用自己的方式解决了别人解决不了的问题」。爽点之后不炫耀。每集结尾留悬念。加爽点必回看该集情绪重力——防止跳脱压不住情绪重量，底色乐观≠没心没肺。
三、共鸣场景镜头语言（农村女孩的窘迫，让观众「认出自己」）
四、小确幸镜头语言（不给正脸，给手/脚/道具，让观众自己感受她的快乐，不强调）
五、矛盾性格双层表达（两个镜头讲两层，不在同一个镜头里解释内心，让观众自己推断）
