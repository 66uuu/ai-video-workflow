# 故事板 Skill

## 这个 Skill 做什么

用户输入任意形式的剧本内容（文档 / 故事 / 要求 / 一句话），Skill 分两个阶段处理：

- **阶段一**：建立全局锚点（整个剧本只做一次）
- **阶段二**：逐条生成每条视频的故事板（从阶段一输入内容里自动提取，不重复让用户输入）

---

## 生成参数（全局固定，不得自行更改）

类型模型画质 / 分辨率比例图片（三视图 / 故事板）Lib Image低画质16:9视频Seedance 2.0 Fast（2.0 mini）480p4:3

> 所有图片生成（包括三视图和故事板）统一使用 Lib Image 低画质 16:9；所有视频生成统一使用 Seedance 2.0 Fast 480p 4:3。

---

## 阶段一：全局锚点建立（整个剧本只做一次）

**输入**：用户提供任意形式的内容——剧本文档 / 故事 / 要求 / 一句话均可。

**执行步骤**：

1. 自动分析输入内容，识别人物、场景、风格信息

2. **生成人物三视图（角色锚点）**，全剧本复用：

   生成三视图时，将 agent 整理的角色形象描述与下方「三视图提示词模板」组合后作为 prompt 发送给生图模型。不得让生图模型自行决定排版或风格。

   - **角色形象描述**：agent 根据剧本中的人物描述，结合网络搜索或自行想象，整理出该角色的外貌特征（五官、发型、服装、体型、风格等）
   - 生图参数：**Lib Image / 低画质 / 16:9**

3. 提炼色彩调性 → 输出为统一文字提示词（不生成色彩参考图），全剧本复用

4. 输出锚点清单

**锚点清单字段**：

字段说明锚点名称该锚点的名称锚点类型角色 / 风格 等（不包含场景类型，不单独生成场景锚点）节点Key对应节点的 Key提示词直接用于后续生图/生视频的提示词，不是解释性描述适用范围全剧本 / 某条视频

> **注意**：阶段一只建立角色锚点和色彩调性，**不单独生成场景锚点图**。场景信息已通过故事板分镜自然呈现，无需额外生成。

---

## 三视图提示词模板

> **说明**：本模板是写给 agent 的工作流说明，不是直接复制发送的固定文本。agent 生成三视图时，需将角色形象描述与以下模板拼合后发送给生图模型。

生成三视图加大头照，在同一张图中生成丰富细节的角色展示风格图片，图片比例16:9，具体要求：排版布局左侧1/3为从头部到肩膀的清晰正面大头照，右侧2/3为人物的站立半身三视图（正视、侧视、背视）；所有视图必须为同一角色，五官、发型、服装、体型、风格、比例与细节完全一致，不改变人物特征；三视图比例统一、姿态自然；纯白色背景、无阴影、无道具、无文字。

---

## 阶段二：每条视频生成（每条视频重复此流程）

**输入来源**：直接从阶段一的输入内容里按顺序提取每条视频的剧情，不重复让用户输入。

**执行步骤**：

1. **计算建议时长**：分析该条视频的台词总字数 ÷ 6\~8字/秒 → 告知用户建议时长。具体生图和生视频的时长控制由模型自由发挥，Skill 不主导细节。

2. **拆分镜号**：按剧情内容自动拆分为 4\~9 个镜号，**确定具体镜号数量**（如 6 个）。

3. **判断视角**：先整体判断这条视频适合用哪种视角，确定后整张故事板统一使用该视角，不混用。不同故事板之间可以各自选不同视角，限制的是同一张故事板内不混用两种视角：

   - POV 第一视角
   - 第三视角（电影分镜）

4. **生成故事板**：

   生成故事板时，将角色锚点图作为参考图传入（reference node）；将该条视频的剧情内容（分镜描述：画面描述 + 人物台词）与对应视角的故事板提示词模板组合后作为 prompt 发送给生图模型。

   - **发送时，将步骤2已确定的镜号数量直接填入提示词模板中的"镜头总数量"字段**，不让生图模型自行决定镜头数量
   - 色彩调性使用阶段一提炼的统一文字提示词
   - 生图参数：**Lib Image / 低画质 / 16:9**

5. **生成视频**：

   生成视频时，将该条视频对应的故事板图节点作为参考图传入（reference node）。故事板图片已包含人物、道具、场景的视觉信息。

   - 视频参数：**Seedance 2.0 Fast（2.0 mini）/ 480p / 4:3**

## 故事板提示词模板（两套，根据视角自动选择）

> **说明**：以下两套模板是写给 agent 的工作流说明，不是直接复制发送的固定文本。agent 在发送给生图模型时，需将模板中的 `[镜头总数量]` 替换为步骤2已确定的具体数字（如 6），将 `[色彩调性]` 替换为阶段一提炼的色彩调性文字，将 `[项目名]` 替换为实际项目名称，再发送给生图模型。

### POV 第一视角版

你将根据我提供的剧情内容，生成一张16:9的第一人称主观视角分镜图。本次分镜图共 **\[镜头总数量\]** 个镜头，请严格按照此数量生成，不得增减。

分镜图固定版式要求如下（不可更改）： 顶部通栏标注格式为"项目名：\[项目名\] / 镜头总数量：\[镜头总数量\] / 色彩调性：\[色彩调性\]" 中下部分采用整齐的网格排列，列数和行数根据镜头总数量灵活适配（不固定列数），保证整体排版美观对齐，每个分镜缩略图严格保持4:3比例，各分镜间有清晰边框并整齐排列，每个分镜框左上角带有手写体数字序号（从01顺序编号，不足两位补0，如01、02……09）。 每个分镜均为第一人称主观视角，画面中仅可见手部、前臂或衣领边缘作为身体参照，绝不出现主角本人的完整面部或全身像。 每个分镜下方仅标注一行技术信息，格式为"pov视角/景别：XX / 运镜：XX"。 全图严格禁止（不可更改）：任何台词、对话、旁白、字幕、对话气泡、文字标注框或画面描述性文字；任何角色完整的正面面部、背面全身像、侧面全身像或多角度参考图；任何第三人称上帝视角、鱼眼超广角、俯拍全景、仰拍全景等非人眼高度的主观镜头；任何镜子、水面、玻璃、抛光金属面等可反射出主角倒影的物体或表面；任何空白分镜框，每个分镜框内必须有内容。 根据我提供的剧情内容，为每个镜头设计合理的景别和运镜，并按照 \[色彩调性\] 为画面着色。

### 第三视角电影分镜版

你将根据我提供的剧情内容，生成一张16:9的电影分镜图。本次分镜图共 **\[镜头总数量\]** 个镜头，请严格按照此数量生成，不得增减。

分镜图固定版式要求如下（不可更改）： 顶部通栏标注格式为"项目名：\[项目名\] / 镜头总数量：\[镜头总数量\] / 色彩调性：\[色彩调性\]" 中下部分采用整齐的网格排列，列数和行数根据镜头总数量灵活适配（不固定列数），保证整体排版美观对齐，每个分镜缩略图严格保持4:3比例，各分镜间有清晰边框并整齐排列，每个分镜框左上角以圆标显示数字序号（从01开始顺序编号，不足两位补0）。 每个分镜为纯净构图，不含任何描述性文字或标注。 每个分镜下方仅标注一行技术信息，格式为"景别：XX / 运镜：XX"。 全图严格禁止（不可更改）：任何台词、对话、旁白、字幕、对话气泡；任何画面描述（动作、情绪、场景细节）；任何角色三视图或多角度参考图；任何空白分镜框或冗余信息区域。 根据我提供的剧情内容，为每个镜头设计合理的景别和运镜，并按照 \[色彩调性\] 为画面着色。仅输出分镜图和技术标注，不输出任何画面描述。

## 全局禁止规则

- **禁止人物不一致**：全剧本必须复用同一人物三视图锚点，不得每条视频重新生成人物形象
- **禁止色彩调性飘移**：必须全剧本统一使用阶段一提炼的色彩调性文字提示词
- **禁止故事板超出 4\~9 格范围**：格数由剧情内容自动决定，不得少于4格或多于9格
- **禁止一张故事板混用两种视角**：每张故事板只能使用 POV 第一视角或第三视角其中一种；不同故事板之间可以各自选不同视角，限制的是同一张故事板内不混用两种视角
- **禁止 Skill 主导时长细节**：只告知用户建议时长（台词总字数 ÷ 6\~8字/秒），具体时长控制由生图/生视频模型自由发挥
- 每条视频必须包含台词或对话，否则跳过不生成，避免浪费积分
- **禁止单独生成场景锚点**：阶段一只建立角色锚点和色彩调性，不生成任何场景锚点图
- **禁止让生图模型自行决定镜头数量**：镜头总数量由 agent 在步骤2拆分时确定，发送 prompt 时必须填入具体数字
- **禁止让生图模型自行决定三视图排版或风格**：必须使用三视图提示词模板，不得省略或让生图模型自由发挥排版
- **禁止擅自更改生成参数**：图片统一使用 Lib Image 低画质 16:9，视频统一使用 Seedance 2.0 Fast 480p 4:3，不得自行调整
