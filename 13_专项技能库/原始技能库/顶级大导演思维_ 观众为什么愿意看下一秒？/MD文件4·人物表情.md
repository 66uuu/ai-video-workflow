MD文件4·[人物表情.md](http://人物表情.md)\
顶级大导演思维 Skill — V2.0融合版\
模块定位\
本文件为独立表演子引擎，承接《分镜创作执行手册》。专门解决：AI表情随机、静态、无时序、强度混乱、千人一面、词藻堆砌、分镜与提示词脱节、情绪无梯度问题。实现：剧情触发→心理判定→时序表情→五级强度→多人物差异化→可视化提示词落地全链路强制执行。

一、表情与三镜体系联动规则\
主镜头：承载人物整体情绪、面部基础表情、肢体动态\
小特写：专注动作细节，不强行叠加表情\
副镜头：专注事件结果、环境反馈、对方反应表情\
1.1 最终决策树（AI自动判断流程）\
STEP1：判断动作是否具备剧情重要性 → 不重要 = 单镜结束\
STEP2：判断动作是否有结果 → 有结果 = 启用主+副双镜\
STEP3：判断细节是否需要观众看清 → 需要 = 追加小特写\
STEP4：判断是否有撞击/破碎音效 → 有则追加音画同步接力标记\
1.2 最终铁律\
不要让一个镜头承担「人物、动作、细节、结果、情绪」全部任务。 主镜头负责叙事、副镜头负责落地、小特写负责因果、声音负责衔接。 镜头拆分不为好看，只为信息完整、因果通顺、层次清晰。

二、核心总纲\
表情不是装饰，是剧情信息的一部分。\
所有表情必须满足：前状态 → 剧情触发 → 瞬时变化 → 后状态延续。\
禁止孤立表情、禁止无理由情绪跳变、禁止多情绪同级堆叠。\
分镜表预设表情 = 视频提示词最终执行表情，完全对齐、零丢失。\
三、表情五级强度系统（全局统一标准）\
1级｜微表情（隐忍/试探/平静）\
仅细微变化：目光停顿、眉头微动、嘴角微敛、呼吸微变。

2级｜明显情绪（压力/不悦/犹豫）\
眉头明显起伏、嘴唇收紧、呼吸加重、目光躲闪/锁定。

3级｜强烈情绪（愤怒/悲伤/震惊/恐惧）\
眼眶泛红、眉头紧锁、呼吸急促、眼神剧烈变化。

4级｜情绪爆发（争吵/崩溃/重击）\
眼泪欲落、嘴唇颤抖、面部张力失控、肢体紧绷。

5级｜极端失控（仅限高潮终局）\
彻底崩溃、失控哭泣、极致惊惧、精神震颤。普通剧情严禁使用。

四、表情状态机（禁止无序跳变）\
固定链路：

初始稳态 → 剧情刺激触发 → 微表情异动 → 主情绪确立\
→ 情绪强化 → 压制/爆发 → 情绪收尾 → 新稳态\
所有表情变化必须在该链路内。禁止：平静→痛哭→平静 无逻辑跳变。

五、时序表情规则（镜头内动态变化）\
单镜头内超过3秒，必须做时间轴拆分，禁止全程静态表情。

标准写法（按实际镜头时长等比拆分，不固定具体秒数）：

前段（约前1/3时长）：原状态稳态\
中段（约中1/3时长）：接收刺激、微变化，主情绪成型\
后段（约后1/3时长）：情绪延续/压制/转化\
示例：镜头时长8秒

0–2.5秒：原状态稳态\
2.5–5.5秒：接收刺激、微变化，主情绪成型\
5.5–8秒：情绪延续/压制/转化\
示例：镜头时长4秒

0–1.5秒：原状态稳态\
1.5–2.5秒：接收刺激、微变化\
2.5–4秒：主情绪成型，情绪延续\
核心原则：时序节点随镜头时长等比缩放，禁止把长镜头的时序节点机械套用到短镜头。单镜头3秒及以下无需强制拆分时序，保持单一情绪状态即可。

六、反应类型强制分类（杜绝默认"震惊"）\
反应类型	可视化描述\
立即反应	瞬间瞳孔收缩、目光骤停\
延迟反应	先平静、数秒后缓慢读懂信息、情绪下沉\
压制反应	表面无痕，仅下颌、眼神、呼吸紧绷\
防御反应	眉头锁紧、身体微撤、眼神警惕\
怀疑反应	定点凝视、轻皱眉、持续观察\
否认反应	目光闪躲、摇头、急于解释\
隐藏反应	整体平静，仅眼底一瞬波动\
七、多人物同场差异化规则\
多人同镜/同场：禁止全员同情绪、同表情。 必须根据人物立场、信息差、权力关系、性格，生成差异化反应。

通用差异化模板：

角色身份	表情倾向\
知情者	隐忍、冷静、紧绷\
不知情者	震惊、错愕、慌乱\
旁观者	回避、紧张、漠然\
施压者	冷静、克制、目光锐利、居高临下\
受压者	紧张、防御、眼神躲闪、身体微撤\
通用案例——职场会议室（三人同场）：

主导方（知情者）：冷静，嘴角微敛，目光锁定对方，下颌轻绷（压制反应）\
被质疑方（受压者）：眉头微皱，目光短暂偏移，手指轻按桌面（防御反应）\
旁观同事：身体微向后靠，目光在两人间来回，表情刻意保持中立（隐藏反应）\
八、表情与景别联动规则\
景别	表情描写范围\
全景/远景	只写体态、整体情绪氛围，不写微观面部\
中景	眉眼、嘴部、整体神态\
近景	眼神、瞳孔、眼眶、呼吸、下颌细节\
特写	聚焦单一关键细节（眼神/嘴唇/下颌），保留时序变化，不堆叠多个细节\
大特写	聚焦极致局部（瞳孔/泪痕/嘴角微动），只保留关键唯一细节，仍需时序，不做静态描述\
九、表情与动作强制拆分规则\
禁止合并句式：「他愤怒地砸碗」

强制二分结构：

【表情状态】可视化面部+呼吸+眼神变化\
【肢体动作】独立行为描述\
通用案例对比：

❌ 错误写法：「她绝望地推开椅子站起来」

✅ 正确写法：

【表情状态】眼眶泛红，目光低垂，下唇轻颤，呼吸急促（3级·悲伤）\
【肢体动作】双手撑桌，椅子向后推出，缓慢站起，背对镜头\
十、表情时序逻辑顺序（不可颠倒）\
前置判断（必须先执行）\
设计表情前，首先判断触发来源：

有外部信息输入（看到/听到/接收到）→ 使用外部触发链路\
无外部信息，人物内心主动产生 → 使用内心触发链路\
两条链路禁止混用，判断后再执行对应链路。

外部触发链路\
看到/接收信息 → 视觉停顿 → 理解信息 → 情绪产生 → 面部变化 → 肢体反应\
内心主动触发链路（独自回忆/内心挣扎/做决定/潜伏隐忍）\
内心状态变化 → 情绪产生 → 面部变化 → 肢体反应\
禁止：先动作、再表情、再看懂信息的逻辑倒置。

十一、关键剧情表情锚点（强制预设）\
以下节点必须前置设计三段式表情：前状态 → 触发瞬间 → 后状态

初见关键证据/关键视频\
得知背叛、谎言揭穿\
身份反转、真相落地\
权力关系逆转\
情感破裂、重大抉择\
通用案例——悬疑剧·得知背叛（近景，镜头时长6秒）：

阶段	时段	表情描写	强度\
前状态	0–2秒	眉眼放松，目光稳定，嘴唇自然闭合（平静）	1级\
触发瞬间	2–3.5秒	目光骤然停住，瞳孔收缩，眉毛微扬，嘴唇微张，呼吸短暂停滞（外部触发·立即反应）	3级\
后状态	3.5–6秒	眼眶泛红，眉头紧锁，嘴唇收紧，呼吸克制，眼神从对方脸上缓慢移开（压制反应·延迟消化）	3→2级（压制）\
十二、禁用规则（绝对禁止）\
禁止多同级情绪堆叠：震惊+愤怒+悲伤+绝望\
禁止抽象虚词：情绪复杂、深情、痛苦地看着\
禁止强度越级：普通对话突然五级崩溃\
禁止表情无承接：上镜泛红、下镜无痕\
十三、内置标准化表情词库（可直接调用）\
所有抽象情绪，强制替换为以下可视化文本：

情绪	可视化描述\
平静	眉眼放松，目光稳定，嘴唇自然闭合，呼吸平稳。\
疑惑	眉头轻皱，目光定点停留，头部微侧，嘴唇轻抿。\
震惊	目光骤然停住，眉毛微扬，瞳孔收缩，嘴唇微张，呼吸短暂停滞。\
愤怒	眉头紧锁，目光锐利，下颌绷紧，嘴唇紧抿，呼吸加重。\
压抑愤怒	眉头微敛，眼神压低，下颌紧绷，刻意压制呼吸，面部无爆发。\
悲伤	眼眶泛红，目光低垂，眉尾下压，嘴角微垂，情绪下沉。\
强忍泪水	眼底蓄泪，眨眼放缓，嘴唇紧抿，呼吸克制，不让泪水落下。\
恐惧	瞳孔放大，目光慌乱，呼吸急促，身体下意识拘谨后撤。\
紧张	目光闪烁，喉结滚动，嘴唇反复抿动，呼吸略显急促。\
犹豫	目光短暂偏移，欲言又止，唇瓣微张即闭，眉头轻蹙。\
失望	眼神黯淡，眉尾垂落，对视无力，情绪逐渐低落。\
心虚	眼神躲闪，不敢长直视，表情刻意维持平稳。\
强装镇定	表面平静，目光短暂卡顿，嘴角僵硬，下颌不自觉绷紧。\
决绝	眼神定型，眉头舒展，唇线收紧，情绪落地坚定。\
冷漠	面部无波动，眼神疏离平静，情绪克制内敛。\
得意/轻蔑	嘴角微扬带弧度，目光居高俯视，眉头略微上扬，整体神态松弛带压迫感。\
隐忍克制	面部整体平静，眼神内敛不外露，下颌轻微绷紧，呼吸刻意放缓，情绪压在表情之下。\
释然	眉头舒展，目光柔和，嘴角自然放松，呼吸平稳深长，整体神态由紧绷转为松弛。\
十四、标准输出字段（分镜表强制必填）\
【人物】【心理状态】【基础表情】【时序表情变化】【情绪强度】【触发点】【表演肢体动作】\
十五、最终执行铁律\
先定心理，再定表情；先定时序，再写提示词。 所有情绪必须肉眼可见、可帧级对应、可时序追溯。
