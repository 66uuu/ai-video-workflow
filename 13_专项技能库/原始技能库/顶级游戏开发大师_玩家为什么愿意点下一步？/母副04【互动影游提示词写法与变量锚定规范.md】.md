#  互动影游提示词写法与变量锚定规范

版本：V1.0\
定位：给AI一套“填空公式”，确保所有分支节点提示词不崩、不漂移、能直接接引擎。所有子级共享此底座，具体角色与场景锚点ID由子级扩展。

## 一、图片提示词·八要素填空公式

\[画面构图：机位/景别\]

- \[无角色 或 人物空间与互动关系：位置/距离/朝向\]

- \[极具体的微表情与面部特写：物理器官描述，禁止抽象词\]

- \[明确的场景环境元素与前景/背景道具：精确罗列实物\]

- \[光影几何与大气效果：光源方向/颜色/明暗气氛\]

- \[视觉风格/胶片质感：导演名或风格标签\]

- \[技术参数：相机/镜头/光圈\]

- \[负面提示词：禁止文字/Logo/水印/现代物品\]

- \
  案例：

  > 极近景平视机位 + 陆凡位于画面黄金分割点，跪姿，锁链缠绕 + 下颌紧绷、瞳孔收缩、额头冷汗 + 斩仙台玄铁地面、红色封印符文、万仙列阵 + 乌云压顶、金色神光从云缝透出、色温5200K + 胡金铨式写实武侠+东方神话美学 + 100mm微距、f/1.8 + 禁止文字、Logo、水印、现代元素

  ## 二、视频提示词·七要素填空公式

  \[时长与镜头运动：3-5秒/推/拉/摇/移\]

  \[角色一致性锁定：首帧参考/人物锚点ID\]

  \[动作因果链：脚步→重心→物理反馈\]

  \[光影与色调锁定：环境光/主光源/色温\]

  \[声音叙事：无BGM，纯物理音效\]

  \[防崩指令：禁止飞檐走壁/威亚/悬浮\]

  \[输出规格：16:9/24fps/720P以上\]

\
案例：

> 5秒+低角度仰拍缓慢推进 + 孙悟空首帧参考i-6j9vke5nbu92 + 破云而降、金箍棒砸地、地面青石板碎裂飞溅 + 乌云压顶、金色神光从云缝透出、色温5200K + 无BGM，仅金箍棒破风声+金属共振 + 禁止飞檐走壁、威亚特效、人物悬浮 + 16:9/24fps/1080P

## 三、互动影游专属追加三要素

- \[节点ID与分支标识：N05A/N06B/N07C\]

- \[变量变化提示：因果值+40·天罚风险+25·路线锁定=A\]

- \[选择界面UI描述：卷轴按钮/变量显示/倒计时\]

- \
  案例：

  > 3秒+时间重启、天道金印从云端压下 + 孙悟空首帧参考i-6j9vke5nbu92 + 天道金印降落、古篆文字环绕流动 + 金光罩住陆凡、众神将后退 + 无BGM，仅天道判定音+金属共振 + 禁止画面出现文字、Logo + 节点ID：N05A·A线天道判定 + 变量变化：因果值+40·天罚风险+25·西方教敌意+20·路线锁定=A

  ## 四、变量锚定规则

  每个节点提示词末尾必须标注：节点ID：N05A\
  变量变化：因果值+40·天罚风险+25·路线锁定=A

## 五、分支一致性锁定

同角色在不同分支的提示词必须用同一人物锚点ID。

- 禁止分支A用锚点ID-001，分支B用锚点ID-002
- 所有分支共用同一套角色锚点库
- 所有分支共用同一套场景锚点库

## 七、负面提示词清单

禁止：

- 文字、Logo、水印、乱码
- 现代物品（手机、汽车、高楼）
- 飞檐走壁、威亚特效、人物悬浮
- 塑料感皮肤、过度美颜
- 手部穿模、肢体融合
