# 互动影游通用产品防崩指令

版本：V1.0\
定位：互动影游中涉及实体产品的通用防崩参数。所有子级共享此底座，具体产品参数由子级扩展。

## 一、防崩色号（黄金/金属类通用）

颜色色值用途足赤金#D4AF37金属产品主色暖金拉丝#CFB53B金属拉丝质感暗金#B8860B金属阴影处

禁止色：银白、铂金、冷灰、亮白

## 二、材质防穿模

1. 金属表面必须拉丝、哑光、氧化痕迹
2. 禁止塑料感、光滑无瑕
3. 手部与产品之间留有自然缝隙
4. 产品与皮肤不得融合

## 三、物理比例锁定

1. 手镯内径约6厘米（或按实际数据）
2. 手镯与手腕之间留有一根手指的缝隙
3. 手镯在手腕上自然垂直，不紧绷、不松垮
4. 禁止手镯缩小成戒指尺寸
5. 禁止手镯放大成巨型环状物
6. 保持1:1真实物理比例

## 四、锦盒物理坐标系

1. 锦盒为经典横开式
2. 铰链固定在远离镜头一侧
3. 盒子由下方向后方翻开
4. 开口正面朝向镜头方向
5. 禁止盒子侧翻、透视错误、前后颠倒

## 五、手部动作防崩

1. 每个镜头只做一个单一动作
2. 禁止多个复杂动作在同一秒内完成
3. 手部动作必须有物理因果链
4. 禁止手指弯曲畸形、断指、多余手指

## 六、材质描述强制词

### 正向必加：

- 足赤金、哑光暗金、暖金色拉丝金属
- 通体浑然一体的高级暖金色
- 无拼接感、零银白、零铂金、零冷灰

### 反向禁止：

- 禁止白色金属、银白反光
- 禁止冷白杂色、灰白质感
- 禁止塑料感、光滑无瑕

## 七、子级扩展规则

子级可在此母级基础上追加专属产品参数：

- 子级A（洪荒西游）：追加金箍棒、斩仙刀等专属道具参数
- 子级B（乙女影游）：追加戒指、项链等情感信物参数
- 子级C（悬疑互动剧）：追加线索道具、证据物品参数
