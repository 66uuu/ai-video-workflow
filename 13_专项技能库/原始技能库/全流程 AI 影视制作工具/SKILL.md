# 全流程 AI 影视制作工具

## 技能用途

将用户的模糊构思、角色设定或故事剧本转化为可执行的 AI 短剧、电影或游戏画面方案。擅长处理混合风格（国漫 CG 感、游戏实机感、华丽神性等），输出精准的双语分镜提示词（Prompt）与质量控制（QC）标准，并在多集制作中维持角色身份与剧情状态的连续性。

## 适用输入

- **角色/世界观设定**：角色图、Bible 文件（PDF、图片、纯文本均可）、能力描述、动作习惯。
- **系列素材（多集时）**：系列状态档 Series State、上一集结尾状态、既有角色 ID 锁定卡。
- **创意文案**：故事梗概、小说片段、短剧脚本或模糊的口语化描述。
- **画面参考**：特定风格参考图，或对光影、材质的具体要求。
- **规格**：画幅比例、单镜时长、是否需要对白、交付格式。

## 操作步骤

### 步骤 1：意图桥接（缺漏必问）

解析自然语言，识别核心风格意图，补全缺失的动作、场景与关键规格信息。

- 识别：风格层级（如国漫/实机/神性）、题材类型（动作型/生活型/氛围型）、集数与场次、核心动作。
- 缺漏项**必须先询问，不擅自定案**。
- 提问规则：**每次最多问 3 项**，每项附 2–3 个预设选项，允许使用者回答“略过”。
- 仅**非关键规格**（画幅、分镜数量、调色倾向等）可在使用者未指定时套用默认值，并在输出中标注 `[预设]`。
- **角色身份、世界观、剧情走向、不可逆设定一律不得假设。**
- 使用者略过的是**关键规格**时，停在本步骤，不得进入提示词编译。

### 步骤 2：跨集状态装载（仅多集或续集时）

多集制作时，先读取外部状态档（规范见〈多集连续性与角色一致性〉）。

- 从状态档取出：角色 Bible 版本、角色 ID 锁定卡、各角色最新服装/伤势/情绪状态、已登场场景、上一集结尾状态与时间点。
- 状态档缺失或版本不明时，**先向用户索取，不得凭猜测续写前情**。
- 单集或首次开篇可跳过本步骤，并在输出中注明“未启用系列状态”。

### 步骤 3：风格分工（12 维分工表）

按附录 A 的 12 个固定维度逐项指派负责风格，解决风格冲突。

- 题材不涉及的维度标为 **`不适用`**，该维度由必填转为可选；**不得为凑满 12 栏而强行套用**。
- 冲突优先序：**身份与形态一致性 > 物理可信度 > 美学华丽度**。

### 步骤 4：角色锚定

建立 Character Bible，并同步生成**角色 ID 锁定卡**（见〈多集连续性与角色一致性〉）。

- Bible 栏位：五官、服饰、武器、形态，每位角色另加“不可变特征”与“可变特征（变体）”两栏。
- 从 PDF/图片/文本形式的 Bible 中抽取锚点时必须逐字记录原文关键特征，不得同义改写。

### 步骤 5：动作编排（分级五段）

按“预备-触发-接触-反应-余势”语法规划动作，并根据题材分级映射（见附录 A 下方《动作强度分级》）。

- 原子化叙事：**每镜仅处理一个核心动作**。
- A 动作型照用五段；B 生活型映射为五段变体；C 氛围型免五段。

### 步骤 6：提示词编译

输出包含六要素的专业双语提示词：**主体、场景、镜头语言、光效、VFX、终止状态**。

- 每镜 Prompt 必须**原样携带**该角色的 ID 锁定卡锚点字串，不得改写同义词。
- 变体状态以 `base + variant(EpXX)` 明示。
- 规格沿用 `[预设]` 时必须保留标记，便于使用者覆写。
- 相邻镜的**视频续写**依〈镜间视频续写（含 edit_video 降级）〉执行；续写 Prompt 须携带前镜“终止状态”，且不得重演前情。

### 步骤 7：交付与回写

输出完整交付物（见《输出要求》），若为多集制作，**收工后回写系列状态档**并提交差异摘要（新增角色、状态变化、未闭合伏笔、视频续写降级记录）。

- **单集或未启用系列状态时**：不写状态档，视频续写降级记录落在交付物「视频续写记录」与该镜任务记录中。

## 附录 A：12 维风格分工表

| # | 维度 | 默认可归属风格 |
|---|---|---|
| 1 | 人物五官与脸型 | 国漫 CG |
| 2 | 发型与发丝动力 | 国漫 CG |
| 3 | 服装形制与褶皱 | 国漫 CG |
| 4 | 皮肤与材质质感（布料/金属/次表面） | 游戏实机感 |
| 5 | 体型比例与解剖 | 依角色设定，默认国漫 |
| 6 | 武器/道具设计与持握 | 游戏实机感 |
| 7 | 场景建筑与空间结构 | 电影感 |
| 8 | 大气与体积光（雾、尘、神光） | 神性华丽 |
| 9 | 特效与粒子（掌风、能量、冲击环） | 神性华丽 |
| 10 | 镜头语言与运镜（焦段、运动） | 电影感 |
| 11 | 色彩与调色基调 | 电影感 |
| 12 | 动作质量与受力（重量感、打击反馈） | 游戏实机感 |

**动作强度分级**

- **A 动作型**（武打、战斗）：五段照用——预备 → 触发 → 接触 → 反应 → 余势。
- **B 生活型**（日常、情感、对话）：五段映射为——意图 → 启动 → 交互/接触 → 情绪反应 → 余韵；仍要求每镜只承载一个核心动作。
- **C 氛围型**（空镜、转场、特写）：免五段，仅需“运镜 + 光效 + 终止状态”。
- B/C 型下，维度 9（特效）与维度 12（受力）默认为 `不适用`，**不得强行生成特效**。

## 附录 B：输出规模

**分镜列表固定栏位**：`ID（集-场-镜，如 EP05-S03-02）｜时长｜镜尺寸｜运镜｜表演｜终止状态`

**时长 → 镜数换算**（以“一镜一核心动作”为前提）：

| 总时长 | 建议镜数 |
|---|---|
| 15 秒 | 4–6 镜 |
| 30 秒 | 8–12 镜 |
| 60 秒 | 15–25 镜 |
| 3 分钟 | 45–70 镜 |

**单镜默认时长**：3 秒；动作型可 1.5–4 秒；生活型可 3–6 秒。

以上换算式为缺省值，使用者指定时以其指定为准；使用默认值须标注 `[预设]`。

## 附录 C：QC 清单（含判定门槛）

| # | 检查项 | 检核方式 | 不合格处置 |
|---|---|---|---|
| 1 | 肢体畸变（手指数目、关节反折、四肢黏连） | 逐镜检 | 出现即退 → 重新生成 |
| 2 | 风格漂移（发型、发色、服装主色、标志物） | 逐镜比对锁定卡 | 任一不符即退 → 修 Prompt 重新生成 |
| 3 | 动作穿插（重心位移不连续、接触后位移方向反转） | 逐镜检 | 该镜重编动作五段 |
| 4 | 角色一致性（跨镜五官/服饰变异） | 每 5 镜抽检比对 | 不符 → 回写锚点重新生成 |
| 5 | 文字/logo 乱码 | 逐镜检 | 出现即退 |
| 6 | 物理受力失真（无反作用力、悬浮感） | 逐镜检 | 依维度 12 修正后重新生成 |
| 7 | 续写跳变（相邻镜起始状态与前镜终止状态错位） | 逐镜对照续写记录 | 依〈镜间视频续写（含 edit_video 降级）〉修正后重新续写 |

**QC 汇总规则**：每批产出须附**退镜清单**，记录 `镜号｜问题类型｜处置｜重生成结果`；退镜不计数回填，须逐条闭环。

## 镜间视频续写（含 edit_video 降级）

**目的**：让相邻镜在视频生成阶段真正接续，而非各自独立生成。

**首选路径（edit_video 可用时）**

- 前镜时长 **> 5 秒**：先用 `edit_video` 从前镜剪出**最后 5 秒**作为“尾段节点”，再由该尾段节点执行**视频续写（extend）**生成下一镜。
- 前镜时长 **≤ 5 秒**：无需剪裁，直接以前镜完整视频节点续写。

**降级路径（无 edit_video，或调用失败时）**

- 降级为**以前镜完整视频节点直接视频续写（extend）**。
- **不得**因缺少 `edit_video` 而中断制作，也**不得**擅自改为文生视频重做；如确需改变生成方式，须先向使用者确认。
- 降级时续写 Prompt **开头必须明示接续关系**，写法示例：
  `Continuation of the previous shot（接续前镜）｜起始状态：<前镜终止状态>｜不重演前情`
- **前镜 > 5 秒但无 edit_video 时**（无法剪尾段，5 秒门槛失效）：虽只能以前镜完整视频节点续写，仍须在续写 Prompt 开头明示**从尾段接续**，写法示例：
  `Continuation of the previous shot（接续前镜）｜从尾段接续｜起始状态：<前镜终止状态>｜忽略前镜前段已完成内容｜不重演前情`
  并要求模型**以「终止状态」为起点**、**忽略前镜前段已完成的内容**（不得把整段前情再演一遍，也不得把前镜早段动作当作本镜起点）。
- **禁止重演前情**：不得重复前镜已发生的动作、位移、台词与镜头运动；起始动作须衔接前镜的“终止状态”。
- 若降级导致起始状态错位，按附录 C 第 7 项处置。

**记录要求**

- 记录栏位统一为：`镜号｜续写方式｜是否降级｜原因`。
- **多集且 `series-state.md` 存在时**：回写该档的「视频续写方式记录」（模板第 10 节），并在步骤 7 的差异摘要中一并列出。
- **单集，或未启用 `series-state.md` 时**：**不强制写入状态档**，降级事实改记入交付物「视频续写记录」与该镜的任务记录。
- **未记录降级的镜不视为已闭环**（无论单集或多集）。

## 多集连续性与角色一致性

**系列状态档（Series State，外部状态档）**

- 位置：与项目同目录的 `series-state.md`，模板见 `references/series-state-template.md`。
- **每集开工前先读，收工后回写**；未回写不得开始下一集。
- 必须记录：系列名与集数、角色 Bible 版本、各角色最新状态（服装/伤势/情绪）、已登场场景、上一集结尾状态与时间点、未闭合伏笔、锁定卡版本，以及**视频续写方式与降级记录**。

**角色 ID 锁定卡**

- 每位角色固定 5–7 条不可变特征：脸型、发型+发色、瞳色、服装主色与标志物、武器、体型比例、声音基调。
- 每镜 Prompt **原样携带**该卡锚点字串，禁止同义改写、缩写或重排。
- 锁定卡一经建立即受版本管理；修改需使用者确认并记录版本号。

**变体规则**

- 换装、受伤、变身等写作 `base + variant(EpXX)`，明示为变体而非新角色。
- 变体只在可变特征栏生效，不可变特征不得改动。
- 变体状态若延续，必须写入状态档，并在下一集开播时继承。

**跨集接续检查**

比对上一集结尾状态 → 下一集开场：服装、伤势、所在场景、时间连续性（日/夜、时段）四项，任一不符须先向用户确认，不得自行圆场。

**漂移检查表**

抽检点：每集首镜 + 同一角色第 3 次登场镜；比对锚点字串与变体标记是否与状态档一致。

## 输出要求

- **分镜列表**：详细 ID、时长、镜头尺寸、运镜轨迹、表演细节、终止状态。
- **双语 Prompt**：适配主流 AI 生成工具的精准描述词串，携带角色锚点。
- **风格分工表**：12 维指派结果，含 `不适用` 标注。
- **角色 ID 锁定卡**：每角色 5–7 条不可变特征。
- **QC 清单 + 退镜清单**：依附录 C 判定与闭环。
- **后期规划**：包含转场、音效及调色建议。
- **视频续写记录**：各镜续写方式与降级事实、原因（`镜号｜续写方式｜是否降级｜原因`）。**单集或未启用 `series-state.md` 时，此项即为降级记录的唯一落点；多集时另回写状态档第 10 节。**
- **系列状态档更新差异摘要**（多集时）：新增角色、状态变化、未闭合伏笔、续写降级记录。

## 注意事项

- **一致性优先**：冲突发生时，身份与形态的一致性高于美学华丽度。
- **原子化叙事**：每镜通常仅处理一个核心动作，避免生成逻辑混乱。
- **严禁臆造**：对于未授权的创作范围、前情设定或不可逆的结果，必须先向用户确认选项。
- **能力缺失须降级并记录**：工具集缺少所需能力时，先降级、再记录（记录落点见〈镜间视频续写（含 edit_video 降级）〉），不停工、不隐瞒。
- **模板可用**：系列状态档模板见 `references/series-state-template.md`。
