# 迭代修复

## 作用

这个文件负责在 AI 短剧制作过程中诊断问题并给出修复路径。

它适用于：

图片生成不稳定
视频生成失败
人物或主体漂移
场景不统一
风格跑偏
分镜不连贯
剪辑后不像一部片
声音、字幕、节奏影响观看
用户不知道该重做还是局部修复

迭代修复的目标是尽量保住已经可用的部分，定位最小问题，做最小改动。

## 修复总原则

先判断问题类型，再动手改。
一次只改一个主要变量。
优先局部修复，不要马上推翻全部。
如果结构没问题，优先修画面或剪辑。
如果结构有问题，再回到故事和分镜。
保留可用素材，建立“可用/待修/废弃”清单。
每次修改都记录原因，避免越改越乱。

## 问题诊断顺序

按这个顺序判断：

```text
1. 故事是否看得懂？
2. 分镜是否连贯？
3. 人物/主体是否一致？
4. 场景和风格是否统一？
5. 单个镜头是否可用？
6. 剪辑节奏是否顺？
7. 字幕、声音、音乐是否干扰？
8. 是否符合交付要求？
```

不要先纠结单个画面瑕疵。先判断它是否影响成片理解。

## 素材分类

把素材分成三类：

```text
可用：可以进入粗剪。
待修：方向正确，但有局部问题。
废弃：方向错误，继续修成本太高。
```

判断标准：

可用素材：角色、场景、动作、情绪或信息基本满足镜头任务。
待修素材：主体正确，但有表情、动作、光线、构图或时长问题。
废弃素材：主体错误、风格完全不符、角色严重漂移、动作无法理解。

## 参考图审核

当用户发来参考图时，先判断它能不能进入图生视频，不要直接写视频提示词。

检查：

主角、主体或核心对象是否清楚稳定？
外观、服装、材质、比例或结构是否方便多镜头复用？
场景是否符合项目目标、时代感、空间层次和光线设定？
是否有明显 AI 味、过度精致、手部畸形、文字乱码或背景抢戏？
是否适合做视频运动，还是只适合作为静态海报？

输出格式：

```text
参考图判断：
可以继续用：
需要重生成：
适合做哪些镜头：
不适合做哪些镜头：
下一步：
```

如果参考图不稳定，先修参考图，不要进入图生视频。

## 视频片段审核

当用户发来视频片段时，先判断片段是否完成镜头任务。

检查：

这个片段对应哪个镜头任务？
主体是否漂移？
动作是否能看懂？
镜头运动是否过度？
时长是否够剪？
是否有严重穿帮？
是否能通过裁切、缩短、转场或调色保留？

输出格式：

```text
片段判断：
镜头任务是否完成：
可保留部分：
需要重做部分：
可用剪辑补救：
重生成提示词方向：
```

不要只评价“好看不好看”。先判断它能不能放进时间线。

## 人物或主体漂移

表现：

同一角色看起来像不同人。
年龄、发型、服装变化没有叙事理由。
主体形态或比例不稳定。
不同镜头画风差异过大。

修复方式：

回到视觉设定和角色卡。
重复使用同一张参考图。
固定年龄、身份、发型、服装和关键外貌特征。
减少镜头提示词中的人物描述变化。
用“同一位角色/同一主体”开头。
视频失败时，先重新生成静态关键帧，再做图生视频。

提示词修复：

```text
同一位{角色/主体}，保持相同外貌、服装、比例和风格，动作轻微变化，场景和色调保持一致
```

## 场景不统一

表现：

同一空间布局变化太大。
关键道具消失或乱变。
时间段和光线前后不一致。
生活层次或世界观突然变化。

修复方式：

建立或补全场景卡。
固定 2-3 个关键道具。
固定时间段、光线方向和色调。
减少提示词中的新道具。
对重复场景使用同一张场景参考图。

提示词修复：

```text
同一主场景，保持固定空间布局、固定关键道具、固定时间段和光线方向，画面风格统一
```

## 风格跑偏

表现：

有的镜头像广告片，有的像纪录片，有的像动画。
色调忽冷忽暖，没有叙事理由。
画面精致度不一致。
有的镜头过度风格化。

修复方式：

回到统一风格词。
删除互相冲突的风格词。
固定写实程度、色调和画面质感。
每个镜头复用同一段风格块。
如果某个镜头太突兀，先尝试调色和剪辑，再决定是否重做。

提示词修复：

```text
保持全片统一风格，低饱和色调，自然光，真实质感，克制镜头语言，不要风格跳变
```

## 表演或动作过度

表现：

表情太夸张。
动作太戏剧化。
角色突然强烈爆发。
情绪和前后镜头不匹配。

修复方式：

删除极端情绪词。
使用“轻微、克制、缓慢、短暂停顿、自然反应”等词。
把情绪转成小动作。
缩短镜头时长，避开过度动作部分。
用局部特写替代完整表演。

提示词修复：

```text
表演克制，动作轻微，情绪通过短暂停顿、视线变化和手部动作表达，不要夸张表情或强烈肢体动作
```

## 动作不连贯

表现：

角色动作跳变。
物体位置前后不一致。
一个动作无法从开始走到结束。
视频中出现奇怪变形。

修复方式：

把复杂动作拆成关键瞬间。
每个镜头只做一个动作。
用剪辑连接动作，不要求模型生成完整连续动作。
用道具特写、反应镜头或环境镜头做过渡。

替代方案：

```text
复杂动作：角色快速穿过人群
改写：角色站在人群边缘，下一镜头是脚步穿过地面，下一镜头是角色到达目标位置
```

## 提示词越改越乱

表现：

每次修改都引入新问题。
提示词越来越长，但结果越来越不稳定。
模型抓不到重点。

修复方式：

回到视觉设定。
删除无关形容词。
保留主体、动作、场景、情绪、镜头、光线六项。
一次只改一个变量。
保存上一版可用提示词。

简化模板：

```text
{主体}，{场景}，{一个动作}，{一个情绪/信息任务}，{景别}，{光线和色调}，{统一风格}
```

## 画面太空

表现：

画面没有可看的细节。
场景像模板背景。
主体和环境没有关系。

修复方式：

增加 2-3 个具体道具。
增加主体与道具的互动。
明确空间类型和生活/世界观细节。
使用更具体的景别和机位。

示例：

```text
不要只写“角色在房间里难过”。
改成“角色站在工作台旁，手停在未完成的物件上，背景有工具、屏幕和未整理的材料”。
```

## 画面太乱

表现：

主体太多。
道具太多。
背景抢戏。
观众不知道看哪里。

修复方式：

减少主体数量。
删除不必要道具。
明确视觉焦点。
用近景或特写。
降低背景复杂度。

提示词修复：

```text
画面简洁，单一视觉重点，背景不过度复杂，主体清晰，构图克制
```

## AI 味太重

表现：

皮肤和材质过度光滑。
场景过度精致。
光线不真实。
角色像模板人物。
画面像拼贴或宣传海报。

修复方式：

增加真实材质和普通细节。
降低过度电影化和过度精致感。
强调自然光、真实皮肤质感、具体空间。
删除“高级、震撼、史诗、极致”等空泛词。
使用更具体的身份、环境和动作。

## 分镜不连贯

表现：

单个镜头可看，但连起来不明白。
镜头之间没有因果。
中段重复同一种信息。
结尾没有回答开头。

修复方式：

给每个镜头写“任务”。
删除任务重复的镜头。
补一个建立镜头或结果镜头。
调整镜头顺序。
用字幕或声音补少量必要信息。

检查问题：

```text
这个镜头让故事前进了吗？
这个镜头提供了新信息吗？
这个镜头和前后镜头有什么关系？
如果删掉它，故事是否更清楚？
```

## 粗剪后节奏不顺

表现：

开头太慢。
中段拖。
结尾太快或太满。
情绪或信息没有呼吸。

修复方式：

开头 5 秒内给出视觉钩子或问题。
删除中段重复镜头。
重要信息多留 1-2 秒。
过渡镜头缩短。
结尾保留停顿，但不要拖长。

## 字幕和文字问题

表现：

字幕太密。
文字解释太多。
观众来不及看。
屏幕文字生成不可读。

修复方式：

可读文字后期添加。
每句字幕尽量短。
一屏只放一个主要信息。
删除画面已经表达的解释。
关键信息可用标题卡或屏幕信息处理。

## 声音和音乐问题

表现：

音乐太满。
声音压过台词或旁白。
情绪被音乐强行带走。
环境声缺失导致画面漂浮。

修复方式：

降低音乐音量。
增加适量环境声。
重要文字或台词处减少音乐复杂度。
音乐只辅助段落变化，不替代画面表达。
结尾可留短暂停顿。

## 需要重做的情况

以下情况建议重做，而不是继续修：

核心角色或主体完全错误。
镜头任务和画面完全不匹配。
风格与全片完全不同且调色无法修复。
动作变形严重影响理解。
镜头会误导故事。
修复成本高于重新生成。

重做前先保留：

可用提示词
可用参考图
正确的风格描述
失败原因

## 迭代输出模板

当用户说“生成结果不好”时，按这个格式回应：

```text
问题类型：

可能原因：

保留内容：

需要修改：

建议重生成方式：

改写后的提示词：

下一步检查：
```

## 修复优先级

优先修：

1. 影响看懂故事的问题
2. 影响角色/主体一致的问题
3. 影响场景和风格统一的问题
4. 影响剪辑节奏的问题
5. 轻微画面瑕疵

不要把轻微瑕疵放在结构问题前面。

## 版本管理建议

建议用户保留：

`v1_rough`
`v2_fix_story`
`v3_fix_visual`
`v4_sound_subtitle`
`final`

每次修改只记录一句：

```text
这版主要修：{问题}
```

这样可以防止改到后面找不到上一版。
