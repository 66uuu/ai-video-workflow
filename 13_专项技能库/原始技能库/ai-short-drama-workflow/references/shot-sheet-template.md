# 分镜表模板

## 作用

这个文件负责把故事结构转换成可执行的分镜表。

分镜表不是简单列画面，而是把每个镜头的任务、时长、生成方式、提示词和剪辑用途都确定下来。它应该让用户知道下一步要生成什么素材、怎么生成、怎么剪。

适用于：

用户已有故事结构，需要拆镜头
用户需要图片提示词和视频提示词
用户需要控制镜头数量
用户需要判断镜头是否可生成
用户需要进入剪辑前的素材规划

## 分镜表必填列

标准分镜表建议包含：

```text
镜头编号：
时间码：
时长：
段落作用：
画面内容：
主体/角色：
场景：
景别：
机位：
镜头运动：
主体动作：
情绪或信息任务：
台词/旁白/字幕/屏幕文字：
生成方式：
图片提示词：
视频提示词：
声音建议：
剪辑备注：
风险点：
```

如果用户需要更简洁，可以只输出：

```text
镜头编号 | 时长 | 画面 | 动作 | 情绪/信息任务 | 图片提示词 | 视频提示词 | 备注
```

## 分镜设计原则

每个镜头只承担一个主要任务。
每个镜头都要能生成。
镜头之间要有推进，而不是重复同一种信息。
开头镜头负责吸引或建立规则。
中段镜头负责推进、升级、对照或补充。
结尾镜头负责结果、余味或记忆点。
不要让字幕承担全部叙事。
不要为了炫技增加难生成镜头。

## 镜头任务类型

给每个镜头分配一个任务：

钩子：吸引观众继续看。
建立：交代人物、世界、目标或规则。
推进：让故事进入下一步。
升级：让阻碍、情绪或信息更强。
对照：展示前后、两方或两个状态差异。
暗示：埋下后续信息。
揭示：让观众理解新信息。
选择：主角或主体做出决定。
结果：展示行动后果。
收尾：留下记忆点或余味。

## 景别选择

常用景别：

远景：交代环境、空间关系、世界观。
全景：展示人物和动作。
中景：适合对话、行动和关系。
近景：适合情绪、反应和关键动作。
特写：适合道具、手部、眼神、屏幕、细节。

选择建议：

开场常用远景、中景或强视觉特写。
情绪变化常用近景和特写。
世界观展示常用远景和全景。
产品或关键道具常用特写。
行动推进常用中景或全景。

## 镜头运动选择

新手优先：

静止镜头
缓慢推进
轻微平移
轻微后退
简单跟随
从道具特写到人物近景

谨慎使用：

快速环绕
大范围航拍
连续追逐
大量角色调度
精确动作长镜头
复杂打斗

镜头运动应服务内容，不要每个镜头都动。

## 生成方式选择

按镜头难度选择：

```text
角色脸部一致要求高：优先参考图 -> 图生视频
场景一致要求高：优先场景参考图 -> 图生视频
环境空镜：可用文生视频
道具特写：可用文生图或图生视频
抽象意象：可用文生图/文生视频
需要可读文字：后期添加，不依赖生成模型
需要精确对白口型：谨慎使用，必要时单独规划
```

## 30 秒分镜模板

适合超短概念、广告钩子、社媒短片。

建议 3-5 个镜头：

```text
1. 钩子：强视觉或问题
2. 建立：人物/产品/规则
3. 变化：动作、反差或卖点
4. 结果：展示效果
5. 收尾：记忆点、标语或片名
```

注意：

只表达一个核心点。
镜头不要超过 5 个。
开头必须直接。

## 60 秒分镜模板

适合微短剧、单设定短片、小反转、情绪短片。

建议 5-7 个镜头：

```text
1. 钩子：异常、问题、强画面
2. 建立：人物、目标或规则
3. 推进：主体行动或信息出现
4. 升级：阻碍、压力或反差增强
5. 揭示/选择：关键信息或动作
6. 结果：变化后的状态
7. 收尾：余味或记忆点
```

如果用户是新手，优先 6 个镜头。

## 90 秒分镜模板

适合完整小剧情、轻设定、悬疑微反转、关系/成长/选择类故事。

建议 7-10 个镜头：

```text
1. 开场钩子
2. 建立主角/主体和处境
3. 触发事件
4. 第一次推进
5. 信息补充或对照
6. 升级或阻碍
7. 转折、揭示或选择
8. 结果
9. 收尾画面
```

如果故事信息量不大，压缩到 8 个镜头。

## 120 秒分镜模板

适合两个情节点、轻世界观、多场景但单主线短片。

建议 10-12 个镜头：

```text
1. 钩子
2. 世界/场景建立
3. 主体目标
4. 第一次行动
5. 第一次阻碍
6. 信息补充或对照
7. 第二次行动
8. 升级
9. 转折或选择
10. 结果
11. 回扣
12. 收尾
```

注意：

不要把 120 秒变成 12 个互不相干的漂亮镜头。
每 2-3 个镜头必须有一次推进。

## 分镜表输出格式

推荐用 Markdown 表格。

简洁版：

```md
| 镜头 | 时间 | 画面 | 动作 | 任务 | 生成方式 | 备注 |
|---|---:|---|---|---|---|---|
| 1 | 0-8s |  |  |  |  |  |
```

完整版：

```md
| 镜头 | 时间 | 段落作用 | 画面内容 | 景别/机位 | 动作 | 情绪/信息任务 | 文字/声音 | 生成方式 | 图片提示词 | 视频提示词 | 风险 |
|---|---:|---|---|---|---|---|---|---|---|---|---|
| 1 | 0-8s | 钩子 |  |  |  |  |  |  |  |  |  |
```

如果表格太宽，可以按镜头逐条输出。

逐条格式：

```text
镜头 1｜0-8 秒｜钩子
画面：
景别/机位：
动作：
任务：
文字/声音：
生成方式：
图片提示词：
视频提示词：
风险：
```

## 分镜可生成性检查

每个镜头输出前检查：

是否需要太多角色同时互动？
是否需要精确口型？
是否需要复杂连续动作？
是否需要模型生成可读文字？
是否需要角色高度一致？
是否缺少参考图？
是否只有抽象情绪，没有具体动作？

如果镜头不可控，改写成更可生成的形式：

```text
复杂动作 -> 关键动作瞬间
长对白 -> 字幕/旁白/屏幕文字后期添加
多人调度 -> 主体反应 + 局部细节
大场面 -> 标志性局部 + 声音/剪辑暗示
抽象情绪 -> 手部动作、停顿、视线、道具变化
```

## 分镜节奏检查

粗略判断每个镜头时长：

特写和道具镜头：2-5 秒
情绪反应镜头：4-8 秒
环境建立镜头：3-6 秒
行动推进镜头：5-10 秒
结尾留白镜头：5-10 秒

注意：

不要所有镜头时长一样。
重要情绪或信息需要多留 1-2 秒。
过渡镜头要短。
结尾可以慢一点，但不能拖。

## 声音和文字规划

分镜表应提前标注：

哪些地方需要旁白
哪些地方需要字幕
哪些地方需要屏幕文字
哪些地方只需要环境声
哪些地方需要音乐进入或退出

原则：
可读文字尽量后期添加。
声音不要补救结构问题。
旁白不要重复画面已经表达的内容。
音乐变化要配合段落变化。

## 单镜头时间轴细分模板（进阶）

当需要更精细的镜头控制时，可将单个10秒镜头按时间轴拆分为4段，每段包含镜头+音效+台词，确保节奏精准。

### 时间轴四段式结构

```text
[0-3秒] 镜头：[景别]+[镜头]+[核心动作]；音效：[主音效]+[环境音]；[台词/画外音]
[3-6秒] 镜头：[景别]+[镜头]+[互动反应]；音效：[关键音效]；[台词/画外音]
[6-8秒] 镜头：[景别]+[镜头]+[情绪特写]；音效：[氛围音]；[画外音/沉默说明]
[8-10秒] 镜头：[景别]+[镜头]+[下一镜铺垫]；音效：[过渡音]
```

### 各段作用说明

| 时间段 | 作用 | 重点 |
|---|---|---|
| 0-3秒 | 钩子/建立 | 抓住注意力，交代核心画面 |
| 3-6秒 | 推进/互动 | 展示动作、关系或信息变化 |
| 6-8秒 | 情绪/特写 | 强化感受，给观众反应时间 |
| 8-10秒 | 过渡/铺垫 | 自然衔接下一个镜头 |

### 台词时段规则

有台词的镜头必须遵守：
台词时段镜头固定，不切换、不推拉
仅当前说话角色有张嘴动作
嘴唇动作需要和台词同步
不是当前角色台词，不要有张嘴、喉部动等疑似发声动作
台词用中文引号标注

### 音效分层规划

每个镜头音效分三层：
**主音效**：当前动作的核心声音（脚步声、倒水身、说话声等）
**环境音**：场景背景声（风声、鸟鸣、人群嘈杂等）
**过渡音**：衔接上下镜头的声音（音乐渐入、音效延续等）

### 时间轴分镜输出格式

当用户需要精细时间轴时，按以下格式输出单个镜头：

```text
分镜头N：
[0-3秒] 镜头：[景别]，[机位/运镜]，[核心动作]，说："[台词]"；音效：[主音效]+[环境音]
[3-6秒] 镜头：[景别]，[机位/运镜]，[互动反应]；音效：[关键音效]
[6-8秒] 镜头：[景别]，[机位/运镜]，[情绪特写]；音效：[氛围音]
[8-10秒] 镜头：[景别]，[机位/运镜]，[下一镜铺垫]；音效：[过渡音]
场景：[完整场景描述，一字不改复用]
```

### 时间轴使用建议

适合：对白戏、情绪戏、需要精准节奏的镜头
不适合：纯环境空镜、快速蒙太奇、大场面远景
新手先用粗分镜，熟练后再做时间轴细分
时间轴越细，剪辑时越省力，但生成时需要的控制也越多
优先给核心情绪镜头、关键对白镜头做时间轴细分

## 常见分镜问题

问题：镜头很多，但故事不推进。

修复：

给每个镜头写“任务”。
删除任务重复的镜头。
每 2-3 个镜头必须有新信息或新变化。

问题：每个镜头都很好看，但不像一部片。

修复：

统一主场景、色调和角色设定。
增加开头和结尾的呼应。
检查镜头顺序是否有因果或递进。

问题：镜头太难生成。

修复：

拆成关键帧。
用剪辑表现连续动作。
用局部特写替代复杂调度。
用声音或字幕补充不可生成的信息。

问题：故事信息太多。

修复：

删除支线。
把背景压成 1-2 个镜头。
把解释放到旁白或字幕，但不要过量。
只保留一个主要转折。

## 输出前检查

输出分镜表前确认：

是否符合目标时长？
镜头数量是否合理？
每个镜头是否有任务？
生成方式是否清楚？
是否需要参考图？
是否已经标注文字和声音？
是否有明显难生成镜头？
是否有开头、中段、结尾？
