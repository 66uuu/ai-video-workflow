# 故事结构

## 作用

这个文件负责帮助用户把创意、题材或故事素材整理成适合 AI 生成的短片结构。

它服务所有类型的 AI 短剧和剧情短片，不默认任何具体题材。使用时先判断用户目标，再选择结构。

适用场景：

用户只有一个创意，需要变成故事
用户故事太长，需要压缩
用户要做 30 秒、60 秒、90 秒、120 秒或更长短片
用户需要剧情、情绪、悬疑、科幻、奇幻、广告、知识科普、社会议题等不同结构
用户需要把真实经历、小说片段、品牌需求或概念设定改成可生成的视频

## 结构选择总原则

选择结构前，先判断四件事：

```text
目标时长：
作品类型：
观众需要看懂什么：
最后要留下什么感受：
```

结构不是为了装满信息，而是为了让观众在有限时间内获得清楚的观看路径。

优先选择：

能在目标时长内讲完的结构
符合用户制作能力的结构
适合 AI 生成的结构
能形成明确开头、中段、结尾的结构

避免：

一支短片同时使用太多结构
用复杂时间线掩盖主题不清
把全部背景信息塞进前半段
只追求反转，忽略角色和情绪

## 按时长选择结构

### 15-30 秒结构

适合：

超短社媒视频
概念预告
单个视觉点子
广告钩子
氛围片段

推荐结构：

```text
0-5 秒：视觉钩子
5-15 秒：核心动作或信息
15-25 秒：变化、反差或记忆点
25-30 秒：标语、片名、产品点或情绪落点
```

镜头数建议：3-5 个。

重点：

只表达一个点。
不要讲复杂背景。
画面必须快速建立识别度。

### 45-60 秒结构

适合：

微短剧
情绪短片
小反转
产品概念片
单设定科幻/奇幻片

推荐结构：

```text
0-8 秒：钩子或异常
8-20 秒：交代人物、目标或规则
20-40 秒：推进变化或制造压力
40-52 秒：转折、揭示或完成动作
52-60 秒：收尾画面或记忆点
```

镜头数建议：5-7 个。

重点：

保留一条主线。
只设置一个主要变化。
结尾要有明确画面，不只靠解释。

### 75-90 秒结构

适合：

有完整起承转合的小剧情
人物关系类剧情
悬疑微反转
成长/选择类故事
概念设定稍复杂的短片

推荐结构：

```text
0-15 秒：触发事件
15-35 秒：目标、困境或规则建立
35-60 秒：升级、对照或关键信息补充
60-78 秒：转折或主角选择
78-90 秒：结果和余味
```

镜头数建议：7-10 个。

重点：

允许有一层背景补充。
中段必须有推进，不要只是解释。
结尾要回答开头提出的问题。

### 100-120 秒结构

适合：

两个情节点的剧情短片
轻世界观设定
多场景但单主线故事
需要铺垫的广告或概念片

推荐结构：

```text
0-15 秒：钩子和主角
15-35 秒：目标或规则
35-60 秒：第一次推进或失败
60-85 秒：第二次推进、反差或新信息
85-105 秒：选择、揭示或完成
105-120 秒：收尾和记忆点
```

镜头数建议：10-12 个。

风险：

容易变成流水账。
容易解释过多。
容易超过新手可控范围。

### 3-5 分钟结构

适合：

更完整的剧情短片
客户宣传片
多段式叙事
作品集主片

推荐结构：

```text
开场：建立人物、世界或问题
第一段：目标出现
第二段：阻碍升级
第三段：选择或反转
第四段：结果和回声
```

注意：

需要更强的脚本、镜头连续性和剪辑能力。
不建议小白第一支作品直接做 3 分钟以上。
必须先做详细分镜和制作排期。

## 按叙事机制选择结构

### 单事件结构

适合：

一个选择
一次任务
一次误会
一个发现
一个小目标

结构：

```text
事件出现 -> 主角行动 -> 阻碍出现 -> 结果出现 -> 余味
```

优点：

清楚、好生成、适合新手。

风险：

如果事件太小，容易无聊。
需要一个清楚的结果画面。

### 目标任务结构

适合：

冒险
科幻
奇幻
广告任务
游戏感短片
行动驱动剧情

结构：

```text
主角得到目标 -> 遇到阻碍 -> 尝试解决 -> 关键变化 -> 完成或失败
```

适合 AI 的做法：

把动作拆成少量关键瞬间。
避免复杂连续打斗或追逐。
用道具、环境和剪辑表现任务推进。

### 反转结构

适合：

悬疑
黑色幽默
科幻设定
广告记忆点
社媒传播

结构：

```text
建立预期 -> 加强预期 -> 暗示异常 -> 揭示真相 -> 回看前文有意义
```

注意：

反转必须提前埋线索。
不要只靠最后一句文字解释。
反转后画面要成立。

### 对照结构

适合：

前后变化
两种选择
两个世界
两种身份
产品使用前后

结构：

```text
A 状态 -> B 状态 -> 差异扩大 -> 关键原因出现 -> 结论或选择
```

适合 AI 的做法：

用色调、场景、服装或构图区分两个状态。
避免同时开太多对照维度。

### 递进结构

适合：

情绪升高
危机升级
任务难度升级
怪异现象变强
产品卖点逐层展开

结构：

```text
轻微变化 -> 明显变化 -> 无法忽视 -> 关键爆发 -> 结果
```

注意：

每一段都要比上一段更强。
不要让中段重复同一种信息。

### 回环结构

适合：

开头结尾呼应
命运感
时间循环
成长后再看同一物件
品牌主张回扣

结构：

```text
开头画面/台词 -> 中段改变理解 -> 结尾回到相同画面/台词但意义改变
```

注意：

开头的元素要简单、清楚。
结尾必须让观众理解意义变化。

### 世界观展示结构

适合：

科幻
奇幻
未来城市
架空设定
概念预告

结构：

```text
世界规则 -> 角色进入 -> 规则影响角色 -> 异常或冲突 -> 记忆点收尾
```

注意：

只保留一个核心设定。
设定要通过画面体现，不要只靠文字解释。
角色仍然要有目标或反应。

### 旁白意象结构

适合：

情绪短片
诗性影像
抽象主题
视觉实验
片头或概念片

结构：

```text
主题句 -> 意象一 -> 意象二 -> 意象三 -> 主题回扣
```

注意：

意象之间要有递进。
旁白不要连续堆金句。
每个意象都要服务主题。

## 按作品类型选择结构

### 剧情短片

优先结构：

单事件结构
目标任务结构
对照结构
回环结构

核心问题：

主角想要什么？
阻碍是什么？
最后发生了什么变化？

### 情绪短片

优先结构：

递进结构
旁白意象结构
回环结构
单事件结构

核心问题：

观众要感受到什么？
情绪从哪里开始？
结尾如何落下？

### 悬疑/惊悚短片

优先结构：

反转结构
递进结构
世界规则结构

核心问题：

观众一开始以为什么？
哪些细节暗示不对劲？
真相出现后是否能回看前文？

### 科幻/奇幻短片

优先结构：

世界观展示结构
目标任务结构
对照结构
回环结构

核心问题：

唯一核心设定是什么？
这个设定如何影响角色？
画面上如何看出设定？

### 广告/品牌概念片

优先结构：

问题 -> 解决
使用前 -> 使用后
任务完成
视觉记忆点递进

核心问题：

观众要记住什么？
产品或品牌在故事里承担什么作用？
结尾是否有明确记忆点？

### 知识/科普剧情化短片

优先结构：

问题提出
错误理解
关键信息
例子展示
结论回扣

核心问题：

要讲清哪个知识点？
哪个误区最适合戏剧化？
画面如何辅助理解？

### 社会议题短片

优先结构：

一个普通人的一天
具体困境
对照结构
单事件结构

核心问题：

不要试图讲完整社会问题。
只聚焦一个具体人物或具体场景。
让观众先看见处境，再理解观点。

## 按素材来源选择结构

### 用户只有一句创意

处理：

```text
创意 -> 类型判断 -> 目标观众感受 -> 选择结构 -> 一句话梗概
```

输出：

3 个可选方向
每个方向一个结构
每个方向一个结尾画面

### 用户有完整故事

处理：

```text
故事复述 -> 找主线 -> 删支线 -> 选结构 -> 分段
```

输出：

主线
可删内容
可转为背景的信息
推荐结构
目标时长

### 用户有小说片段

处理：

```text
找场景 -> 找人物目标 -> 找冲突 -> 找可视化动作 -> 压缩成镜头
```

注意：

不要照搬大量心理描写。
把心理活动转成动作、道具、空间和旁白。

### 用户有品牌需求

处理：

```text
品牌目标 -> 受众 -> 产品/服务作用 -> 故事包装 -> 记忆点
```

注意：

不要让剧情淹没品牌目标。
不要把广告做成纯口播。

### 用户有真实经历

处理：

```text
真实事件 -> 核心变化 -> 可视化场景 -> 结构选择 -> 保护隐私和复杂性
```

注意：

不必照搬真实顺序。
保护当事人隐私。
保留复杂性，不把人物简单脸谱化。

## 新手推荐结构

如果用户是小白，优先推荐：

单事件结构
目标任务结构
对照结构
回环结构
旁白意象结构

谨慎推荐：

多线叙事
复杂非线性
多主角群像
高强度动作戏
精确口型对白
大规模世界观解释

## 结构输出模板

当用户需要结构建议时，按这个格式输出：

```text
推荐结构：

为什么适合：

目标时长：

故事分段：
0秒：
秒秒：
秒秒：
秒秒：

建议镜头数：

最重要的画面：

最容易翻车的地方：

下一步：
```

## 结构检查

任何结构确定后，检查：

开头是否清楚？
中段是否推进？
结尾是否有结果或余味？
主角、主体或核心对象是否明确？
观众是否知道自己在看什么？
是否能在目标时长内完成？
是否适合 AI 生成？
是否需要过多口型对白或复杂连续动作？

如果检查不过，先改结构，不要进入分镜和提示词阶段。
