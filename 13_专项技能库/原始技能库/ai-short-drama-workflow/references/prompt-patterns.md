# 提示词模板

## 作用

这个文件负责把故事、视觉设定和分镜转换成可用于图像生成、关键帧生成、图生视频和文生视频的提示词。

它适用于：

生成角色参考图
生成产品、空间、活动装置、道具或概念对象参考图
生成场景参考图
生成关键帧图片
生成图生视频提示词
生成文生视频提示词
编写反向词
保持角色、场景、风格一致
修复提示词导致的跑偏问题

提示词不是越长越好。好的提示词应该清楚、稳定、可控，并且服务分镜任务。

## 基本原则

先有视觉设定，再写镜头提示词。
先写图片提示词，再写视频提示词。
图片提示词负责“画面是什么”。
视频提示词负责“画面怎么动”。
同一角色、同一场景、同一风格要复用固定描述。
每个提示词只解决当前镜头的任务，不要把整部片的信息都塞进去。
如果生成结果跑偏，一次只改一个变量。

## 提示词组装顺序

建议按这个顺序组装：

1. 固定视觉设定
2. 当前镜头主体
3. 场景和时间
4. 动作
5. 情绪、信息状态或卖点状态
6. 景别和机位
7. 光线和色调
8. 画面质感
9. 风格约束
10. 反向词

通用格式：

```text
{固定视觉设定}，{主体}，{场景和时间}，{动作或展示状态}，{情绪/信息状态/卖点状态}，{景别/机位}，{光线/色调}，{画面质感}，{风格约束}

反向词：{不想要的内容}
```

## 提示词标准结构公式（必用）

生成稳定视频提示词的黄金公式，按此顺序组装可大幅降低画面漂移、肢体畸形、风格跳变的概率：

```text
主体细节 + 缓慢连续动作 + 场景环境 + 光影 + 景别 + 运镜 + 风格色调 + 画质稳定约束
```

各模块说明：

| 模块 | 作用 | 必选 | 示例 |
|---|---|---|---|
| 主体细节 | 锁定人物/物体外观，保证一致性 | ✅ | 同一位年轻女生，穿着白色连衣裙，长发披肩 |
| 缓慢连续动作 | 描述运动方式，必须用安全动作词 | ✅ | 缓慢转身，发丝随风轻微飘动 |
| 场景环境 | 交代空间背景，锚定画面 | ✅ | 站在海边，远处有落日 |
| 光影 | 决定画面氛围和质感 | ✅ | 黄昏暖金色逆光 |
| 景别+运镜 | 控制画面构图和镜头运动 | ✅ | 中近景，镜头缓慢平稳推进 |
| 风格色调 | 统一视觉风格 | ✅ | 电影氛围感，暖色调 |
| 画质稳定约束 | 防止AI跑偏的保底词 | ✅ | 4K超清，画面流畅稳定，人物五官面部全程不变 |

注意：
动作必须从「通用安全动作词」中选择，禁止使用大幅度动作
画质稳定约束词必须放在提示词末尾，作为保底约束
每个模块用逗号分隔，不要用长句，保持关键词堆叠形式

## 通用安全动作规范（必用）

视频生成中，动作越大越容易穿模变形。**必须从安全动作词中选择，禁止使用大幅度动作。**

### 安全通用动作词（优先选用）

人物动作：
缓慢转身
轻轻抬手
缓缓抬头
慢慢低头
脚步缓慢挪动
嘴角轻微上扬
眼神缓缓移动
呼吸轻微起伏
手指轻轻松开/握紧
身体微微前倾/后仰
发丝随风轻微飘动
衣袖随风轻微飘动

环境动作：
树叶缓缓飘落
水面轻微泛起涟漪
烟雾缓慢飘散
云雾缓慢流动
火焰轻轻摇曳
窗帘随风轻微晃动
尘埃缓缓飘落
雨滴轻轻落下

镜头运动：
镜头缓慢推进
镜头缓慢拉远
镜头轻微平移
镜头缓慢环绕
固定平稳镜头
镜头缓慢升起/降下

### 严格禁止动作（绝对不能写）

❌ 快速奔跑
❌ 剧烈跳舞
❌ 多人打斗
❌ 大幅度跳跃
❌ 频繁肢体变换
❌ 高难度动作
❌ 快速转头/转身
❌ 剧烈情绪爆发
❌ 复杂手部动作
❌ 多人复杂互动

注意：
一个镜头只做一个主要动作，不要同时多个动作
动作幅度越小，生成越稳定
情绪表达优先用眼神和微表情，不用大动作
实在需要大动作，用多个镜头拼接，不要一个镜头完成

## 通用风格块

风格块用于让所有镜头保持在同一个视觉世界里。

模板：

```text
题材类型，写实程度，文化/时代/空间背景，情绪气质，光线方向，色调，镜头语言，画面质感，质量约束
```

示例结构：

```text
现实主义短片，日常空间，克制情绪，低饱和色调，自然光，生活细节真实，中近景和特写为主，画面统一，真实皮肤质感
```

注意：

不要每个镜头换一种风格块。
不要堆太多互相冲突的风格词，例如"纪录片、广告大片、梦幻动画、超写实电影感"同时出现。
风格词要和故事类型一致。

### 画质与镜头语言

画质词：
4K超清

镜头语言：
电影级构图

手持跟拍质感

长镜头质感

使用原则：
一个项目选定1-2个光影词，全程复用
一个项目选定1种主风格，不要混搭
画质词统一放在提示词末尾
风格词要与故事题材匹配

## 角色或主体参考图提示词

角色或主体参考图用于锁定人物、产品、空间、装置、道具、怪物、载具或概念对象的外观。它应该比单镜头提示词更稳定、更正面、更清楚。

模板：

```text
{年龄}，{身份}，{外貌特征}，{发型}，{体型}，{服装}，{妆容/质感}，{情绪基调}，{背景}，{光线}，{景别}，{风格}

反向词：不要换脸，不要夸张表情，不要过度磨皮，不要风格化过强，不要不符合身份的服装
```

填写要求：

年龄、身份、发型、服装必须明确。
外貌要有辨识度，但不要写成过度美化。
情绪基调要适中，参考图不要生成极端表情。
背景尽量简单，避免干扰角色识别。
如果角色有多个时间线，分别生成不同阶段参考图。
如果主体不是人物，必须写清形态、材质、颜色、尺度、关键结构、使用场景和禁止误画的细节。

非人物主体模板：

```text
{对象类型}，{核心功能或信息作用}，{形态和轮廓}，{材质}，{颜色}，{尺度}，{关键结构/关键细节}，{使用场景}，{光线}，{景别}，{统一风格}

反向词：不要改变主体比例，不要增加无关结构，不要误画品牌或标识，不要材质漂移，不要背景抢主体
```

多时间线角色模板：

```text
同一角色，{时间线/年龄阶段}，保留相同面部特征和气质，改变符合时间线的发型、服装和状态，背景简洁，真实光线，半身参考图
```

## 配角、辅助对象或环境元素参考图提示词

配角、辅助对象或环境元素要服务关系、功能和信息层级，不需要抢主角或核心主体。

模板：

```text
{角色关系/功能}，{年龄段}，{身份或职业背景}，{外貌和服装}，{性格气质}，{对主角的态度}，{背景简洁}，{自然光}，{半身或中景}，{统一风格}
```

非人物辅助元素模板：

```text
{辅助对象类型}，{与核心主体的关系}，{形态/材质/颜色}，{出现位置}，{信息作用}，{不抢主体}，{统一风格}
```

注意：

配角不要脸谱化。
配角不要简单写成“坏人”“反派”“冷漠的人”。
如果配角只在一个镜头出现，可以减少细节。
如果配角反复出现，必须建立固定描述。

## 场景参考图提示词

场景参考图用于锁定空间、道具、光线和生活层次。

模板：

```text
{场景类型}，{时间}，{空间大小}，{生活/社会层次}，{关键道具}，{光线}，{色调}，{氛围}，{镜头视角}，{画面质感}

反向词：不要不符合设定的装饰，不要过度豪华，不要空泛背景，不要风格跳变
```

填写要求：

至少写 2-3 个固定道具。
写清时间和光线，例如清晨、午后、夜晚、室内弱光、窗边自然光。
写清空间层次，例如普通居住空间、学校、办公室、公共交通、未来实验室、传统街巷。
如果场景会多次出现，提示词必须保留固定道具和光线。

## 关键帧图片提示词

关键帧用于生成视频前的核心画面。它应该对应分镜中的一个明确情绪点、信息点、动作点或卖点展示点。

模板：

```text
{固定视觉设定}，{角色/主体/核心对象}，{场景}，{动作或展示状态}，{情绪变化/信息变化/卖点变化}，{视觉意象或关键道具}，{景别}，{机位}，{光线和色调}，{画面质感}

反向词：{根据项目添加}
```

示例结构：

```text
同一位主角，站在固定主场景中，手停在某个关键道具旁，表情克制，情绪刚刚发生变化，中近景，轻微侧面机位，低饱和色调，自然光，现实主义短片质感
```

关键帧检查：

是否能看出主角是谁？
是否能看出场景在哪里？
是否能看出这一镜头的情绪、信息、任务或卖点作用？
是否方便做图生视频？
是否和前后镜头风格一致？

## 图生视频提示词

图生视频提示词重点描述运动，不要重复堆静态外貌。

模板：

```text
保持角色/主体外观、结构、场景和色调一致。主体{动作或状态变化}，情绪/信息/卖点从{起始状态}变化到{结束状态}。镜头{运动方式}。环境中{轻微变化}。整体节奏{快/慢/克制/紧张/舒缓/清晰}。
```

常用角色动作：

缓慢抬头
轻轻低头
停顿后转身
手指松开
拿起或放下某个物件
走过一段空间
看向屏幕或窗外
在人群中停住
呼吸变慢
表情轻微变化

常用镜头运动：

静止镜头
缓慢推进
轻微后退
轻微平移
从手部特写切到脸部近景
跟随角色缓慢移动

常用环境变化：

灯光轻微变化
窗帘或衣角轻微晃动
屏幕亮起或暗下
人群背景轻微流动
雨水、风、尘埃、蒸汽等轻微运动

常用非人物主体变化：

产品指示灯轻微亮起
关键部件轻微展开或闭合
空间灯光从入口延伸到核心区域
人流或使用痕迹轻微流动
示意元素按顺序出现
信息层级从模糊变清楚

注意：

不要要求复杂连续动作。
不要让同一镜头承载太多运动。
不要要求精确口型，除非用户明确需要。
动作越小，越容易稳定。

## 文生视频提示词

文生视频适合没有参考图、或只需要氛围镜头和过渡镜头的情况。

模板：

```text
{题材和风格}，{角色或主体}，{场景}，{动作}，{情绪}，{镜头运动}，{光线和色调}，{画面质感}，{时长感}

反向词：不要人物漂移，不要风格跳变，不要夸张动作，不要不符合场景的元素
```

适合文生视频的镜头：

环境空镜
过渡镜头
道具特写
背影远景
氛围镜头
不需要固定角色脸部的镜头

不适合文生视频的镜头：

需要主角高度一致的脸部特写
多角色复杂互动
需要准确动作连续性的镜头
需要精确口型的镜头

## 台词/旁白/字幕提示

如果镜头需要文字表达，先决定文字属于哪一种：

旁白：适合内心独白和主题表达。
字幕：适合补充信息或保留台词。
屏幕文字：适合消息、通知、搜索、记录、任务界面。
口型对白：最难控制，除非用户明确需要，否则不作为默认方案。

写提示词时不要强求模型准确生成文字。屏幕文字、字幕和消息内容通常应在剪辑工具中后期添加。

推荐写法：

```text
手机屏幕亮起，但屏幕文字后期添加，不要求模型生成可读文字。
```

## 画质稳定约束词（必加）

每个提示词末尾必须加入稳定约束词，这是防止AI跑偏的保底机制。根据镜头类型选择对应约束词。

### 通用稳定约束（所有镜头必加）

```text
4K超清，画面流畅稳定，无抖动模糊，无畸形穿模，细节清晰，色彩自然
```

### 人物镜头稳定约束

有人物出现的镜头，在通用约束基础上追加：

```text
人物五官面部全程不变，服饰发型统一，手部正常无畸形，身体比例正常
```

### 场景镜头稳定约束

风景、空镜、场景类镜头，在通用约束基础上追加：

```text
场景结构稳定，空间布局一致，无闪烁跳变，细节层次丰富，无杂物水印
```

### 产品/物体镜头稳定约束

产品展示、道具特写类镜头，在通用约束基础上追加：

```text
物体形态比例稳定，材质质感统一，无反光畸变，边缘清晰锐利，无变形扭曲
```

### 视频生成专用稳定约束

图生视频或文生视频时，额外追加：

```text
画面丝滑无闪烁，运动自然流畅，无卡顿跳帧，前后帧一致，风格统一
```

使用规则：
稳定约束词统一放在提示词最后
人物镜头必须加人物稳定约束
视频生成必须加视频稳定约束
约束词不是越多越好，选3-5个最关键的即可

## 反向词模板

通用反向词：

```text
不要夸张表情，不要过度磨皮，不要人物变脸，不要手部畸形，不要风格跳变，不要不符合设定的场景，不要过度表演，不要广告大片感，不要卡通风格，除非用户明确要求
```

角色一致性反向词：

```text
不要换脸，不要改变发型，不要改变服装，不要年龄突然变化，不要妆容突然变化，不要表情夸张
```

场景一致性反向词：

```text
不要改变空间布局，不要改变关键道具，不要改变时间段，不要突然出现无关物品，不要过度豪华或过度空旷
```

情绪克制反向词：

```text
不要强烈情绪爆发，不要激烈争吵，不要戏剧化崩溃，不要夸张肢体动作，不要用力过猛
```

写实质感反向词：

```text
不要塑料皮肤，不要网红滤镜，不要过度锐化，不要过度梦幻，不要悬浮精致感，不要不真实的光影
```

## 六维一致性准则（分镜必检）

生成连续分镜时，必须从六个维度检查前后镜头的一致性，避免出现穿帮、跳变、逻辑断裂。

| 维度 | 检查内容 | 要求 |
|---|---|---|
| 人物一致 | 出场角色必须严格匹配角色信息库 | 未出现的角色绝不写入 |
| 时空一致 | 相邻分镜的时间、地点、光线 | 必须无缝衔接，不能突然跳变 |
| 物品一致 | 关键道具的位置、状态 | 需延续上一镜头的状态 |
| 动作连贯 | 新分镜的起始动作 | 必须承接上一镜的结束状态 |
| 台词合规 | 说话角色的嘴部动作 | 仅当前说话角色有张嘴动作 |
| 敏感过滤 | 违禁词、敏感内容 | 自动过滤替换，保持剧情逻辑 |

一致性检查清单（每个新镜头前必过）：
1. 人物：上一镜有哪些人？这一镜应该有哪些人？
2. 时间：现在是早晨/中午/黄昏/夜晚？与上一镜是否连续？
3. 地点：在什么地方？空间布局与上一镜是否一致？
4. 光线：光线方向、色调、强度与上一镜是否统一？
5. 道具：关键物品在什么位置？状态有没有变化？
6. 动作：上一镜结束时人物在做什么？这一镜应该从什么动作开始？

## 3秒决策原则（生成前必检）

输出每个分镜提示词前，用3秒快速检查三项：

✅ **人物是否齐全？** — 严格映射角色信息，未出现角色绝不写入
✅ **场景是否连贯？** — 时间（晨/午/晚）、地点、光线必须与上一镜一致
✅ **有无违禁内容？** — 自动过滤血腥/低俗/政治敏感词

任一条件不满足，立即中止并重新推理。

## 分镜生成四步法

生成连续分镜的标准流程：

### STEP 1：场景锚定
提取当前文案的时间/地点/人物三大核心要素，确定本镜头的基本场景。

### STEP 2：连续性检查
比对上一镜头的结尾状态：
上一镜最后人物在做什么动作？
上一镜最后场景是什么状态？
上一镜最后有哪些道具和人物？
本镜应该从什么状态开始？

### STEP 3：台词植入
仅当文案包含对话时添加台词字段：
用中文引号标注台词内容
标注哪个角色在说话
台词时段镜头固定，不切换、不推拉
非说话角色不要有嘴部动作

### STEP 4：敏感扫描
自动检查并替换违禁词：
用中性词保持剧情逻辑
血腥暴力用暗示替代直白描写
敏感内容用间接方式表达
保持故事完整性的同时合规

## 违禁词过滤与替换规则

### 替换总原则
保持剧情逻辑不变，用中性/暗示/间接的表达方式替换违禁词。

### 血腥暴力类（重点屏蔽）

| 违禁词 | 替换方案示例 |
|---|---|
| 血液飞溅、喷血、鲜血淋漓 | 衣领有红痕、嘴角渗红、身上有污渍 |
| 血腥场面、血肉模糊 | 场面惨烈、现场一片狼藉、战况激烈 |
| 分尸、碎尸、斩首、砍头 | （删除直白描写，用结果暗示） |
| 断肢、爆头、穿刺 | 身负重伤、倒下不起、失去意识 |
| 屠杀、灭门、尸横遍野 | 伤亡惨重、所剩无几、几乎全军覆没 |
| 内脏外露、残肢断臂 | 伤势严重、无法行动、奄奄一息 |

替换原则：
保留"受伤/死亡"的剧情结果
删除具体的血腥细节描写
用远景、剪影、反应镜头替代特写
用声音暗示替代视觉直白描写

### 裸露低俗类（重点屏蔽）

| 违禁词 | 替换方案示例 |
|---|---|
| 全裸、半裸、一丝不挂 | 衣衫单薄、衣着简朴、（删除相关描写） |
| 性感暴露、低俗姿势 | （删除，改用气质/神态描写） |
| 色情、淫秽、性暗示 | （直接删除，用情感/关系描写替代） |

替换原则：
剧情必要的身体描写用衣物、光影遮挡
低俗暗示全部删除，改用情感表达
医学/正常场景的身体描写保留但避免低俗化

### 其他高危敏感词

| 类别 | 处理方式 |
|---|---|
| 封建迷信强化版 | 弱化恐怖描写，改为传说/习俗/仪式 |
| 危害公序良俗 | 删除具象化场景，用结果暗示 |
| 敏感宗教/政治 | 全部删除，改用中性历史/文化表述 |
| 血腥祭祀、活人献祭 | 改为古老仪式、传统祭祀（删除血腥细节） |
| 僵尸吸血、食人恶鬼 | 改为传说中的异兽、先民信奉的神灵 |

### 替换检查
替换后确认：
1. 剧情逻辑是否完整？
2. 人物动机是否清晰？
3. 情绪氛围是否保留？
4. 是否还有残留的违禁表述？

## 角色标签映射规则

视频提示词中必须包含角色标签映射语句，确保人物一致性。

### 映射规则
1. 必须包含所有视频提示词中实际出现的角色
2. 没有出现的角色不能写在角色标签映射中
3. 每个角色必须匹配角色信息库中的设定
4. 角色名称必须前后统一，不能中途改名

### 映射语句模板

```text
角色映射：{角色A}= {外貌/服饰特征}，{角色B}= {外貌/服饰特征}
```

示例：
```text
角色映射：阿生=二十岁左右清瘦青年，穿粗麻短褐，眼神坚毅；族老=白发长须老者，穿兽皮短褂
```

### 映射检查
提示词中出现了几个人物？
映射中是否都包含了？
有没有映射了但画面里没有的人物？
每个人物的特征描述是否与角色卡一致？

## 输出自检机制（6项必检）

输出每个分镜提示词后，必须通过以下6项检查：

| 检查项 | 检查内容 | 通过标准 |
|---|---|---|
| ✅ 字段数校验 | 输出字段数量 | 必须且只能有规定字段数 |
| ✅ 引号校验 | 对话使用的引号 | 所有对话必须用中文引号，禁用英文引号 |
| ✅ 长度校验 | 视频提示词长度 | 控制在合理范围内（建议500字内） |
| ✅ 人物校验 | 出现的角色 | video_prompt中出现的角色必须100%映射角色信息 |
| ✅ 场景校验 | 场景信息完整性 | prompt必须包含原始场景核心信息 |
| ✅ 连贯校验 | 与上一镜的衔接 | video_prompt必须包含衔接前置内容 |

### 自检流程
1. 写完提示词后，先对照6项逐一检查
2. 发现问题立即修改，不要等到生成后再改
3. 连续分镜尤其要重点检查人物校验和连贯校验
4. 拿不准的地方宁可保守，不要冒险

## 提示词修复规则

当生成结果不好时，先判断问题：

人物漂移：

复用同一张角色参考图。
减少人物描述变化。
固定发型、服装、年龄、身份。
使用角色一致性反向词。

场景漂移：

回到场景卡。
固定 2-3 个关键道具。
固定时间段和光线。
删除过多新场景信息。

表演过度：

删除“崩溃、激烈、强烈爆发、极端情绪”等词。
加入“克制、轻微、停顿、几乎看不出来”。
把情绪写进动作细节。

画面太空：

增加具体道具。
增加空间细节。
增加角色动作。
明确景别和机位。

画面太乱：

删除多余形容词。
减少主体数量。
减少道具数量。
每个镜头只保留一个视觉重点。

AI 味太重：

增加真实生活细节。
降低过度电影化描述。
强调自然光和真实皮肤质感。
删除“高级、震撼、史诗”等空泛词。

## 提示词质量检查

写完提示词后检查：

是否能看出主体是谁？
是否能看出场景在哪里？
是否有明确动作？
是否有明确情绪、信息任务或卖点任务？
是否有景别和机位？
是否与视觉设定一致？
是否有反向词？
是否把文字内容留给后期处理？
是否没有塞入整部片的无关信息？

如果检查不过，先改提示词，不要直接生成。
