# 视觉设定

## 作用

这个文件负责建立 AI 短剧的“视觉圣经”，保证图片和视频在人物、场景、色调、镜头语言上保持统一。

AI 短剧最常见的问题不是单张图不好看，而是每个镜头都像来自不同作品。视觉设定的任务就是提前锁定画面规则，让后续提示词、参考图和视频生成都围绕同一个世界展开。

适用于：

用户准备生成参考图
用户需要角色一致性
用户需要产品、空间、活动、装置或知识画面的主体一致性
用户有多个时间线、状态变化或补充场景
用户生成素材后发现人物漂移
用户希望成片看起来统一、克制、有电影感

## 视觉设定输出顺序

建议按这个顺序建立：

1. 整体视觉方向
2. 主角、主体或核心对象卡
3. 配角、辅助对象或环境元素卡
4. 主场景卡
5. 补充场景卡
6. 时间线色彩策略
7. 镜头语言
8. 统一风格词
9. 反向词
10. 参考图生成计划

不要一上来就写单镜头提示词。先建立视觉设定，再把设定复用到每个镜头。

## 整体视觉方向

先用 3-5 个关键词定义作品气质。

示例：

```text
写实/概念化程度，核心场景类型，主色调，镜头气质，信息或情绪基调
```

常见方向：

现实主义生活短片
都市情绪片
国风意象短片
悬疑氛围短片
科幻概念短片
青春成长短片
商业概念广告片
产品功能概念片
空间展示片
活动回顾或预告片
知识科普可视化短片

整体方向要服务主题，不要只追求好看。

## 主角、主体或核心对象卡模板

这个模板用于锁定人物、产品、空间、活动装置、怪物、载具、道具或其他核心对象。不要每个镜头重新描述一套设定。

```text
姓名：
对象类型：
年龄：
身份：
功能/用途：
文化背景：
外貌特征：
形态/材质：
发型：
体型：
服装：
妆容：
情绪/信息基调：
表演方式：
当前状态：
变化前/变化后状态：
禁止变化：
```

填写建议：

人物写外貌、服装和表演；产品或对象写形态、材质、颜色、尺度和功能。
外观不要写得过于抽象，要有具体可见特征。
造型要简单、稳定、便于多镜头复用。
情绪或信息基调要明确，例如“紧张、克制、清晰、轻快、专业、疏离”。
表演或展示方式要写具体，例如“短暂停顿、缓慢转身、局部亮起、核心部件展开、视线变化”。
禁止变化要写清楚，例如“不要变成网红脸，不要换发色，不要突然浓妆”。

示例：

```text
姓名：主角 A
对象类型：人物
年龄：根据故事设定
身份：与故事主题相关的普通人物
功能/用途：推动故事或承载观众视角
文化背景：根据项目设定
外貌特征：普通但有辨识度，真实皮肤质感，符合人物经历
形态/材质：人物皮肤、服装和道具质感真实
发型：稳定、自然，便于多镜头复用
体型：偏瘦
服装：简单、稳定，符合身份和场景
妆容：自然，不抢戏
情绪/信息基调：与主题或信息目标一致，例如紧张、克制、期待、清晰、专业或疏离
表演方式：用停顿、眼神、手部动作、身体姿态表达，不依赖夸张表演
当前状态造型/外观：根据主场景和时间设定
变化前/变化后造型或状态：根据叙事、功能展示或信息递进设定
禁止变化：不要突然换脸，不要风格跳变，不要过度精致化
```

## 配角、辅助对象或环境元素卡模板

配角、辅助对象或环境元素不一定要像核心对象一样细，但反复出现的内容必须稳定。

```text
角色关系：
对象功能：
年龄：
身份：
外貌：
形态/材质：
服装：
生活痕迹：
性格气质：
对主角的态度：
表演方式：
禁止变化：
```

常见配角类型：

家人
伴侣
朋友
同事
陌生人
老师或学生
客户或合作方
未来/过去的同一个人
产品配件
空间标识
活动装置
信息屏幕
关键道具

写关键配角时，避免简单脸谱化。可以写：

```text
不是单纯冷漠或恶意，而是带有自己的处境、目标和表达方式。
```

写伴侣类角色时，避免偶像剧化。可以写：

```text
普通生活背景，真诚但不完美，表达方式平实。
```

## 场景卡模板

场景卡用于保证同一个空间反复出现时不漂移。

```text
场景名称：
场景类型：
时间：
空间大小：
生活层次：
主要道具：
光线：
色调：
氛围：
镜头可拍细节：
禁止元素：
```

填写建议：

“生活层次”很重要。普通居住空间、工作场所、公共空间、商业空间不能混乱。
道具要具体，例如手机、旧桌子、水杯、工具、标识物、屏幕设备。
禁止元素可以防止 AI 生成豪华房间、过度精致陈设或不符合故事的背景。

示例：

```text
场景名称：主场景
场景类型：根据故事选择，如卧室、办公室、车站、餐厅、街道、旧房间
时间：根据剧情设定
空间大小：符合人物身份和叙事需要
生活层次：与角色身份一致
主要道具：3-5 个能反复出现的关键道具
光线：符合时间和情绪
色调：冷灰蓝为主，局部暖光
氛围：与主题一致，例如安静、紧张、温暖、疏离或压迫
镜头可拍细节：道具、手部动作、光线变化、空间空缺、角色停顿
禁止元素：不要出现不符合人物身份、时代和场景层次的物品
```

## 风格卡模板

风格卡用于统一画面质感和镜头语言。

```text
写实程度：
镜头语言：
调色方向：
光线风格：
画面质感：
表演尺度：
节奏感：
参考类型：
禁止风格：
```

示例：

```text
写实程度：现实主义，接近生活流短片
镜头语言：中近景、特写、缓慢推进、少量静止镜头
调色方向：根据时间线区分，但整体保持统一
光线风格：自然弱光，室内灯光真实
画面质感：真实皮肤质感，普通生活细节，不过度磨皮
表演尺度：克制，情绪通过停顿和细节表达
节奏感：慢一点，留呼吸，不靠快速剪辑煽情
参考类型：根据项目选择，例如现实主义生活短片、产品概念片、空间展示片或科幻概念片
禁止风格：不要偶像剧滤镜，不要广告大片感，不要悬浮精致感
```

## 时间线色彩策略

如果作品有多个时间线、状态、空间或想象段落，必须区分色彩逻辑。

常用策略：

```text
基础段落：保持主色调和主光线，建立统一世界。
变化前/问题段落：色彩、光线或构图略弱，强调未完成、混乱或普通状态。
变化后/解决段落：色彩、光线或构图更清楚，但不要突然换风格。
想象/概念段落：可以更柔、更虚或更图形化，但必须和主风格有关联。
高潮/重点信息：对比略强，光线更集中，突出关键对象或关键动作。
结尾：回到主色调或视觉母题，留下记忆点。
```

注意：

色彩变化要有叙事理由。
不要每个补充段落都换一套色调。
回忆可以温暖，但不要把痛苦记忆拍成过度唯美。

## 镜头语言规则

根据用户水平，优先选择可控镜头。

新手优先：

静止镜头
缓慢推进
中景
近景
手部特写
背影
侧脸
道具特写

谨慎使用：

大幅运镜
环绕镜头
长时间连续动作
多人复杂调度
大场面
精确口型对白

短片常用可控镜头动作：

主角停在原地
手机屏幕亮起或暗下
主体轻微移动
道具被拿起或放下
热闹场合中的笑容变淡
旧物被拿起又放下
角色背影停在房间里

## 统一风格词模板

用于每个图片提示词前后复用。

```text
{项目类型}，{写实/风格化程度}，{核心场景或空间类型}，{镜头气质}，{材质或画面质感}，{光线风格}，{主色调}，{主体清楚}，{信息层级清楚}，{风格统一}
```

可以根据题材调整：

现实生活向：

```text
现实主义生活短片，日常生活空间，生活流，明确人物目标，克制表演，真实室内光线，具体生活细节，低饱和色调，情绪留白
```

悬疑氛围向：

```text
现实主义悬疑短片，低饱和色调，局部阴影，克制镜头，安静压迫感，真实空间，细节暗示，不夸张恐怖
```

科幻概念向：

```text
近未来现实主义，普通生活与轻科技结合，冷色调，简洁科技道具，克制表演，情绪优先，避免过度赛博朋克
```

产品/品牌向：

```text
清晰主体，真实材质，干净构图，明确使用场景，卖点可视化，光线稳定，品牌不过度抢戏，信息层级清楚
```

空间/活动向：

```text
空间动线清楚，入口和核心区域明确，真实人流或使用痕迹，光线统一，氛围可信，关键标识清楚但不杂乱
```

知识/科普向：

```text
概念对象清楚，示意关系明确，信息层级清晰，画面简洁，颜色区分有逻辑，避免装饰元素干扰理解
```

## 反向词模板

根据项目添加。

通用反向词：

```text
不要网红脸，不要夸张表情，不要过度磨皮，不要人物变脸，不要手部畸形，不要不符合剧情的豪华场景，不要卡通风，不要过度表演，不要偶像剧滤镜，不要广告大片感，不要不符合人物身份的室内陈设
```

现实生活题材反向词：

```text
不要把配角拍成单一反派，不要夸张争吵，不要强烈情绪爆发，不要过度苦情，不要脏乱卖惨，不要用表情替代叙事推进
```

投稿/交付作品反向词：

```text
不要拼贴感，不要风格跳变，不要角色突然换脸，不要无意义炫技，不要字幕过密，不要音乐压过情绪
```

## 参考图生成计划

参考图生成顺序：

1. 主角、主体或核心对象参考图
2. 关键状态、关键动作或关键情绪图
3. 变化前/变化后状态图，如需要
4. 关键配角图
5. 主场景图
6. 补充场景图
7. 关键道具或关键细节图
8. 片尾或最终记忆点图

每张参考图都要检查：

是否符合人物/主体卡
是否符合场景卡
是否符合色调策略
是否方便后续做视频
是否会造成角色漂移

如果主角、主体或核心对象参考图不稳定，不要继续做视频。

## 非人物项目补充字段

当项目主体不是人物时，补充：

```text
核心对象：
对象功能：
使用场景：
使用前状态：
使用后状态：
必须展示的细节：
禁止误画的细节：
品牌/标识处理：
```

示例方向：

产品：强调外形、材质、使用方式、卖点和尺度。
空间：强调动线、入口、核心区域、光线和人如何使用空间。
活动：强调地点、参与者、流程节点、核心体验和收尾记忆点。
知识科普：强调概念对象、示意图风格、信息层级和可读性。

## 角色一致性规则

保持角色一致时，重复使用：

同一张参考图
同一套发型
同一类服装
同一组身份描述
同一组情绪/信息基调
同一组反向词

不要每个镜头都换描述顺序和人物细节。

建议写法：

```text
同一位主角、主体或核心对象，身份/形态、外观特征、材质、服装或结构保持一致，质感真实，表达克制
```

避免写法：

```text
美丽女孩、年轻女性、漂亮女主、温柔女生
```

后者太泛，容易导致人物漂移。

## 场景一致性规则

重复场景必须保留：

空间大小
时间段
光线方向
主要道具
色调
社会层次

如果同一房间反复出现，提示词中反复写入 2-3 个固定道具。

示例：

```text
同一主场景，固定空间布局，固定 2-3 个关键道具，稳定时间段和光线方向
```

## 生成前检查

进入图片提示词或视频提示词前，确认：

主角、主体或核心对象是否已经定义清楚？
主角造型、主体外观或核心对象结构是否固定？
主场景是否明确？
不同时间线、状态或场景的色调是否有逻辑？
是否有统一风格词？
是否有反向词？
是否知道先生成哪些参考图？

如果没有，先补视觉设定。
