# 03 · 实操示例 · 从想法到就绪提示词包

> 两个完整走通的例子：
> **示例一（视频侧）**：一句话想法 → I2V 就绪提示词包
> **示例二（图片侧）**：一句话描述 → IMAGES.json 生图任务
> 看完这两篇，照葫芦画瓢即可。

---

# 示例一（视频侧）：EP04「后视镜惊瞥」

---

## 输入：用户的原始想法

> 「我想做一个镜头：林砚开车的时候，从后视镜里看到后座有人，但她明明没拉过人。要那种汗毛竖起来的感觉。」

---

## 步骤 1：采集原话（原样记录，不加工）

| 项 | 记录 |
|---|---|
| 要什么画面 | 林砚开车，后视镜里看到后座有人 |
| 情绪/氛围（用户原词） | 「汗毛竖起来的感觉」 |
| 硬性要求 | 车内场景；后视镜视角；她没拉过这个人 |
| 雷区 | （用户未提，按本剧默认：不出现正脸、不出现乱码文字） |

## 步骤 2：选模板

一句话想法 → **`user-prompt-planning`（步骤化规划）**。

## 步骤 3：执行优化（模板原生指令 + 四段结构产出）

```
# 任务：后视镜惊瞥

## 1. 角色与目标
本镜叙事任务：让观众与林砚同时发现"后座有人"，且此人不在任何乘客记录里。
情绪目标：不是 jump scare，是后颈发凉的"意识到"。

## 2. 背景与上下文
EP04 第 17 镜。前置镜头：林砚平稳驾驶（车内中景）。
本镜是 EP04 反转段的第一个信号镜，后面接"她不敢再看后视镜"。
参考图：挂 MB_SC_CARINT_九宫格母版 + EX_LINYAN 表情差分（惊恐格）。

## 3. 关键步骤
1. 静态状态：夜，车内，林砚双手握方向盘，目视前方，车窗外是流动的路灯光斑。
2. 变化：她的视线极缓地移向车内后视镜——在后视镜反射里，后座坐着一个穿深色衣服的人，低头不动。
3. 终止：她的视线猛地移回前方，握方向盘的手收紧，停住。

## 4. 输出要求
- 格式：ComfyUI 就绪提示词包（positive/negative/frames/params/notes）
- 风格：具体可视语言，不写"恐怖"二字，用画面让观众自己凉
- 约束：不写中文文字（后视镜反射里不出现字）；不写乘客正脸；动作 3 秒内完成；结尾必须有终止态
```

## 步骤 4：铁律注入（8 条逐过）

| # | 检查 | 结果 |
|---|---|---|
| 1 | 否定式 | ✅ 无（"没拉过人"是背景信息，不进提示词） |
| 2 | 抽象情绪 | ✅ 已落地：「汗毛竖立」→「视线猛地移回前方，手收紧」 |
| 3 | 中文文字 | ✅ 提示词里无文字需求；后视镜反射写"无文字" |
| 4 | 一镜一意图 | ✅ 单意图：发现后座有人 |
| 5 | 动作预算 | ✅ 3 秒：视线移动+回移+手收紧，能做完 |
| 6 | 参考图 | ✅ 文字不写林砚长相服装（挂图了）；乘客不写正脸（写"深色衣服，低头"） |
| 7 | 帧数 4n+1 | ✅ 72 帧 → 传 73 |
| 8 | 终止态 | ✅ "停住" |

## 步骤 5：组装就绪提示词包

```json
{
  "shot_id": "EP04-S17",
  "positive": "夜，车内驾驶座视角。一名女子双手握方向盘目视前方，车窗外路灯光斑向后流动。她的视线极缓地移向车内后视镜，后视镜反射中后座坐着一个穿深色衣服的人，低头不动，无文字。她的视线猛地移回前方，握方向盘的手收紧指节发白，停住。固定机位。机位固定不动。",
  "negative": "多余手指，畸形手，肢体变形，脸部崩坏，双眼不对称，多余人物，文字乱码，水印，logo，过度磨皮，换脸，五官漂移，清晰的人脸，正脸",
  "frames": 73,
  "params": {"steps": 24, "cfg": 5.0, "shift": 8.0, "sampler": "euler", "scheduler": "simple"},
  "notes": "首帧挂 MB_SC_CARINT_九宫格母版；乘客在后视镜反射中只出现低头剪影；动作预算 3s；G5（帧差≥0.30）G6（不出画）必过；若乘客反射被模型忽略，走 iterate 加'后视镜反射中清晰可见'重出"
}
```

## 步骤 6：交付登记

1. 上面这个 JSON 写进 `06_分镜与时间轴/SHOTS_EP04.json` 的 S17 位
2. 跑 `09_工具脚本/一键生成EP04.bat`
3. 质检 G5/G6；若「后视镜反射里没人」→ 用 `iterate` 模板迭代：「后视镜反射要清晰可见后座乘客」重出

---

## 这个例子展示了什么

1. **用户的「汗毛竖起来」没有丢失**——它被翻译成了具体的视线动作和手部特写，而不是一个无效的抽象词
2. **每步都有出处**——选模板有依据，过铁律有清单，产出有格式
3. **返工路径预埋**——notes 里写明了"如果反射里没人怎么办"

# 示例二（图片侧）：场景空镜「午夜加油站」关键帧

> 同一个 EP04 世界，这次不出视频，出**关键帧静帧**（后续要当 I2V 首帧用）。
> 六步 SOP 与示例一完全相同，差别只在**步骤 4（静态化）**和**步骤 5（IMAGES.json 格式）**。

## 输入：用户的原始想法

> 「画一个加油站，半夜的，林砚待会儿要开进去加油。要那种荒郊野外、破破烂烂的加油站，灯一闪一闪，没人。」

## 步骤 1：采集原话（原样记录，不加工）

| 项 | 记录 |
|---|---|
| 要什么画面 | 半夜加油站，破旧，灯一闪一闪，没人 |
| 情绪/氛围（用户原词） | 「荒郊野外」「破破烂烂」「一闪一闪」 |
| 硬性要求 | 空镜（无人物）；竖版；要当 I2V 首帧用 |
| 雷区 | 不出现现代化新加油站；不出现乱码招牌文字 |

## 步骤 2：选模板

一句话描述要画新图 → **`image-general-optimize`（通用自然语言优化）**。

## 步骤 3：执行优化（模板原生结构：3–6 句，每句一个维度）

模板直接产出（句1 主体+环境锚点 / 句2 光照+时间+配色 / 句3 氛围+风格 / 句4 材质 / 句5 构图）：

> 一座孤立的旧加油站立在荒野夜地里，顶棚铁皮锈蚀变形，两台老式加油机并排站在空地上，周围是齐腰荒草和远处黑漆漆的山影，看不到其他建筑。半夜，顶棚下一盏老旧日光灯管亮着，灯管两端发黑，光线昏黄，在水泥地面投下模糊的影子。画面安静冷清，带着被遗忘的破败感。2D 手绘动画风，平涂色块，干净线稿，硬边阴影。远景，平视，竖幅构图。

## 步骤 4：铁律注入（8 条逐过 + 图片差异项）

| # | 检查 | 结果 |
|---|---|---|
| 1 | 否定式 | ✅ 无（"看不到其他建筑"是画面事实，保留） |
| 2 | 抽象情绪 | ✅ 「荒郊野外」→「荒野、齐腰荒草、远处山影、没有其他建筑」 |
| 3 | 中文文字 | ✅ 不写招牌文字，负向词里加"文字，乱码，招牌文字" |
| 4 | 一镜一意图 | ✅ 单意图：孤立破旧加油站的夜 |
| 5 | **静态化（图片差异）** | ⚠️「灯一闪一闪」单帧表现不了 → 落成静态质感「老旧日光灯管，灯管两端发黑，光线昏黄」 |
| 6 | 参考图 | ✅ 本镜无人物，不涉及 |
| 7/8 | 帧数/终止态 | — 图片场景不适用 |
| + | **禁摄影术语（图片差异）** | ✅ 无 85mm/浅景深/体积光/电影级；光线用绘画语言「硬边阴影」 |

## 步骤 5：组装生图任务（IMAGES.json 格式）

```json
{
  "id": "EP04_SC_GASSTATION",
  "mode": "t2i",
  "prompt": "一座孤立的旧加油站立在荒野夜地里，顶棚铁皮锈蚀变形，两台老式加油机并排站在空地上，周围是齐腰荒草和远处黑漆漆的山影，看不到其他建筑。半夜，顶棚下一盏老旧日光灯管亮着，灯管两端发黑，光线昏黄，在水泥地面投下模糊的影子。画面安静冷清，带着被遗忘的破败感。2D手绘动画风，平涂色块，干净线稿，硬边阴影，低饱和暗色调，冷蓝夜空与昏黄灯光的对比。远景，平视，竖幅构图。",
  "negative": "文字，乱码，招牌文字，水印，logo，3D渲染，写实皮肤纹理，照片级材质，电影级，体积光，浅景深，模糊，噪点，多余人物，现代建筑，城市天际线，明亮 daylight",
  "width": 768,
  "height": 1152,
  "steps": 28,
  "cfg": 6.0,
  "seed": 0
}
```

## 步骤 6：交付登记

1. 上面这个 JSON 写进 `07_提示词与剧本/IMAGES.json` 的 `jobs` 数组
2. 跑 `09_工具脚本/一键生图.bat`（注意 bat 内旧路径 `源机器E盘灵异悬疑短剧_资产包` 已废弃，以本项目目录为准）
3. 出图落 `04_提示词/_本地生图/日期/`；质检：G1–G7 里图片相关项（无乱码/无人脸崩坏/画风 2D）不过 → 用 `image-iterate-general` 定向改

## 这个例子展示了什么

1. **「一闪一闪」没有硬写进提示词**——单帧表现不了动态，落成了"灯管两端发黑、光线昏黄"的静态质感。**用户的意图（灯老旧不稳定）保住了，只是换了单帧能承载的形式**
2. **图片侧和视频侧共用一套铁律**——只是第 5 条反过来用（静态化）、第 7/8 条不适用、多一条禁摄影术语
3. **负向词一半靠模板生成**——若走 `image-json-structured-optimize`，它的「约束.避免」段直接就是 negative 字段的料
