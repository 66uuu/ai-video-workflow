# 02 · 提示词写法（通用版，无固定风格）

> 适用于任何题材。**本文件不规定任何画风、色调、光线偏好。**
> 唯一目标：让模型稳定生成你要的画面。

---

## 一、两种提示词，别混

| 用途 | 写什么 | 绝对不能写 |
|---|---|---|
| **生图（t2i / i2i）** | 画面内容 + 风格 + 光线 + 镜头 | —— |
| **生视频（I2V）** | 只有运动：动作 + 声景 + 配乐 + 镜头 | 画风、长相、服装、姓名 |

原因：I2V 的第一帧图已经定死了画风和长相，文字再写一遍会和图打架 → 画风漂移、换脸。

---

## 二、生图提示词

### 2.1 结构（按需写，不必填满）

```
[主体] + [动作/状态] + [场景] + [风格] + [光线] + [镜头]
```

**风格这一段完全自由**，想写什么写什么：

| 想要 | 就写 |
|---|---|
| 照片级写实 | `photorealistic, natural light, 85mm, shallow depth of field` |
| 明亮通透 | `bright, airy, high key lighting, soft daylight, high saturation` |
| 厚涂插画 | `thick paint illustration, painterly brushwork` |
| 日系动画 | `anime style, cel shading, clean line art` |
| 3D 渲染 | `3d render, octane, subsurface scattering` |
| 黑白 | `black and white, high contrast, film grain` |
| 水彩 | `watercolor, soft edges, paper texture` |

**不写风格也可以**，模型会按内容自行判断。

### 2.2 不同题材的示例

**人像**

```
a young woman sitting by a window, looking down, soft morning light from the left,
photorealistic, 85mm, shallow depth of field
```

**产品**

```
a matte black wireless headphone on a white marble surface,
studio lighting, soft shadow, product photography, 100mm macro
```

**风景**

```
a mountain lake at sunrise, still water reflecting the peaks,
wide angle, 24mm, golden hour, high dynamic range
```

**动物**

```
a corgi running on grass, motion blur on legs, bright afternoon sun,
telephoto 200mm, shallow depth of field
```

**场景空镜**

```
an empty subway platform at night, fluorescent lights, wet floor reflections,
symmetrical one-point perspective, 24mm
```

### 2.3 挂参考图时

- **不要**在文字里重复参考图已经给出的长相/服装/颜色，会打架。
- 只写"要改变的部分"：换场景、换光线、换动作、换镜头。
- 权重：换场景 0.5 / 同场景换机位 0.75 / 只改表情 0.9。

### 2.4 负向词

只写**技术缺陷**，不要写风格偏好：

```
多余手指，畸形手，肢体变形，脸部崩坏，双眼不对称，
文字乱码，水印，logo，签名，过度磨皮
```

**不要写**"明亮、鲜艳、蓝天白云、阳光"这类词——它们会把画面主动压暗去色。除非你确实不要这些元素。

## 三、I2V 提示词

### 3.1 四段结构

```
动作 + 声景 + 配乐 + 镜头
```

四段用空格连起来，程序会自动在末尾追加"机位固定不动。"

### 3.2 动作段（最重要）

**写法：先静态 → 再一个变化 → 最后终止**

```
✅ 她站在台阶上，把手机贴在耳边等着，身体几乎不动。
   她缓慢地低下头，把手机往耳朵上贴紧一点，停住。

❌ 她走过整个画面（会出画，只剩空景）
❌ 她害怕地抬头，同时转身（两个动作，会扭曲）
```

要点：
- 一镜只做一个动作
- 用"缓慢地""极轻地"控制速度
- **结尾必须有"停住 / 停下 / 不动了"**

### 3.3 声景段

```
雨持续落在水泥台阶和铁皮雨棚上，远处有车驶过积水的声音。
```

模型不出声，但**声景会影响画面节奏**：写"雨持续落"画面更稳更慢；写"急促脚步"画面变快。

### 3.4 配乐段

```
无配乐。
```

或者写你想要的：

```
低沉的弦乐铺底。
```

**配乐是自由项**，没有统一要求。

### 3.5 镜头段

```
近景，85mm 中长焦，浅景深。
```

用真实摄影术语，模型对 `85mm`、`浅景深`、`微距` 有明确响应。

### 3.6 动作幅度与时长

| 级别 | 定义 | 适用 | 时长上限 |
|---|---|---|---|
| 极低 | 只有一个元素动（雨下、数字跳） | 道具特写、钩子镜 | 3s |
| 低 | 镜头微动，主体静止 | 人物特写、气氛镜 | 4s |
| 中 | 镜头动 + 主体动作 | 行走、对话、载客 | 4s |
| 高 | 快切、甩镜、动态模糊 | 打斗、惊吓 | 1.5s |

---

## 四、三条技术红线（与风格无关，必须遵守）

1. **帧数必须是 4n+1**（Wan2.2 硬要求）。脚本会自动处理，手改时别忘。
2. **挂了参考图就不要重复写长相/服装**——防换脸。
3. **一镜只做一个动作**——幅度按几秒内可完成来估。

## 五、批量生成防丢图

### 5.1 前缀编码

并行出图同秒完成会互相覆盖，文件名由提示词开头推导。**在提示词最前面加唯一编码**：

```
【P01】a matte black headphone on marble...
【P02】a corgi running on grass...
```

### 5.2 去水印产物顺序还原

擦除工具输出随机哈希名，**串行**执行后按修改时间重命名：

```bash
i=1; for f in $(ls -tr processed_image_*.png); do mv "$f" "目标名_${i}.png"; i=$((i+1)); done
```

---

## 六、一句话

**生图管"长什么样"，随便写；I2V 管"怎么动"，只写动作。**
风格从来不是必填项。
