# 00 · 通用工作链（图像 + 视频，不限于 AI 漫剧）

> **这份文档是通用的。** 它描述的是"本机 ComfyUI 出图 → 图生视频 → 拼接成片"这条管线本身，
> 和题材无关：AI 漫剧能用，产品图、人像、风景、动物、广告、课件、口播背景，都能用。
>
> 当前 `AI生成视频/` 这个包，**只是一个技能包（skill pack）**：完整工作流程 + 本地部署的工具与插件 + 工作日志。
> 它不再承载任何一部具体作品——早期的《夜路司机》剧集任务、改编设定与视频产物已全部清理，产物一律落在仓库之外的桌面文件夹。

## 二、通用层的四步

```
① 环境体检  →  ② 出图  →  ③ 图生视频  →  ④ 拼接
```

### ① 环境体检（第一次必做）

```
双击 11_本地工具接入指南\一键环境体检.bat
```

或命令行：

```bat
cd /d "<本包>\11_本地工具接入指南\bridge"
python selfcheck.py
```

看到 `✔ 环境就绪，可以直接开工` 就行。

### ② 出图（文生图 / 图生图）

```bat
cd /d "<本包>\11_本地工具接入指南\bridge"

:: 纯文生图
python nr_bridge.py t2i --prompt "你的提示词" --out "..\_产出"

:: 挂参考图（保脸 / 保产品外观）
python nr_bridge.py t2i --prompt "你的提示词" --ref "D:/ref.png" --ref-weight 0.5 --out "..\_产出"
```

### ③ 图生视频（I2V）

```bat
python nr_bridge.py i2v --image "D:/keyframe.png" --prompt "动作描述" --frames 49 --profile std --out "..\_产出"
```

`--frames 49` ≈ 2 秒 @24fps。脚本内部自动按 **4n+1** 提交，出片裁回精确帧数。

**要出多条，一定用批量入队，别一条一条跑**（实测快 3.2 倍）：

```python
import nr_bridge as nb
c = nb.Comfy()
wfs = [nb.build_i2v(img, p, 49, **nb.PROFILES["draft"]) for p in prompts]
c.run_many(wfs, r"<D盘>\产出", label=["S01", "S02", "S03"])
```

原因见 `04_速度与一致性优化.md`：逐条跑时，两条之间的空闲期 ComfyUI 会把模型卸掉，
下一条又从零加载（约 71 秒），24 条就是 28 分钟白等。

### ④ 拼接

通用层不内置拼接器（因为每部片子的规格不同）。两个选择：

- **简单拼接**：用 ffmpeg concat（命令见 `01_命令手册.md`）
- **按时间轴拼接**：用 `09_工具脚本/assemble_ep04.py`（漫剧实例里的实现，可照着改）

## 三、这套管线能做什么（举例）

| 题材 | 怎么做 |
|---|---|
| AI 漫剧 / 短剧 | 剧本 → 分镜 → 关键帧 → I2V → 拼接（就是当前这个包） |
| 产品展示视频 | 产品图 → 关键帧（换背景/换角度）→ I2V 做轻微推拉/旋转 → 拼接 |
| 人像动态 | 人像照片 → I2V 做呼吸/眨眼/微转头 |
| 风景空镜 | 文生图出景 → I2V 做云动/水波/光影变化 |
| 广告分镜 | 分镜表 → 逐镜出图 → 逐镜 I2V → 拼接 |
| 课件/口播背景 | 文生图出背景 → 可选 I2V 做缓慢运镜 |

**没有任何一步要求"必须是漫剧"。**
