# 03 · 套用到新项目（任意题材）

> 换题材不需要改工作链，只需要新建一个项目目录 + 一份镜表。
> 下面用一个**产品展示视频**做完整示例（非漫剧），照抄即可。

---

## 一、新建项目目录

```
<D盘>\我的项目\
├─ shots.json          ← 镜表（核心）
├─ timeline.json       ← 帧数（可选，不写就每镜固定 72 帧）
├─ keyframes\          ← 关键帧图
├─ video\              ← 生成的视频
└─ out\                ← 成片
```

---

## 二、写镜表 `shots.json`

```json
{
  "shots": [
    {
      "id": "S01",
      "keyframe": "S01.png",
      "prompt": "产品缓慢旋转 15 度，停住。轻微的金属摩擦声。无配乐。特写，100mm 微距，浅景深。"
    },
    {
      "id": "S02",
      "keyframe": "S02.png",
      "prompt": "一束光从左向右扫过产品表面，停住。环境安静。无配乐。中景，50mm。"
    },
    {
      "id": "S03",
      "keyframe": "S03.png",
      "prompt": "产品静止，背景的薄雾缓慢飘动。低频环境音。无配乐。全景，35mm。"
    }
  ]
}
```

**要点**
- `id` 补零（`S01` 不是 `S1`），保证排序
- `prompt` 只写运动，不写画风
- 每镜只做一个动作，结尾"停住"

## 三、出关键帧

### 方式 A：单张出（通用层）

```bat
cd /d "<本包>\11_本地工具接入指南\bridge"

python nr_bridge.py t2i --prompt "a matte black headphone on white marble, studio light, product photography, 100mm macro" --out "<D盘>\我的项目\keyframes"
```

### 方式 B：批量出（用 IMAGES.json）

把每镜的**生图提示词**写成任务单：

```json
{
  "jobs": [
    { "id": "S01", "mode": "t2i", "prompt": "【S01】a matte black headphone on white marble, studio light, 100mm macro" },
    { "id": "S02", "mode": "t2i", "prompt": "【S02】same headphone, side light raking across, dark background, 50mm" },
    { "id": "S03", "mode": "t2i", "prompt": "【S03】headphone on a desk with thin fog, wide shot, 35mm" }
  ]
}
```

```bat
cd /d "<本包>\09_工具脚本"
python gen_image.py --jobs "<D盘>\我的项目\images.json" --desktop
```

> 想让三张图的产品长得一样？第一张满意后，后两张挂 `--ref` 指向它，权重 0.6–0.75。

## 四、出视频

### 方式 A：逐镜（通用层）

```bat
cd /d "<本包>\11_本地工具接入指南\bridge"

python nr_bridge.py i2v ^
  --image "<D盘>\我的项目\keyframes\S01.png" ^
  --prompt "产品缓慢旋转 15 度，停住。轻微的金属摩擦声。无配乐。特写，100mm 微距，浅景深。" ^
  --frames 72 ^
  --out "<D盘>\我的项目\video"
```

### 方式 B：按镜表批量（通用业务脚本）

```bat
cd /d "<本包>\11_本地工具接入指南\bridge"

python example_business.py ^
  --shots "<D盘>\我的项目\shots.json" ^
  --keyframes "<D盘>\我的项目\keyframes" ^
  --out "<D盘>\我的项目\video"
```

如果写了 `timeline.json`，加上 `--frames "<D盘>\我的项目\timeline.json"` 就能按帧数出。

## 五、拼接

### 5.1 统一规格

```bat
cd /d "<D盘>\我的项目\video"

for %f in (*.mp4) do ffmpeg -y -i "%f" -vf "scale=1024:1536:flags=lanczos" -r 24 -c:v libx264 -pix_fmt yuv420p "norm_%f"
```

> 产品横屏就改成 `scale=1536:1024`；方形改 `1024:1024`。

### 5.2 生成列表并拼接

```bat
:: list.txt
file 'norm_S01.mp4'
file 'norm_S02.mp4'
file 'norm_S03.mp4'

ffmpeg -f concat -safe 0 -i list.txt -c copy "<D盘>\我的项目\out\成片.mp4"
```

## 六、质检

```bat
cd /d "<本包>\09_工具脚本"
python _qa_check.py "<D盘>\我的项目\video\S01.mp4"
```

看两个数：

| 指标 | 正常 | 异常处理 |
|---|---|---|
| 相邻帧差 | 0.3–2 | <0.3 几乎没动；>8 运动过猛 |
| 首末帧差 | ≥1.5 | 太小 = 动作没完成，加"停住" |

## 七、换题材时的差异点

| 题材 | 生图重点 | I2V 重点 |
|---|---|---|
| 产品 | 材质、光位、背景干净 | 缓慢旋转/推拉、光扫过 |
| 人像 | 光线方向、皮肤质感 | 呼吸、眨眼、微转头 |
| 风景 | 时间、天气、构图 | 云动、水波、光影变化 |
| 动物 | 动态姿态、毛发 | 轻微动作、尾巴/耳朵动 |
| 漫剧 | 角色一致性（挂参考图） | 一个叙事动作 + 停住 |

**唯一不变的是四步：出图 → I2V → 质检 → 拼接。**

## 八、从零到成片（命令汇总）

```bat

```

## 九、常见坑

| 坑 | 处理 |
|---|---|
| 人物/产品每张都不一样 | 挂参考图，权重 0.6–0.8 |
| 视频里主体走出画面 | 缩小动作幅度，别写"走过整个画面" |
| 动作没做完 | 结尾加"停住" |
| 画面几乎不动 | 给一个明确可见的变化（转头、光扫过） |
| 拼接后音画不同步 | 先统一帧率再 concat，别混用不同 fps |
| 文件名乱序 | 补零 `S01`–`S09` |

---

## 十、一句话

**新项目 = 新建一个文件夹 + 写一份 `shots.json`。工作链本身不用改。**
