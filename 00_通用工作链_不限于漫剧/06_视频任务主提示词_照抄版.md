# 06 · 视频任务主提示词（照抄版 v5）

> 用法：复制两条 `===` 之间全部内容 → 把【】填成你的任务（填不出写"未提供"）→ 整段发给 AI。
> 适用：任何图像/视频任务（漫剧、产品、人像、空镜、广告、课件），不限于漫剧。
> 设计来源：通用办公工作流 **v5** × 本包管线（体检→卡→出图→I2V→质检→拼接→交付）。
> v4 变化：新增**事实底座六块**与**指令卡层（K1–K6）**、撰写/审查分角色、卡级断言 **C1–C6**、质量门十维、交付包六件。
> v5 变化：指令层扩为**镜级指令库**（一镜一卡一对话、写审交替）、四种角色不混用、新增**章节型断言 B1–B8**。
>
> **成果落盘铁律**：本任务所有产物只写 `你的桌面\AI产物\YYYYMMDD_任务名\`（子目录 `图片/`、`视频/`、`成片/`、`日志/`），**不回写技能包目录**。
> **D 盘铁律**：成果、中间片、日志、缓存、模型**全部在 D 盘**；C 盘只放已安装程序本体与系统临时目录，**不得在 C 盘自建目录存产物**。

# 任务名称：【一句话，例：漫剧EP05 第1–8镜／产品A 15秒展示视频】

## 开工前 先选级别（我未说明就按 L2）
- **L1 试片**：1–3 镜、验参数/试提示词 → 只做第0步宪章、第1步交底（填能填的）、第2.5步的 K3/K4、第3步的 U2/U7/C2、第6步单步。
- **L2 常规**：一整集 / 一条广告片 → 第0–11步全程。
- **L3 交付**：对外交付、镜头数>8、要动已有成片、涉及报价合同 → 全程 + 关键数字双答一致性 + 六件交付包 + 人工终审。
- 若你判断该升级而我没提，先问我一句再开工。

## 第0步 项目宪章（不变量，任何一步都先对照）
1. 帧数必须 4n+1（Wan2.2 硬要求），不满足不入队。
2. 一镜一意图：一个镜头只做一件事，动作按秒预算。
3. I2V 提示词不写画风／长相／服装／姓名，身份由参考图承载。
4. 不写否定式、不写抽象情绪；画面文字写"留白，无文字"。
5. I2V 结尾必须有终止态（停住／停下／不动了）。
6. 文件命名唯一前缀，防并行覆盖。
7. 不虚报：没跑过的生成不写"已完成"；耗时与通过率未实测就标"未实测"。
8. 不替代：你只给指令与检查清单，不代跑本机软件、不代签验收结论。
【本任务特有条款：__】

## 第1步 交底（缺的写"未提供"，不许脑补）
- 题材与用途：【漫剧／产品展示／人像动态／风景空镜／广告／课件】
- 成片规格：分辨率【】；帧率【】；单镜时长【】；总时长【】；镜头数【】
- 已有资产：【角色锁定图路径／场景图／参考图／剧本／分镜表；没有写"未提供"】
- 管线状态：ComfyUI【已启动／未启动／未体检】；参数档【draft／std／其他】
- 红线：不可改的角色特征【】；不可出现的元素【】；合规要求【】
- 工具与路径：bridge 路径【】；输出目录【】；ffmpeg 位置【】
- 事实边界：以上未填即视为未提供。信息不足写"待补充：__"，并继续完成能做的部分。

## 第2步 澄清门（关键项没定，不准动手）
先列歧义清单：问题 → 影响哪一步 → 建议默认值。
- 关键项（必须我确认后才进入第2.5步）：成片时长与镜头数【】；画幅比例【16:9／9:16／1:1】；角色一致性来源【有无锁定图】。
- 非关键项（可写暂定假设）：风格【】；光线【】；是否配音/字幕/音乐【默认不做】。
- 格式：关键项未确认前，只输出问题清单，不写提示词、不排任务。

## 第2.5步 事实底座 + 指令卡（v5：一镜一卡一对话）
先填六块，缺的标【待补充】，不许自行编造：
1. 世界规则：【路径/摘要】
2. 角色锁定表：【角色名｜面部锚点｜三视图｜表情差分｜不可改特征｜音色】
3. 场景锁定表：【场景码｜主视觉｜九宫格机位｜本次复用哪一格】
4. 本集规格：【镜数｜总时长｜画幅｜帧率｜交付分辨率｜4n+1】
5. 本集风格变量：【光线/色温/质感，**每集自定，不设全局风格锚**】
6. 红线：【不可出现元素｜不可改特征｜平台合规】

然后按需写卡（每张卡五件套：角色 + 粘贴占位 + 编号问项≥3 + 输出形式 + 负面清单≥3）：
- K1 剧本卡 → 本集分场剧本
- K2 分镜卡 → 镜表（镜号/秒数/景别/机位/内容）
- K3 生图卡 → 每镜一段：`【画面】/【光影/镜头】/负向：`
- K4 I2V 卡 → 每镜一段：`【运镜】/【终止态】`，禁写长相/服装/姓名/画风
- K5 配音卡 → 台词 + 情绪/停顿标记（有对白才写）
- K6 合成卡 → 调色/溶解/字卡/混音参数（要交付才写）
规则：写完一镜立刻审一镜（审查角色只给"通过/待改 + 一句改法"），不留到整集再统一审。

## 第2.8步 提示词工程（阶段 0，写卡前先过一遍引擎）
- 走 `15_提示词工程_prompt-optimizer/01_从想法到提示词_SOP.md` 六步：采集原话 → 选模板 → 优化 → 过 8 条铁律 → 组装就绪提示词包。
- 视频镜用 `user-prompt-planning`（模糊想法）/ `user-prompt-professional`（太泛）/ `iterate`（定向改）；生图镜按图片侧 12 模板选。
- 产出五字段小包（positive / negative / frames / params / notes）后，再回填到 K3（生图卡）与 K4（I2V 卡）。
- 阶段 0 **不替代质量门**：G1–G7、U/C/B 断言照旧。

## 第3步 验收断言（每条必须有阈值和执行器，缺一列等于没写）
视频断言：
U1 镜头数 = 【】（计数｜实际值填__｜数文件/数CSV行）
U2 每镜帧数 4n+1 且 = 时间轴要求（数值｜逐镜实际值__｜`_qa_check.py <mp4> <帧数>`）
U3 每镜"关键帧 + I2V 片段 + 命名一致"三件套（存在性｜缺一即FAIL｜目录核对）
U4 人脸/身材漂移达标（指标｜NCC ≥【】｜`drift_check.py`）
U5 文件前缀唯一，无同秒覆盖（唯一性｜重复即FAIL｜文件名去重）
U6 成片时长与时间轴误差 ≤【建议0.3秒】（数值｜实际__｜ffprobe）
U7 真运动且主体不出画（指标｜相邻帧差≥0.30、首末≥1.5、边带≥首帧55%｜`_qa_check.py`）
U8 交付包齐全（清单｜成片+说明+时间轴+素材清单+验收单+卡包｜目录核对）

卡级断言（管"写没写对"）：
C1 事实底座六块有值或标【待补充】，无空白项（字段｜逐项核对）
C2 每镜 K3+K4 卡齐全（有对白加 K5）（存在性｜镜号逐行对）
C3 每张卡五件套齐（结构｜逐卡打勾）
C4 负面清单零违反：K4 无长相/服装/姓名/画风；全文无"电影级/震撼/首次/填补空白"（不含｜搜词）
C5 每张撰写卡有对应审查记录（存在性｜看卡包末尾）
C6 卡与镜表一一对应，镜号无缺/无多/无重（计数｜集合比对）

章节型断言（v5，管"一镜一卡跑起来的留痕"）：
B1 事实底座六块有值或标【待补充】（字段齐全｜逐项核对）
B2 每镜声明"对应问项：__"并逐条作答（存在性｜看卡开头）
B3 负面清单零违反：不写长相/服装/姓名/画风/抽象情绪，不写第二个运镜（不含｜搜词）
B4 每镜撰写与审查均留痕（存在性｜看卡包末尾）
B5 统一质控五维（事实/逻辑/对齐/表达/证据边界）全部作答（存在性｜逐维核对）
B6 证据三级标注齐全（一致性｜抽查10句）
B7 参考图与资产编号一一对应，无挂错、无一对多（一致性｜资产索引比对）
B8 帧数与时长配额 ±15%（数值｜ffprobe + 时间轴逐镜统计）

明确不做：【不配音／不加字幕／不改剧本／不重绘角色设定】
交付时每条都要填"实际值"，不许只写"已检查"。

## 第4步 工作链（每步带完成判据与验证方法）
S1 环境体检：输入=bridge/selfcheck.py（缺失就手工查 8188 与模型文件）；输出=就绪/缺失清单；完成判据=清单无"未知"项；验证=重跑或手工复核结果一致；交给S2=参数档
S2 指令卡：输入=事实底座+剧本/分镜；输出=K1–K6 适用卡+审查记录；完成判据=每镜 K3+K4 齐、C1–C6 全过；验证=对照宪章八条逐条过；交给S3=逐镜卡
S3 关键帧：输入=K3+参考图；输出=每镜 PNG；完成判据=张数=镜头数；验证=抽 3 张对提示词；交给S4=关键帧路径表
S4 图生视频：输入=关键帧+K4；输出=每镜片段；完成判据=帧数均 4n+1；验证=读文件帧数核对；交给S5=片段清单
S5 质检：输入=片段+drift报告；输出=合格/重做清单；完成判据=覆盖全部镜头；验证=抽 2 个不合格镜回查；交给S6=合格片段
S6 拼接：输入=合格片段+时间轴；输出=成片 mp4；完成判据=时长误差达标；验证=ffprobe 读时长比对；交给S7=成片
S7 交付打包：输入=成片+时间轴+说明+卡包；输出=六件交付包+验收单；完成判据=U8 齐全；验证=目录核对；最终去向=归档
执行规则：一次只做一个 S；S2 内部顺序固定（事实底座→K1→K2→每镜 K3/K4 写一镜审一镜→K5/K6）；每段按"①输出 ②判据逐条打勾 ③三项自检 ④下游衔接"回报；等我确认再进下一步。

## 第5步 一致性检查（动手前跑一次）
- 宪章 ↔ 卡：有无卡违反第0步八条（尤其 4n+1、一镜一意图、I2V 不写长相）？
- 验收 ↔ 工作链：U1–U8 / C1–C6 / B1–B8 是否每条都有 S 覆盖？有无 S 不服务任何断言？
- 工作链 ↔ 交底：每个 S 的输入是否都在"已有资产"里？缺的是否标"待补充"？
- 卡 ↔ 资产：卡里引用的参考图路径是否真实存在？场景码是否在场景锁定表里？
- L3 任务加双答：镜头数（数文件/数CSV）、总帧数（各镜之和/ffprobe）、总时长（时间轴/ffprobe）各算两次，不一致就列分歧，不许取平均。

## 第6步 执行七要素（每个 S 内部自查）
1) 输入边界：只用第1步给的资产，不引入未确认素材；
2) 前置检查：先列"本步需确认项"，缺失标"待补充"，不许猜；
3) 逻辑链：按【读卡 → 核对参考图与帧数 → 提交 → 收片质检】顺序推进；
4) 负面清单：K4 不写长相/服装/姓名/画风；不要一镜多动作；不要"电影级/震撼"；证据不足改"概括表述／标待复核"；
5) 输出格式：命名【镜头号_前缀】；输出目录【】；回报字段【】；
6) 语言风格：简体中文，先结论后依据，参数写具体数值；
7) 下游衔接：末尾写"本步为下一步准备了：__"。

## 第7步 质量门（十维，交付前逐条自查，随交付附上 + 三态裁定）
【事实】有无未执行却写成已完成？耗时/通过率是否实测？
【一致性】角色锁定图是否全程复用？I2V 是否重复描述长相？
【对齐】U1–U8 是否逐条通过？未通过的说明原因。
【表达】有无"电影级""震撼"等不可验收形容词？
【证据边界】结论是否标 ①实测 ②推断 ③待确认？
【格式】4n+1、前缀编码、目录、批处理 label 是否符合约定？
【断言】U1–U8 每行是否填了"实际值"？只写"已检查"视为未过。
【一致性·双答】镜头数/总帧数/总时长两路结果是否一致？不一致列分歧。
【交付】六件交付包是否齐全（成片/说明/时间轴/素材清单/验收单/卡包）？
【指令】C1–C6 是否逐条通过？每镜 K3/K4 是否有审查记录？B1–B8 是否有留痕？
**裁定：PASS（十维全过且断言全部实跑）/ CONCERNS（列注意项）/ FAIL（列硬伤与修法）**

## 第8步 收敛循环（不通过就补，不整批重跑）
列缺口 → 对应哪条 U/C → 补哪个 S → 只重做坏的部分 → 重跑第7步；最多 3 轮。3 轮未收敛：停止，输出"未解决项 + 建议人工处理方式"，不许凑合交付。
**错误压缩**：每次失败只写三件——一句原因 + 一条修法 + 影响哪条 U/C。同一个错误出现两次，必须换方法（换参数档/拆镜/换参考图），不许原样重试。

## 第9步 交接单（长项目每 3–5 步一次）
已完成（对应哪些 U/C）／未决（卡在哪、需要谁给什么）／下一步（S 编号+输入是否齐）／关键路径与版本／已排除的错误方向。

## 第10步 交付落地（片出来 ≠ 交付完成）
交付包六件，缺一件不算交付：
- `成片.mp4`（播放器能开、时长对）
- `交付说明.md`（规格／镜头表／素材来源／已知限制）
- `时间轴.csv`（帧数、时长、对应镜头）
- `素材清单.md`（关键帧与源文件路径，可复现）
- `验收单.md`（U1–U8 + C1–C6 + B1–B8 逐条：实际值 / PASS-FAIL / 原因）
- `提示词卡包.md`（K2–K6 定稿 + 审查记录，下一集可复用）
最后一步由我签收：机器断言只能证明"符合约定"，证明不了"好看"。

## 第11步 复盘与迭代
- 哪张卡无效：原表述 → 原因 → 下一版改法（回写 K3/K4 模板，不改单条提示词了事）
- 本机哪个参数档更快/更稳：数据 → 结论
- 踩坑：坑 → 原因 → 写进宪章的预防条款
- 沉淀为本提示词 v5 与本包资产库条目

## 初始化
收到后先不要执行。先输出：①任务理解（≤3句）；②**级别建议**（L1/L2/L3 + 理由一句）；③歧义清单（关键/非关键分列）；④**事实底座六块草案**（缺的标【待补充】）；⑤**卡清单**（本任务要写哪几张 K 卡）；⑥验收断言草案 U1–U8 + C1–C6 + B1–B8；⑦S1 执行计划。经我确认后再开始。
