## 四、升级路线（按"先能落地"排序）

### P0 · 本周就能做，不装任何模型

| # | 动作 | 怎么做 | 验收 |
|---|---|---|---|
| 1 | **卡包落地** | 按 `05` 的 G2.5，把 `P13` 的三件套升级成 K3/K4 五件套：补"编号问项 + 输出形式 + 负面清单"，每镜写完立刻跑审查卡 | C1–C6 全过；卡号 = 镜号 |
| 2 | **事实底座** | 给 EP05+ 建 `07_提示词与剧本/EPxx_事实底座.md`，六块照填（世界规则/角色/场景/规格/本集风格变量/红线） | 无空白项，缺的标【待补充】 |
| 3 | **重做清单自动化** | 在 `batch_local.py --collect` 末尾，把"相邻<0.30 / 首末<1.5 / 不在画 / NCC<0.70"自动写入 `重做清单.md` | 跑一集后自动生成清单 |
| 4 | **修环境** | 见第五节：前台/非沙箱启动 ComfyUI，先跑 `python -c "import av"` 探针 | `curl 127.0.0.1:8188/queue` 返回 JSON |

> P0 只改流程和文本，不动模型，不会让单集变慢。

### P1 · 装两个权重，提升清晰度与流畅度

| # | 动作 | 具体 | 预期收益 | 风险 |
|---|---|---|---|---|
| 1 | 超分 | 下 `4x-UltraSharp` 或 `realesrgan-x4plus` 放进 `models\upscale_models`；`assemble_ep04.py` 的缩放链从 lanczos 换成 ESRGAN | 512×768 → 1080×1920 细节更实，尤其脸和布料 | 增加合成耗时；需实测（`bench.py` 不测合成，手工计时） |
| 2 | 补帧 | 下 RIFE 权重放进 `models\frame_interpolation`，只对"动作顿"的镜头 24→48fps | 运镜更顺 | **会改帧数**，时间轴要按新帧率重算；不许全局开 |
| 3 | 首尾帧（可选） | 装 `ComfyUI-WanVideoStartEndFrames`（383 星），给"必须回到某姿态"的镜头指定尾帧 | 解决"动作没做完" | 与当前 GGUF 工作流兼容性**未验证**，先拿 1 镜试 |

### P2 · 架构级，等 P0/P1 稳定后再评估

1. **换底模**（SDXL / Qwen-Image）→ 才能用 PuLID/InstantID；必须先测显存与单张耗时。
2. **人脸相似度指标**：用已装的 `insightface` 算"生成脸 vs 锚点脸"余弦相似度，补上 drift_check 测不到的那一半。
3. **workflow 代码化**：用 ComfyUI-to-Python-Extension 固化工作流，减少 JSON 手改。
4. **多集编排**：借 MoneyPrinterTurbo 的"一条命令串全流程"思路，写一个 `make_episode.py`（K1→K6 串起来）。

## 六、怎么判断升级有没有效（别只看"感觉更好"）

| 指标 | 现在 | 升级后目标 | 怎么量 |
|---|---|---|---|
| 单集一次通过率 | 未统计 | 逐集记录，目标逐集上升 | PASS 镜数 / 总镜数 |
| NCC 末段均值 / 最低值 | 未统计 | 最低值 ≥ 0.70，均值上升 | `drift_check.py` |
| 重做镜数 | 未统计 | 下降 | `重做清单.md` 行数 |
| 单集成片耗时 | 有档位数据（draft 1.27s/帧等） | 不因流程升级而变慢 | `bench.py` + 手工计时 |
| 主观"能看"评分 | 人签收 | 人签收 | 交付验收单 |

> 升级的唯一标准是**上面至少两项变好，且没有一项明显变差**。
> 只增加步骤、不改善指标的改动，一律不做。

## 七、明确不建议做的事

| 不建议 | 原因 |
|---|---|
| 恢复"全局风格锚" | `P00` 已明确废除：它会把整部片压成同一种暗灰色 |
| 为了"更先进"换 HunyuanVideo / Wan2.1 官方全套 | 星数高不等于本机能跑；先 `bench.py` 测，再决定 |
| 同时上 AnimateDiff + Wan I2V 两条路线 | 功能重叠，维护成本翻倍 |
| 全局开补帧 | 改帧数会打乱时间轴，只在问题镜头局部用 |
| 现在装 PuLID/InstantID | 需 SDXL 底模，本机是 SD1.5；换底模是 P2 大改 |
| 上"素材混剪"式短视频工具 | 那是解说视频的玩法，不是分镜叙事漫剧 |
| 追 0 星新仓库当天上线 | 没有可验证内容，不能当依据 |
