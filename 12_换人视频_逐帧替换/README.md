# 12_换人视频_逐帧替换 —— 项目 README

> **给下一个 AI 的接手说明**。目标：把 8.15s 抖音跳舞视频里的人物，逐帧替换成用户提供的西装 2D 角色，**动作/表情/音乐全部保留不变**。

## 任务硬约束（用户原话，不可违反）

1. 「只是单纯替换人物，其他的一切都不要变。动作捕捉，神情、表情啊，及一些音乐卡点，全部都不变」
2. 用户所有漫剧一律 **高清 2D**，不许糊、不许写实/3D（见用户记忆铁律）

## 技术方案（已跑通的最终版 v5）

**本地 ComfyUI 逐帧 img2img + IP-Adapter**：

```
原视频 194 帧(752x560,24fps)
  → preprocess5.py：① 右下「AI创作 ID」块 matchTemplate(阈值0.4) + 左上「AI 生成」固定矩形 inpaint
                   ② 亮低饱和区域整件染海军蓝（v5：erode1次+MIN_AREA800+无兜底+掩膜>25%放弃）
                   ③ Haar 人脸检测排除染脸（放宽参数 1.05/3/minSize40）
                   ④ blur_map 在原帧上算（v4 在 inpaint 帧上算导致全片误判，勿再犯）
  → frameswap.py：每帧 = 原帧 VAEEncode 做 img2img 底图（锁姿势/机位/表情结构）
                  + IP-Adapter(plus_sd15, weight=0.9) 注入参考角色
                  + Counterfeit 2D 底模 + denoise=0.6（模糊帧自动降0.45）+ cfg=5.5
  → assemble.py：194 帧拼 24fps + 铺原视频音频（--hd 另出 2x 1504×1120 高清版）
```

## 参数结论（6 轮实测，勿再重复试错）

| denoise | weight | cfg | 结果 |
|---------|--------|-----|------|
| 0.70 | 0.85 | 6.0 | f090 大动态模糊帧幻觉出第二个人 ❌ |
| 0.55 | 1.00 | 6.0 | 无幻觉，但西装仍白、头发变黑 ❌ |
| 0.60 | 0.80 | 6.0 | 西装白（白睡衣锚在底图里，权重赢不了）❌ |
| 0.50 | 0.80 | 6.0 | v3染色底图：袖子仍白、f090 出现幻觉文字 ❌ |
| **0.60** | **0.90** | **5.5** | **v5染色底图：3帧全过 ✅ 现用** |
