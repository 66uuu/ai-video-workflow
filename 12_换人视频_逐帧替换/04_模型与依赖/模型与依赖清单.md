## 1. 新下载模型：Counterfeit-V2.5_pruned.safetensors（4.26GB）

| 项 | 内容 |
|----|------|
| 用途 | **2D 动漫 SD1.5 底模**，逐帧 img2img 的「画风底座」，保证成片高清 2D |

| 大小/校验 | 4,265,097,179 字节（4265097179） |

## 4. 换人管线速查（命令级）

```bash
# 0) 预处理（去水印+染蓝底图），产出 frames_tint3/
python preprocess3.py
# 1) 3 帧验证
python frameswap.py validate --ckpt Counterfeit-V2.5_pruned.safetensors --denoise 0.5 --weight 0.8
# 2) 全片 194 帧（约35分钟）
python frameswap.py all --ckpt Counterfeit-V2.5_pruned.safetensors --denoise 0.5 --weight 0.8
# 3) 拼回+铺原音频（--hd 另出 2x 高清版）
python assemble.py
python assemble.py --hd
```
