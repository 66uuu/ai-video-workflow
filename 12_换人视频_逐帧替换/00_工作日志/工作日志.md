# 换人视频任务 · 工作日志

**任务**：把微信短视频（8.15s 抖音跳舞视频）里的人物，替换成用户提供的西装 2D 角色。
**硬性要求**（用户明确）：只换人，其他一切不变 —— 动作、神情表情、音乐卡点全部保留。
**日期**：2026-10-18
**工作流**：本地 ComfyUI 逐帧换人（原帧 img2img 底图 + IP-Adapter 注入角色）→ 用户选定方案

## 参数实测记录（Counterfeit 2D 底模，v3→v5 共6轮）

**v5 结论**：denoise 0.6（比v3的0.5更能让提示词覆盖白袖子）+ weight 0.9（更锁参考角色脸）
+ cfg 5.5（压幻觉文字）+ 模糊帧（Laplacian方差<130，仅8帧）自动降 denoise 到 0.45。

## 踩坑记录
- ComfyUI LoadImage 只认 input 目录图 → 原帧必须先 upload_image()
- 上个任务残留的 Wan2.2 job 占卡 → /interrupt + /queue 清空
- **Bash 前台跑生成会被 120s 工具超时 SIGTERM**（服务端 job 还在跑）→ 长任务一律 run_in_background
- HF/civitai 502 → hf-mirror.com 可用（模型 API 404 要先查文件列表找对文件名）
- Counterfeit-V2.5 完整版 7.7GB 太大 → 用 _pruned 4.26GB，8G 显存实测可跑（9s/帧）
- **cv2.imread/imwrite 在中文路径下返回 None**（_验证产出 目录名含中文）→ np.fromfile+imdecode / imencode+tofile
- **cv2 5.0.0 移除了 CascadeClassifier** → 必须用 opencv-python-headless 4.11.0.86
- **blur_map 在 inpaint 后的帧上算** → 水印文字锐利边缘被抹掉，方差 254→109，全194帧误判模糊。
  必须在原帧上算（_fix_blurmap.py；v5 起 blur_map_pass 放在 watermark_pass 前）
- **venv（envs/default）sys.path 损坏**：不含自身 site-packages → import cv2 报 ModuleNotFoundError。
  包本身是好的，用 PYTHONPATH=...envs\default\Lib\site-packages 补上即可跑
- **v3/v4 染色管线 3 个 bug**（全片返工级别）：
  ① erode 2次+MIN_AREA1500 把细手臂/袖子连通域切碎 → f005 袖子大面积白；
  ② 小掩膜用 prev_keep 膨胀兜底 → f090/f145 盖出巨大蓝块；
  ③ 模糊大动态帧白睡衣连成片 → 整个人被染蓝。
  v5 修正：erode 1次+MIN_AREA800、删兜底、掩膜>画面25%放弃染色、Haar放宽(1.05/3/minSize40)
- **水印地图（实测，194帧）**：① 右下「AI创作 ID」块固定在 (548,500)；② 左上「AI 生成」标签固定
  x10-110 y12-51（固定矩形涂，不用匹配）；③ 左下/底部「抖音」logo 块会漂移+变形（matchTemplate
  小模板只中58/194帧）→ **放弃追它，3张验证帧实测被 img2img 重绘自然抹掉**，全片跑完需抽查
- 原视频人物穿白色睡衣+假发+搞笑眼镜+大胡子道具 → 换脸由 IP-Adapter+底图重绘自然处理
- **漂移抖音 ID 水印（v6 才发现，最严重）**：抖音块在 8 秒里从顶部→右侧→底部→左下→右下
  循环漂移，preprocess5 只处理了两个固定水印（右下AI创作+左上AI生成），漂移块没处理 →
  img2img denoise 0.6 把水印文字结构当内容锚住，重绘成幻觉乱码（MiniMax/KOBE/Hit.../0t da12
  等，全片约 20+ 帧）。负面提示词压不住（底图文字对比强，latent 锚定）。
  **修法**：写白字检测器（灰度>150+横条比例+面积+硬边梯度）扫全片 194 帧输出帧定位嫌疑帧，
  只在【顶部y<65/底部y>415/左下/右下】四个水印高发区 inpaint（中段是人物活动区，白手套/白睡衣
  不能碰，会伤动作）→ 45 帧嫌疑帧用 tint6 修补底图重跑（固定 seed=idx*7+1000）
- **f097 幻觉双主体**：denoise 0.6 把运动模糊人体（人物扑向镜头）解构成「站着的西装人+坐着的
  角色」两个主体 → 该帧单独降 denoise 0.5 + 换 seed 202 修复（s101/s303 仍有双主体）
- **f193 贴镜头崩坏**：人物扑近镜头，白睡衣袖子被染蓝+重绘成怪异大蓝块，左下还有水印乱码 →
  底图左下 inpaint + seed 303 修复
- **细抽样会漏帧**：25 帧抽样漏掉 f189/f190 的水印（mp4 抽帧才发现）→ 全量复查必须 4 张
  总览图（49帧/张）人眼过 + 检测器自动扫双保险
- **f145/f194 大蓝块（v6 顺带修）**：贴镜头/扭动帧白睡衣连片，染色掩膜盖出大蓝块被 img2img
  当实体 → tint6 底图 + 换 seed 缩小到可接受（f194 仍有小块蓝色，最后一帧一闪而过）
- **检测器误报**：2D 重绘的描边/床单褶皱/角色脸部梯度大，会骗过「硬边」标准 → 检测器只做
  初筛，必须人眼放大复核（_zoom_suspect/_zoom3）
- **Read 工具会缓存同名图片**：替换帧后重生的总览图可能显示旧内容 → 用 md5sum/单帧直读验证

## 已知偏差（拟向用户披露）
1. 逐帧 img2img 重绘：动作/机位/表情结构级保留，非逐像素复制；快速模糊帧由模型顺势重绘。
2. 全片会被 2D 化重绘（Counterfeit 风格），背景结构/光线保持，非原像素。
3. 大动态模糊帧（f085-f093 等）姿势跟随模糊团块，细节由模型补全。
4. f050 一帧右下水印模板未检出，交给 img2img 重绘兜底。
