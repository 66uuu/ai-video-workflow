# 03 · AI 如何连接本地工具（通信协议）

> 这一篇是"AI 连接本地工具"的实质内容。
> 看完你会明白：**AI 生成图片和视频，本质上就是发几个 HTTP 请求。**

---

## 一、全貌：一次生成要发五个请求

```
①  POST /upload/image      上传首帧（图生视频才需要）
②  POST /prompt            提交工作流 → 拿到 prompt_id
③  GET  /history/{id}      轮询，等 completed
④  GET  /view?filename=... 下载产出
⑤  （可选）GET /object_info 查节点是否存在
```

就这五个。**生图跳过 ①，其余一样。**

浏览器界面在做的事，和这五个请求完全等价。所以你的脚本可以完整替代人操作。

---

## 二、第一原则：绕代理

本机所有 `127.0.0.1` 请求必须绕代理，否则报：

```
upstream connect failed
10061
```

这两个错误**最容易误判**成"ComfyUI 没起来"。实际上服务好好跑着，是代理把 localhost 请求劫走了。

```python
import urllib.request
# 正确：空 ProxyHandler = 不用任何代理
opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))
```

```bat
:: curl 版
curl --noproxy "*" http://127.0.0.1:8188/queue
```

`requests` 版：

```python
requests.get(url, proxies={"http": None, "https": None})
```

（铁律 45）

## 三、五个端点逐个说

### 3.1 `POST /upload/image` —— 把首帧传进去

图生视频必须先让 ComfyUI 拿得到那张图。

**请求**：`multipart/form-data`

```
type=input
subfolder=NR_UPLOAD
overwrite=true
image=@首帧.png
```

**响应**：

```json
{ "name": "S01_ref.png", "subfolder": "NR_UPLOAD", "type": "input" }
```

**关键**：拿到的是 `name` + `subfolder`，`LoadImage` 节点要填的是**拼起来的相对路径**：

```json
"inputs": { "image": "NR_UPLOAD/S01_ref.png" }
```

**三个必踩的坑**：

| 坑 | 现象 |
|---|---|
| 文件名含中文 | HTTP 400 Bad Request |
| `LoadImage` 只写文件名不带子目录 | HTTP 400 或找不到图 |
| 用"复制到 input 目录"这土办法 | 换电脑必废（目录结构不同） |

所以 `nr_bridge.upload_image()` 做了两件事：**文件名净化成纯 ASCII** + **返回带子目录的完整相对名**。（铁律 66）

### 3.2 `POST /prompt` —— 提交工作流

**请求**：

```json
{
  "prompt": { 节点图 JSON },
  "client_id": "随便一个唯一字符串",
  "number": 0
}
```

- `prompt`：工作流（下一节详说）
- `number`：可选。**`0` = 插到队首，不传 = 排到队尾**。批量跑用队尾，调试用队首

**响应**：

```json
{
  "prompt_id": "74e87a84-9f40-4f11-8e6f-dcb6052d329c",
  "number": 19,
  "node_errors": {}
}
```

`node_errors` 非空 = 工作流校验失败，**必须当场抛错**，别等轮询等到超时。

最常见的 `node_errors`：

| 错误 | 原因 |
|---|---|
| `Required input is missing: format` | `SaveVideo.format` 传了 dict，得传字符串 `"mp4"` |
| `Value not in list` | 模型文件名写错，或者文件不在对应目录 |
| `Required input is missing: video` | `SaveVideo` 的 `video` 输入没接（它是 VIDEO 类型，得前置 `CreateVideo`） |

### 3.3 `GET /history/{prompt_id}` —— 轮询进度

**响应**（还没完成时是空对象 `{}`）：

```json
{
  "74e87a84-...": {
    "prompt": [ ... ],
    "outputs": {
      "21": {
        "images": [ { "filename": "...", "subfolder": "...", "type": "output" } ],
        "videos": [ { "filename": "NR_I2V_00001.mp4", "subfolder": "NR/I2V", "type": "output" } ]
      }
    },
    "status": { "status_str": "success", "completed": true }
  }
}
```

**判断完成的两个信号**（任一即可）：

```python
if entry["status"].get("completed") or entry.get("outputs"):
    → 完成
```

**判断失败的信号**：

```python
if entry["status"].get("status_str") == "error":
    → 看 status.messages 里的 execution_error
```

**轮询间隔**：3 秒。别更密——服务端每次都要序列化，密了拖慢它。

**超时**：121 帧 I2V 约 572 秒，`timeout_wait` 设 1800 秒留余量。

### 3.4 `GET /view?filename=&subfolder=&type=output` —— 下载产出

**这是二进制响应**，不是 JSON。

```python
url = "%s/view?filename=%s&subfolder=%s&type=%s" % (
    host, quote(filename), quote(subfolder), "output")
blob = http_get(url, raw=True)
open(dst, "wb").write(blob)
```

**一个坑**：`subfolder` 要 URL 编码（里面有 `/`）。

**另一个坑**：产出可能挂在三个不同的键下：

```python
for key in ("images", "videos", "gifs"):
```

不同保存节点写法不同：
- `SaveImage` → `images`
- `SaveVideo` → `videos`
- `SaveAnimatedWEBP` / `VHS` → `gifs`

**三个都试**，这是 `nr_bridge.fetch()` 做的事。

### 3.5 `GET /object_info` —— 查有哪些节点

返回**全部 1160 个节点**的定义，几 MB。所以只查一次，缓存。

用途：判断必需插件装没装。

```python
oi = http_get(host + "/object_info")
ok = "UnetLoaderGGUF" in oi     # GGUF 插件装了吗
```

`selfcheck.py` 的"必备节点"检查就是这个。

### 3.6 附赠两个

**`GET /queue`** —— 队列状态

```json
{
  "queue_running": [ [19, "prompt-id", {...}, {...}, [...]] ],
  "queue_pending": [ ... ]
}
```

`len(queue_running)` 和 `len(queue_pending)` 就是"运行中/等待中"。

**`GET /system_stats`** —— 显存

```json
{
  "devices": [
    { "name": "cuda:0 NVIDIA GeForce RTX 4060 Laptop GPU",
      "vram_total": 8585216000, "vram_free": 3100000000 }
  ]
}
```

## 四、工作流 JSON 的结构

这是唯一需要"懂"的东西。但其实规则只有两条。

### 规则一：每个节点是「类名 + 输入字典」

```json
{
  "4": {
    "class_type": "CheckpointLoaderSimple",
    "inputs": { "ckpt_name": "majicmixRealistic_v7.safetensors" }
  }
}
```

键 `"4"` 是节点 ID，随便起，只要唯一。`class_type` 必须是 `object_info` 里存在的节点名。

### 规则二：连线是 `["节点ID", 输出槽号]`

```json
{
  "3": {
    "class_type": "KSampler",
    "inputs": {
      "seed": 20261018,
      "steps": 28,
      "cfg": 7.0,
      "sampler_name": "dpmpp_2m",
      "scheduler": "karras",
      "denoise": 1.0,
      "model":   ["4", 0],     ← 取 4 号节点的第 0 个输出（MODEL）
      "positive":["6", 0],     ← 取 6 号节点的第 0 个输出（CONDITIONING）
      "negative":["7", 0],
      "latent_image": ["5", 0]
    }
  }
}
```

**就这两条。没有别的语法。**

槽号是节点输出口的顺序，从 0 开始。比如 `CheckpointLoaderSimple` 输出 `(MODEL, CLIP, VAE)`，所以：
- `["4", 0]` = MODEL
- `["4", 1]` = CLIP
- `["4", 2]` = VAE

### 生图工作流（8 节点，最小可用）

```json
{
  "4": { "class_type": "CheckpointLoaderSimple", "inputs": { "ckpt_name": "majicmixRealistic_v7.safetensors" } },
  "5": { "class_type": "EmptyLatentImage", "inputs": { "width": 512, "height": 768, "batch_size": 1 } },
  "6": { "class_type": "CLIPTextEncode", "inputs": { "text": "正向提示词", "clip": ["4", 1] } },
  "7": { "class_type": "CLIPTextEncode", "inputs": { "text": "低质量, 畸形, 水印", "clip": ["4", 1] } },
  "3": { "class_type": "KSampler",
         "inputs": { "seed": 20261018, "steps": 28, "cfg": 7.0,
                     "sampler_name": "dpmpp_2m", "scheduler": "karras", "denoise": 1.0,
                     "model": ["4", 0], "positive": ["6", 0],
                     "negative": ["7", 0], "latent_image": ["5", 0] } },
  "8": { "class_type": "VAEDecode", "inputs": { "samples": ["3", 0], "vae": ["4", 2] } },
  "9": { "class_type": "SaveImage", "inputs": { "images": ["8", 0], "filename_prefix": "NR/T2I" } }
}
```

### 出视频工作流（12 节点，Wan2.2）

```json
{
  "10": { "class_type": "UnetLoaderGGUF", "inputs": { "unet_name": "Wan2.2-TI2V-5B-Q5_K_M.gguf" } },
  "11": { "class_type": "CLIPLoaderGGUF", "inputs": { "clip_name": "umt5-xxl-encoder-Q4_K_M.gguf", "type": "wan" } },
  "12": { "class_type": "VAELoader", "inputs": { "vae_name": "wan2.2_vae.safetensors" } },
  "13": { "class_type": "ModelSamplingSD3", "inputs": { "model": ["10", 0], "shift": 8.0 } },

  "14": { "class_type": "CLIPTextEncode", "inputs": { "clip": ["11", 0], "text": "夜，一名女子缓慢抬头，停住。雨声持续。无配乐。近景，50mm。机位固定不动。" } },
  "15": { "class_type": "CLIPTextEncode", "inputs": { "clip": ["11", 0], "text": "镜头推近，镜头拉远，变焦，摇镜，换脸，字幕，水印" } },

  "16": { "class_type": "LoadImage", "inputs": { "image": "NR_UPLOAD/S01_ref.png" } },
  "17": { "class_type": "Wan22ImageToVideoLatent",
          "inputs": { "vae": ["12", 0], "width": 512, "height": 768,
                      "length": 73, "batch_size": 1, "start_image": ["16", 0] } },

  "18": { "class_type": "KSampler",
          "inputs": { "seed": 20261018, "steps": 24, "cfg": 5.0,
                      "sampler_name": "euler", "scheduler": "simple", "denoise": 1.0,
                      "model": ["13", 0], "positive": ["14", 0],
                      "negative": ["15", 0], "latent_image": ["17", 0] } },

  "19": { "class_type": "VAEDecode", "inputs": { "samples": ["18", 0], "vae": ["12", 0] } },
  "20": { "class_type": "CreateVideo", "inputs": { "images": ["19", 0], "fps": 24 } },
  "21": { "class_type": "SaveVideo",
          "inputs": { "video": ["20", 0], "filename_prefix": "NR/I2V", "format": "mp4" } }
}
```

### 三个必须记住的细节

**① `length: 73` 是给 72 帧用的**

Wan 要求 `4n+1`。目标 72 帧 → 生成 73 帧 → 出片后用 ffmpeg 裁回 72。

```python
def gen_len(frames):
    return ((frames - 1 + 3) // 4) * 4 + 1
```

不处理这个，拼接时必然卡顿。（铁律 52）

**② `"format": "mp4"` 必须是字符串**

它是动态下拉框（DynamicCombo）。传 dict 会被校验层吃掉，然后报：

```
SaveVideo.execute() missing 1 required positional argument: 'format'
```

（铁律 43）

**③ `SaveVideo` 的 `video` 输入是 VIDEO 类型**

不能直接接 `VAEDecode` 的 IMAGES。必须中间加 `CreateVideo`。

`SaveWEBM` 才直接吃 IMAGES。（铁律 48）

## 五、一次完整的往返（时序）

```
你的脚本                          ComfyUI
   │                                  │
   │── POST /upload/image ──────────→ │  存到 input/NR_UPLOAD/
   │←─ {"name":"S01_ref.png",...} ────│
   │                                  │
   │── POST /prompt ────────────────→ │  校验 → 入队
   │←─ {"prompt_id":"74e87a84-..."} ──│
   │                                  │  ┌── 加载模型 20s
   │                                  │  ├── 采样       │
   │── GET /history/74e87a84 ───────→ │  │   ~500s     │
   │←─ {} （还没好）───────────────────│  ├── VAE 解码   │
   │         …每 3 秒轮询一次…         │  └── 存 mp4     │
   │── GET /history/74e87a84 ───────→ │
   │←─ {"outputs":{"21":{"videos":[..]}}, "status":{"completed":true}}
   │                                  │
   │── GET /view?filename=... ──────→ │  读 output/
   │←─ (二进制 mp4) ───────────────────│
   │                                  │
   ▼ 落地到本地目录
```

**关键洞察**：`POST /prompt` 之后，**连接断开也不影响**。ComfyUI 自己把队列跑完。

这就是为什么 `batch_local.py --submit-only` 压完队列就能退出——任务已经在 ComfyUI 的内存队列里了，你的脚本死掉它也照跑。

**但**：如果 ComfyUI 重启，队列清空。所以压完队列不要重启服务。

## 六、`nr_bridge` 怎么封装这些

| 协议动作 | nr_bridge 方法 |
|---|---|
| 绕代理的 HTTP | `_http()` |
| 探测本地工具路径 | `resolve(cfg)` |
| `POST /prompt` | `Comfy.submit(wf, number=None)` |
| `GET /history` 轮询 | `Comfy.wait(pid)` |
| `GET /view` 下载 | `Comfy.fetch(entry, dst_dir)` |
| 提交+等待+下载 | `Comfy.run(wf, dst_dir)` ← **最常用** |
| `POST /upload/image` | `Comfy.upload_image(path)` |
| `GET /object_info` | `Comfy.has_nodes([...])` |
| `GET /queue` | `Comfy.queue()` |
| `GET /system_stats` | `Comfy.stats()` |
| 生图工作流 | `build_t2i(...)` / `build_t2i_ref(...)` |
| 出视频工作流 | `build_i2v(...)` |
| 4n+1 换算 | `gen_len(frames)` |

### 三十秒上手

```python
import sys
sys.path.insert(0, "11_本地工具接入指南/bridge")
from nr_bridge import Comfy, build_t2i, build_i2v

c = Comfy()

# 出一张图
files = c.run(build_t2i("1girl, portrait, photorealistic, natural light"), "out/")
print(files)   # ['out/NR_T2I_00001_.png']

# 用这张图出一段视频
nm = c.upload_image(files[0])
files2 = c.run(build_i2v(nm, "夜，她缓慢抬头，停住。雨声。无配乐。近景，50mm。", frames=72), "out/")
print(files2)  # ['out/NR_I2V_00001.mp4']
```

**不需要懂 ComfyUI 界面，不需要点任何东西。**

## 七、错误处理：三类要分开

```python
try:
    files = c.run(wf, "out/")
except RuntimeError as e:
    # ① 连不上 / 校验失败 / 执行出错
    print("工具侧问题：", e)
except TimeoutError as e:
    # ② 等太久（可能服务卡住，或帧数太大）
    print("超时：", e)
else:
    # ③ 成功但要检查产出数量
    if not files:
        print("跑完了但没拿到文件 —— 检查保存节点的 filename_prefix")
```

**第三类最容易被忽略**：任务显示成功，但 `outputs` 是空的。原因通常是保存节点的 `filename_prefix` 有非法字符，或保存节点本身没接上。

## 八、为什么这套写法换电脑不用改

| 会变的东西 | 怎么处理 |
|---|---|
| ComfyUI 装在哪 | `config.json` 里 `comfy.root: "auto"` 自动探测 |
| python 在哪 | `comfy.python: "auto"` 优先找 `<root>/venv/` |
| ffmpeg 在哪 | `ffmpeg: "auto"` 依次找 root / PATH / 常见位置 |
| 端口变了 | 改 `comfy.host` 一行 |
| 模型文件名不同 | 改 `config.json` 的 `models` 段 |
| 显卡不同 | 不用改，但要把帧数/分辨率降档 |

**代码一行不用动。** 这是设计目标。
