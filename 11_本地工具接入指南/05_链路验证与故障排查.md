## 第 1 级 · 服务活着

```bat
curl --noproxy "*" http://127.0.0.1:8188/queue
```

**期望**：

```json
{"queue_running": [], "queue_pending": []}
```

内容是什么不重要，**能返回 JSON 就说明 HTTP 层通了**。

### 失败说明什么

| 报错 | 含义 | 修法 |
|---|---|---|
| `upstream connect failed` | **几乎肯定是代理**，不是服务 | 加 `--noproxy "*"` |
| `Failed to connect to 127.0.0.1 port 8188` | 服务真没起 | 起 ComfyUI |
| `curl: (7) Couldn't connect` | 同上 | 同上 |

**第一个是最坑的**：服务明明跑着，报错却说连不上。原因是有全局代理把 localhost 劫走了。（铁律 45）

### 交叉验证（排除误判）

```bat
netstat -ano | findstr :8188
```

有 `LISTENING` 行 = 服务在跑。这时候如果 curl 还报连不上，**100% 是代理问题**。

### 缺了说明什么

| 缺什么 | 含义 | 修法 |
|---|---|---|
| `UnetLoaderGGUF` / `CLIPLoaderGGUF` | `ComfyUI-GGUF` 插件没装/没重启 | clone 插件 → pip 装依赖 → **重启 ComfyUI** |
| `IPAdapterAdvanced` / `IPAdapterModelLoader` | `ComfyUI_IPAdapter_plus` 没装 | 同上 |
| `NR_*` 四个 | 自研节点包没拷进 `custom_nodes` | 拷目录 → 重启 |
| `Wan22ImageToVideoLatent` / `CreateVideo` / `SaveVideo` | ComfyUI 版本太旧 | 升级 ComfyUI 到 0.3x |
| 全部缺失 | 服务连的是另一个 ComfyUI，或版本完全不兼容 | 查 `config.json` 的 host |

**注意**：`CreateVideo` / `SaveVideo` 是 ComfyUI 内置节点（0.3.x 才有），不需要装插件。缺了说明版本旧。

## 第 4 级 · 出视频

```bat
python nr_bridge.py i2v --image NR_T2I_00001_.png --prompt "夜，画面中的女子极轻地眨了一下眼睛，然后停住。雨声持续。无配乐。近景，50mm，浅景深。" --frames 16 --out .
```

**期望**：

```
首帧已上传：NR_UPLOAD/NR_T2I_00001_.png（目标 16 帧 → 生成 17 帧）
  … 62s
完成 62s
./NR_I2V_00001_.mp4
```

耗时 60–90 秒（16 帧 / 16 步）。

### 必看的一句话

```
目标 16 帧 → 生成 17 帧
```

这是 `4n+1` 换算在工作。**如果没有这句，或者显示生成 16 帧，说明换算没生效**——后面拼接必然卡顿。（铁律 52）

### 验证视频真的动了

不靠眼睛，用数：

```bat
python -c "
import sys; sys.path.insert(0,'.')
from nr_bridge import Comfy
import av, numpy as np
c = av.open('NR_I2V_00001_.mp4')
fr = [np.frombuffer(f.to_ndarray(format='gray').tobytes(), dtype=np.uint8) for f in c.decode(video=0)]
c.close()
print('帧数:', len(fr))
if len(fr) > 1:
    adj = np.mean([np.abs(fr[i+1].astype(float)-fr[i].astype(float)).mean() for i in range(len(fr)-1)])
    end = np.abs(fr[-1].astype(float)-fr[0].astype(float)).mean()
    print('相邻帧差: %.2f  (>=0.30 才算真运动)' % adj)
    print('首末帧差: %.2f  (>=1.5 才算动作完成)' % end)
"
```

**期望**：

```
帧数: 17
相邻帧差: 3.50  (>=0.30 才算真运动)
首末帧差: 8.20  (>=1.5 才算动作完成)
```

> 这个脚本要 `av`（PyAV）和 `numpy`，得用 ComfyUI 的 venv 跑：
> `源机器E盘ComfyUI\venv\Scripts\python.exe`

### 判读

| 数值 | 含义 |
|---|---|
| 相邻帧差 < 0.30 | 几乎没动 → 提示词里的动作太含糊 |
| 首末帧差 < 1.5 | 动作做了一半又回去了 → 加终止词"停住" |
| 两项都过 | ✅ 真的在动，且动作完成了 |

**为什么不能靠眼睛**：画面里的雨在动、光在闪，看着像在动，其实主体是静止的。必须算。

### 失败说明什么

| 报错 | 含义 | 修法 |
|---|---|---|
| `HTTP 400 @ /upload/image` | 图名含中文 / 路径不对 | 用 `upload_image()`，别手写 |
| `SaveVideo.execute() missing 'format'` | format 传了 dict | `build_i2v()` 已经处理，别手改 |
| `Required input is missing: video` | `SaveVideo` 没接 `CreateVideo` | 用 `build_i2v()` |
| `CUDA out of memory` | 帧数或分辨率太大 | 降到 16 帧 / 384×576 试 |
| 跑完但没文件 | 保存节点问题 | 检查 `outputs` 里有没有 `videos` 键 |

## 五、故障速查总表

| 现象 | 90% 的原因 | 一句话修法 |
|---|---|---|
| `upstream connect failed` | 代理 | `--noproxy "*"` |
| `comfyui.db.lock` | 已有实例在跑 | `netstat` 查 PID 后 kill |
| `No module named 'av'` | 用错 python | 换 `源机器E盘ComfyUI\venv\Scripts\python.exe` |
| `No module named 'google'` | **实为缺 protobuf** | `pip install protobuf sentencepiece` |
| `missing 'format'` | DynamicCombo 要字符串 | `"format": "mp4"` |
| `missing 'video'` | SaveVideo 要 VIDEO | 前置 `CreateVideo` |
| `HTTP 400 /upload/image` | 中文名或路径 | 用 `upload_image()` |
| 节点缺失 | 装完没重启 | 重启 ComfyUI |
| 排队卡住不动 | 前一任务 OOM 死了 | `GET /queue` 看，必要时 `/interrupt` |
| 队列突然清空 | 重启了 ComfyUI | 重新 submit，已完成自动跳过 |
| 视频乱序 | 文件名没补零 | `S01`–`S09` 必须补零 |
| 帧数差 3–4 帧 | 忘了 4n+1 裁切 | 检查 `trim_video()` 是否执行 |
