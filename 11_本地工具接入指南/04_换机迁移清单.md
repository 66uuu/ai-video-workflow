# 04 · 换机迁移清单

> 场景：把这个工作包拷到另一台电脑，让 AI 直接能接管生成。
> 按顺序做，每一步都有验证方法。**跳过任何一步都会在上线时炸。**

---

## 一、判断：三样必须在新机器上存在

| 必须 | 谁提供 | 多大 |
|---|---|---|
| **ComfyUI + 三个插件 + 七个模型** | **新机器自己装**（`02_下载与安装.md`） | 约 22–27GB |
| **接入层代码**（`bridge/` 目录） | **本工作包自带** | 40KB |
| **业务资产**（提示词/参考图/时间轴） | **本工作包自带** | 365MB |

**核心认知**：模型和程序**不随包走**（太大，且是标准组件）。包里带的是**怎么装、怎么连、怎么用**。

---

## 二、迁移五步

### 第 1 步 · 在新机器装好 ComfyUI（约 40 分钟，主要在下载）

完全按 `02_下载与安装_从零到能出图.md` 做。做完验证：

```bat
curl --noproxy "*" http://127.0.0.1:8188/queue
```

返回 JSON = 服务活着。

**这一步没做完，后面全部无意义。**

### 第 2 步 · 把工作包拷到新机器

整个 `夜路司机_全流程工作包_<日期>/` 拷过去。放哪都行，**但路径别含中文以外的奇怪字符**（空格可以，中文可以）。

建议：`<D盘>\夜路司机_全流程工作包\` 或 `源机器E盘夜路司机_全流程工作包\`

### 第 3 步 · 确认配置

打开 `11_本地工具接入指南/bridge/config.json`，**先别改**，直接体检：

```bat
cd /d <你的路径>\11_本地工具接入指南\bridge
python selfcheck.py
```

`auto` 会自动探测。**大概率直接就过了。**

如果报"ComfyUI 目录 没找到"，手动填：

```json
"comfy": {
  "root": "D:/ComfyUI_windows_portable/ComfyUI"
}
```

> 路径用**正斜杠** `/`，或双反斜杠 `\\`。单反斜杠是转义符，会出错。

### 第 4 步 · 按体检结果修

`selfcheck.py` 的每一项都是可行动的：

| 体检报什么 | 去做什么 |
|---|---|
| `✘ ComfyUI 目录` | 改 `config.json` 的 `comfy.root` |
| `✘ 服务连通` | 起 ComfyUI（`启动.bat` / `run_nvidia_gpu.bat`） |
| `! 显存 ...不够` | 降档：帧数 ≤60，分辨率 448×672 |
| `✘ 模型 xxx 缺` | 按 `02_下载与安装.md` 第三节下这个文件 |
| `✘ 必备节点 缺 UnetLoaderGGUF` | 装 `ComfyUI-GGUF` 插件，**装完必须重启 ComfyUI** |
| `✘ 必备节点 缺 IPAdapterAdvanced` | 装 `ComfyUI_IPAdapter_plus` |
| `✘ 必备节点 缺 NR_*` | 把 `ComfyUI-NightRoad` 拷进 `custom_nodes` |
| `! ffmpeg 没找到` | 放 `ffmpeg.exe` 到 ComfyUI 目录，或改 `config.json` 的 `ffmpeg` |

改完重跑 `selfcheck.py`，直到出现：

```
✔ 环境就绪，可以直接开工
```

### 第 5 步 · 端到端验证

```bat
python selfcheck.py --run
```

它会真出一张图、再用那张图出一段 16 帧视频。全过 = **链路通了**。

产物在 `<包目录>/_产出/selfcheck/`。

## 三、路径要改的地方（只有三处）

### 1. `bridge/config.json`

```json
"comfy": { "host": "...", "root": "auto", ... },
"ffmpeg": "auto",
"output_dir": "auto"
```

**通常全 `auto` 就行。**

### 2. 业务脚本里的资产路径

`09_工具脚本/batch_local.py` 这类脚本里有硬编码路径（本机是 `源机器E盘灵异悬疑短剧_资产包`）。换机要改：

```python
ROOT  = r"源机器E盘灵异悬疑短剧_资产包"      ← 改成新机器上的实际路径
COMFY = r"源机器E盘ComfyUI"
FFMPEG = r"源机器E盘ffmpeg_bin\ffmpeg.exe"
```

**或者更好的做法**：把 `09_工具脚本` 里的脚本改成读 `bridge/config.json`。

新写的业务脚本建议直接用 `bridge`：

```python
from nr_bridge import Comfy, build_i2v
c = Comfy()                               # 路径全自动
```

### 3. 提示词 JSON 里的图片引用

`SHOTS_EP04.json` 里的 `img` 字段是相对路径（`EP04/EP04_S01_报纸划痕_v01.png`），在 ComfyUI 的 input 目录下。用 `upload_image()` 上传就不依赖这个。

## 六、换机器后性能会变的三个数

| 参数 | 本机（4060 8GB） | 换机后怎么定 |
|---|---|---|
| 帧数 | 72 常用 / 121 上限 | 显存 12G+ 可常态用 121；6G 降到 48 |
| 分辨率 | 512×768 | 显存 <7G 降到 448×672 |
| 精度 | Q5_K_M | 显存 12G+ 可上 Q8；6G 用 Q4_K_M |

`selfcheck.py` 的显存那一行会直接给建议。

## 七、最容易出问题的三处

### 1. 忘了重启 ComfyUI

装插件后**必须重启**。不重启节点列表里就没有新节点。

`selfcheck.py` 报"缺 UnetLoaderGGUF"时，第一反应应该是"重启了吗"，而不是"没装上"。

### 2. 模型放错目录

新版 ComfyUI 的目录名和旧版不同：

| 模型类型 | 新版目录 | 旧版目录 |
|---|---|---|
| diffusion model / unet | `models/diffusion_models/` | `models/unet/` |
| text encoder | `models/text_encoders/` | `models/clip/` |

**两个都建上，文件放哪个都行** —— ComfyUI 都会扫。但 `selfcheck.py` 是按文件名递归搜的，所以放哪都能查到。

### 3. 代理

新机器如果装了 Clash / V2Ray 之类的全局代理，localhost 请求会被劫走。

```bat
:: 临时关掉验证
set NO_PROXY=127.0.0.1,localhost
```

`nr_bridge` 已经强制绕代理，不受影响。但如果用别的工具（比如直接 curl），记得加 `--noproxy '*'`。
