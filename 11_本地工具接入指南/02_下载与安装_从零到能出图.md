# 02 · 下载与安装（从零到能出图）

> 目标：一台干净电脑 → 能出图、能出视频，全程不花一分额度。
> 全部装 **E 盘**（或你最大的非系统盘）。C 盘一个字节都不落。

---

## 零、先确认你的机器行不行

| 项 | 最低 | 本机实测 | 说明 |
|---|---|---|---|
| 显卡 | **NVIDIA 6GB 以上** | RTX 4060 Laptop **8GB** | AMD/Intel 也能跑但慢很多，且报错难查 |
| 内存 | 16GB | 16GB | 低于 16G 会频繁换页 |
| 磁盘 | **30GB 空闲** | E 盘充足 | 模型 13.1GB + ComfyUI 自身 |
| 系统 | Win10 64 位 | Win11 | Linux/macOS 也可，路径改一下 |

**判定**：
- 8GB 显存 → 能跑 121 帧（贴上限），日常 72 帧更稳
- 6GB 显存 → 降到 448×672，帧数压到 60 以内
- 12GB+ → 宽裕，可上 Q8 精度

---

## 一、装 ComfyUI

### 方式 A：便携版（最省事，推荐新手）

去 **https://github.com/comfyanonymous/ComfyUI/releases** 下 `ComfyUI_windows_portable_nvidia.7z`。

解压到 `源机器E盘ComfyUI_windows_portable\`，里面长这样：

```
源机器E盘ComfyUI_windows_portable\
├── ComfyUI\               ← 主程序
├── python_embeded\        ← 内置 python
└── run_nvidia_gpu.bat     ← 双击启动
```

**便携版的好处**：python、torch、CUDA 全打包好了，不用自己配环境。

**注意**：便携版的实际模型目录是 `源机器E盘ComfyUI_windows_portable\ComfyUI\models\`，比手动版多一层。

### 方式 B：手动装（可控，本机用的这个）

```bat
:: 1) 设 pip 缓存到 E 盘（关键！默认写 C 盘，一次就涨 2.6G）
setx PIP_CACHE_DIR "源机器E盘pip_cache"

cd /d 源机器E盘
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

:: 2) 建独立 venv
python -m venv venv
venv\Scripts\python.exe -m pip install --upgrade pip

:: 3) 装 torch（CUDA 12.6）
venv\Scripts\python.exe -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126

:: 4) 装 ComfyUI 依赖
venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 验证装好了

```bat
cd /d 源机器E盘ComfyUI
venv\Scripts\python.exe main.py
```

看到 `Starting server` / `To see the GUI go to: http://127.0.0.1:8188` 就成了。

浏览器打开 `http://127.0.0.1:8188`，能看到节点界面就对了。

**先关掉它**，接着装插件和模型。

## 三、下模型（13.1GB，七个文件）

### 3.1 视频侧（Wan2.2 TI2V-5B，8.6GB）

**推荐用 GGUF 量化版**（8GB 卡唯一选择）。

| 文件 | 大小 | 放哪 | 下载 |
|---|---|---|---|
| `Wan2.2-TI2V-5B-Q5_K_M.gguf` | **3.81GB** | `models/diffusion_models/`（旧版叫 `unet/`） | [QuantStack/Wan2.2-TI2V-5B-GGUF](https://huggingface.co/QuantStack/Wan2.2-TI2V-5B-GGUF) |
| `umt5-xxl-encoder-Q4_K_M.gguf` | **3.43GB** | `models/text_encoders/`（旧版叫 `clip/`） | [city96/umt5-xxl-encoder-gguf](https://huggingface.co/city96/umt5-xxl-encoder-gguf) |
| `wan2.2_vae.safetensors` | **1.4GB** | `models/vae/` | [Comfy-Org/Wan_2.2_ComfyUI_Repackaged](https://huggingface.co/Comfy-Org/Wan_2.2_ComfyUI_Repackaged) → `split_files/vae/` |

下载命令（装了 `huggingface_hub` 的话）：

```bat
pip install "huggingface_hub[cli]"

huggingface-cli download QuantStack/Wan2.2-TI2V-5B-GGUF Wan2.2-TI2V-5B-Q5_K_M.gguf --local-dir 源机器E盘ComfyUI\models\diffusion_models

huggingface-cli download city96/umt5-xxl-encoder-gguf umt5-xxl-encoder-Q4_K_M.gguf --local-dir 源机器E盘ComfyUI\models\text_encoders
```

**量化档怎么选**：

| 档 | 大小 | 8GB 卡 |
|---|---|---|
| Q4_K_M | 3.43GB | 更省显存，画质掉一档 |
| **Q5_K_M** | **3.81GB** | ✅ **推荐，本机在用** |
| Q6_K | 4.21GB | 勉强 |
| Q8_0 | 5.40GB | ❌ 跑不动 |

**别下 fp16 版**（`wan2.2_ti2v_5B_fp16.safetensors`，约 10GB）—— 8GB 卡必炸。

### 3.2 生图侧（约 4.6GB）

| 文件 | 大小 | 放哪 | 下载 |
|---|---|---|---|
| `majicmixRealistic_v7.safetensors` | **2.0GB** | `models/checkpoints/` | [LiblibAI](https://www.liblib.art/) 或 [Civitai](https://civitai.com/) 搜 `majicmixRealistic` |
| `CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors` | **2.4GB** | `models/clip_vision/` | [laion/CLIP-ViT-H-14-laion2B-s32B-b79K](https://huggingface.co/laion/CLIP-ViT-H-14-laion2B-s32B-b79K) |
| `ip-adapter-plus_sd15.safetensors` | 98MB | `models/ipadapter/` | [h94/IP-Adapter](https://huggingface.co/h94/IP-Adapter) → `models/` |
| `ip-adapter-plus-face_sd15.safetensors` | 98MB | `models/ipadapter/` | 同上 |

**CLIP-ViT-H-14 文件名必须完全一致**（或改 `config.json` 里的 `models.clip_vision`）——代码按名字找文件。

### 3.3 建目录

```bat

```


## 四、启动服务

### 4.1 启动脚本

在 `源机器E盘ComfyUI\启动.bat`：

```bat
@echo off
chcp 65001 >nul
cd /d 源机器E盘ComfyUI
set PIP_CACHE_DIR=源机器E盘pip_cache

:: 清理残留进程（避免 comfyui.db.lock 报错）
for /f "tokens=5" %%a in ('netstat -ano ^| findstr :8188 ^| findstr LISTENING') do taskkill /PID %%a /F >nul 2>&1

venv\Scripts\python.exe main.py --auto-launch --listen 127.0.0.1 --port 8188
```

`--auto-launch` 会自动开浏览器。

**便携版**直接用 `run_nvidia_gpu.bat`。

### 4.2 两个启动坑

**坑一：`comfyui.db.lock` 报错**

这不是权限问题，是**已经有一个实例在跑**。

```bat
netstat -ano | findstr :8188
taskkill /PID <上面查到的pid> /F
```

**绝不改权限、绝不删库。**（铁律 44）

**坑二：后台启动失败**

不要用 `cmd /c start /b xxx.bat`。会起不来（进程被回收）。

要么双击，要么直接在终端前台跑：

```bat
源机器E盘ComfyUI\venv\Scripts\python.exe main.py --listen 127.0.0.1 --port 8188
```

## 五、验证：五级检查

### 第 1 级 · 服务活着

```bat
curl --noproxy "*" http://127.0.0.1:8188/queue
```

返回 JSON（哪怕 `{"queue_running":[],"queue_pending":[]}`）就对了。

> **`--noproxy "*"` 不能省。** 不绕过代理会报 `upstream connect failed` / `10061`，极容易误判成"服务没起来"。（铁律 45）

### 第 2 级 · 节点齐全

```bat
cd 11_本地工具接入指南\bridge
python nr_bridge.py nodes
```

期望：

```
✔ CheckpointLoaderSimple
✔ ...
✔ NR_SaveMP4

共 18 个，缺 0 个
```

缺 GGUF 节点 → 插件没装好；缺 `NR_*` → 自研节点包没拷进去。

### 第 3 级 · 一键体检

```bat
python selfcheck.py
```

这一条会把路径、服务、显存、7 个模型、18 个节点、ffmpeg 全查一遍，最后给结论：

```
✔ 环境就绪，可以直接开工
```

### 第 4 级 · 真出一张图

```bat
python nr_bridge.py t2i --prompt "1girl, solo, portrait, photorealistic, soft natural daylight" --out .
```

8 秒左右出一张 png。

### 第 5 级 · 真出一段视频

```bat
python nr_bridge.py i2v --image 刚才那张图.png --prompt "夜，画面中的人极轻地眨了一下眼睛，然后停住。雨声持续。无配乐。近景，50mm，浅景深。" --frames 16 --out .
```

60–90 秒出一段 mp4。

**五级全过 = 链路通了，可以开工。**

## 七、常见失败对照

| 现象 | 原因 | 修法 |
|---|---|---|
| `upstream connect failed` / `10061` | 没绕代理 | 加 `--noproxy '*'`；Python 里用空 ProxyHandler |
| `comfyui.db.lock` | 已有实例 | `netstat` 查 PID 后 taskkill |
| `No module named 'av'` | 用了非 ComfyUI 的 python | 换 `源机器E盘ComfyUI\venv\Scripts\python.exe` |
| `No module named 'google'` | **实为缺 protobuf** | `pip install protobuf sentencepiece` |
| `SaveVideo.execute() missing 'format'` | format 传了 dict | 传字符串 `"format": "mp4"` |
| HTTP 400 @ `/upload/image` | 图名含中文 / 缺子目录前缀 | 用 `nr_bridge.upload_image()`，它自动处理 |
| 节点列表没有 `UnetLoaderGGUF` | GGUF 插件没装或没重启 | 装完必须重启 ComfyUI |
| 模型找不到 | 放错目录 | 用 `selfcheck.py` 看它找哪个目录 |
| 显存 OOM | 121 帧 + Q5 贴上限 | 降到 72 帧 / 448×672 / Q4_K_M |
