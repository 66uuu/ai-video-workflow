# 环境清单与安装步骤

> 换机器、重装系统、或者想在这台机器上复现，看这一篇。
> **当前机器统一使用 D 盘，C 盘只保留程序本体。**

---

## 一、这台机器的硬约束（先看这个，决定能不能跑）

| 项 | 值 |
|---|---|
| GPU | **RTX 4060 Laptop 8GB**（常驻占用 0.9GB → 实际可用 **7.2GB**） |
| RAM | 16GB（可用约 11GB） |
| CPU | i5-12450H |
| 系统盘 | C 盘（余量要盯） |
| 工作盘 | D 盘（模型、ComfyUI、项目全在这） |

### 可行性判定（实测过的，不是估的）

| 组合 | 显存 | 可行 |
|---|---|---|
| SD1.5 + IPAdapter + ControlNet | 4.5GB | ✅ |
| SDXL 单跑 | 7GB | ⚠️ 勉强 |
| **SDXL 三件套** | 8.5GB | ❌ **必炸** |
| **Wan2.2 TI2V-5B Q5_K_M** | **6.4–7.3GB** | ✅ **实测可跑 121 帧** |
| Wan2.2 14B | — | ❌ |
| LTX / HunyuanVideo | — | ❌ |

**结论**：这台机器能跑的是 **SD1.5 生图 + Wan2.2 TI2V-5B 图生视频**。这两个够用了。

## 四、安装步骤

### 4.1 ComfyUI 本体

```bat
cd /d 源机器E盘
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
python -m venv venv
venv\Scripts\python.exe -m pip install --upgrade pip
venv\Scripts\python.exe -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
venv\Scripts\python.exe -m pip install -r requirements.txt
```

**pip 缓存必须指 E 盘**（默认会写 C 盘，实测一次就涨 2.6G）：

```bat
set PIP_CACHE_DIR=源机器E盘pip_cache
```

永久设：

```bat
setx PIP_CACHE_DIR "源机器E盘pip_cache"
```

### 4.2 插件

```bat
cd /d 源机器E盘ComfyUI\custom_nodes
git clone https://github.com/city96/ComfyUI-GGUF.git
git clone https://github.com/cubiq/ComfyUI_IPAdapter_plus.git
```

各装依赖：

```bat
cd ComfyUI-GGUF
源机器E盘ComfyUI\venv\Scripts\python.exe -m pip install -r requirements.txt

cd ..\ComfyUI_IPAdapter_plus
源机器E盘ComfyUI\venv\Scripts\python.exe -m pip install -r requirements.txt
```

**GGUF 插件必装的两个额外依赖**（不装会报 `No module named 'google'`，这个报错文案是误导的，实际缺的是 protobuf）：

```bat
源机器E盘ComfyUI\venv\Scripts\python.exe -m pip install protobuf sentencepiece
```

### 4.3 自研节点包

把 `09_工具脚本` 同级的 `ComfyUI-NightRoad` 整个目录拷到：

```
源机器E盘ComfyUI\custom_nodes\ComfyUI-NightRoad\
```

4 个节点：`NR_KenBurns` / `NR_Still` / `NR_ShotInfo` / `NR_SaveMP4`。零模型零显存。

### 4.4 模型

按第三节表格放到对应目录。目录不存在的自己建：

```bat
cd /d 源机器E盘ComfyUI\models
mkdir diffusion_models text_encoders vae clip_vision ipadapter checkpoints
```

### 4.5 启动脚本

`源机器E盘ComfyUI\启动.bat`：

```bat
@echo off
chcp 65001 >nul
cd /d 源机器E盘ComfyUI
set PIP_CACHE_DIR=源机器E盘pip_cache

:: 清理残留进程（避免 comfyui.db.lock 报错）
for /f "tokens=5" %%a in ('netstat -ano ^| findstr :8188 ^| findstr LISTENING') do taskkill /PID %%a /F >nul 2>&1

venv\Scripts\python.exe main.py --auto-launch --listen 127.0.0.1 --port 8188
```

`--auto-launch` 会自动打开浏览器。

### 4.6 验证

```bat
:: 1) 服务在不在
curl --noproxy "*" http://127.0.0.1:8188/queue

:: 2) 节点数
curl --noproxy "*" http://127.0.0.1:8188/object_info -m 30 | python -c "import sys,json; print(len(json.load(sys.stdin)),'nodes')"

:: 3) 生图环境
源机器E盘ComfyUI\venv\Scripts\python.exe gen_image.py --probe

:: 4) torch 能不能用 GPU
源机器E盘ComfyUI\venv\Scripts\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

期望：队列返回 JSON、节点 1160、`--probe` 全绿、torch 打印 `True` 和显卡名。

只影响"生成剪映草稿"这一步，不影响生图/出片主链路。不装也能正常出片。

## 五、C 盘纪律（这条是硬要求）

用户盯 C 盘空间。所有安装/下载默认落 E 盘。

| 项 | 做法 |
|---|---|
| **pip 缓存** | `set PIP_CACHE_DIR=源机器E盘pip_cache` |
| ComfyUI 本体 | E 盘 |
| venv | E 盘（在 ComfyUI 目录内） |
| 模型 | E 盘 |
| 项目 | E 盘 |
| 临时文件 | E 盘（`_tmp_assemble`、`_生成产物`） |

### 清理 C 盘 pip 缓存的正确姿势

```bat
源机器E盘ComfyUI\venv\Scripts\python.exe -m pip cache dir   :: 先确认指向哪
源机器E盘ComfyUI\venv\Scripts\python.exe -m pip cache purge :: 只删下载副本
```

**只删下载的 wheel 副本，不影响任何已安装程序。** 实测清完 ComfyUI 照常可用。

### 禁区（绝不删）

- `C:\Users\<USER>\.workbuddy` —— WorkBuddy 本体 + Python/Node 运行时，删了软件跑不起来
- `C:\...\AppData\Local\Temp` —— 系统临时目录，让用户自己用 Windows「磁盘清理」

## 六、代理问题（本机特有）

**所有 localhost 请求必须绕代理**，否则报：

```
upstream connect failed
```

或

```
10061
```

这两个错误极容易被误判成"服务没起来"，实际上服务好好跑着，是代理抢了请求。

```bat
curl --noproxy "*" http://127.0.0.1:8188/queue
```

Python 里：

```python
import requests
requests.get("http://127.0.0.1:8188/queue", proxies={"http": None, "https": None})
```

或设环境变量：

```bat
set NO_PROXY=127.0.0.1,localhost
```

## 八、降级阶梯（万一 OOM）

一次只降一档，降完必须重跑质检——降太多画面会糊到不能用。

```
① batch 1（不要并行）
② 步数 30 → 24 → 20 → 15
③ 帧数 121 → 72 → 48 → 16
④ 分辨率 512×768 → 448×672 → 384×576 → 256×384
⑤ 精度 Q5_K_M → Q4_K_M
⑥ 模型 SDXL → SD1.5
⑦ tiled VAE
⑧ 逐张卸载
```

### 显存纪律

- 每张/段生成后**立即释放**，禁止队列跑整集（虽然实测 31 镜排队不 OOM，但保险）
- 每 5 单元 `nvidia-smi` 复核一次

```bat
nvidia-smi --query-gpu=memory.used,memory.total --format=csv
```
