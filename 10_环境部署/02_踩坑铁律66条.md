# 第一组 · 剧作与分镜（1–12）

### 1. 人物一致性：三件套先行
每角色先有「锚点 → 三视图 → 表情差分」，后续镜头一律挂锚点 i2i，**禁止文字重述脸**。

### 2. 五层提示词
风格锚（全剧固定）/ 不变量（脸发瞳标记）/ 服装变量 / 动作 / 环境镜头。
**服装必须是变量层** —— 写死在不变量里，换装就要重出所有资产。

### 3. 每镜三件套
生图 prompt + 生视频运镜 prompt + 特效叠加 prompt。缺一不可。

### 4. 中文文字一律留白
生图留白 → 擦净 → 后期人工贴字（全片强制）。
AI 出中文必是乱码，乱码在竖屏特写下极其明显。

### 5. 灵异实体：只给局部、永不露脸、单次 ≤1.5s
出脸即废弃（**不修补**）。EP60 出现 0 次。

### 6. 场景一致性
主视觉 → 九宫格机位 → 母版 → 后续镜头挂母版。每 10 集抽检。

### 7. 声音优先
预算 = 声音 > 特效 > 场景精度。「抽空」每集 1–2 次。

### 8. 剧本四级不得跳级
故事梗概 → 分集大纲（索引层）→ **分集细纲（执行层，六段节拍＋必说台词）** → 分镜脚本 → 切片提示词。
**禁止从大纲跳分镜。** 中间那层"她为什么来、带什么情绪"不在细纲里，分镜就只能靠猜。

### 9. 六段节拍固定
冷开场 3s → 情境 9s → 异变 23s → 规则触发 20s → 反转 20s → 新钩子 15s。
每集必有"看得见的"钩子，**禁旁白式自我解释**。

### 10. 一次性外景不新建母版
一律标【复用】，挂已有母版改置景。新建一次就是几百张图的工作量失控。

### 11. 去 AI 味台词六原则
① 句子不完整（省主语/断句/吞尾字）
② 有废话口癖
③ 情绪靠停顿气息不靠形容词
④ 不解释不总结不说教
⑤ 反问少陈述多
⑥ 重要角色每句 ≤15 字（**老周 ≤8 字**）

### 12. 导演主张"没看清"
恐怖来自信息差与克制，不是血浆与突脸。运镜以静为主（EP04 一半镜头固定，12/24），加速快切只留给第三幕。

# 第二组 · 资产与生图（13–23，63–66）

### 13. 风格靠图不靠字
生成一律带 `_资产锁定/A01_SC_NIGHTROAD_主视觉_v01.png` 作风格参考图。
**仅用于"从零新角色/新场景首图"** —— 锚点一旦存在，就不许再挂 A01（见 20）。

### 14. 规范跟随模型收敛
模型稳定输出与设定冲突 → **改设定文档，不反复重生成**。
已修两处：风衣米色 → 橄榄灰米色；及肩短发 → 黑色微卷中短发。

### 15. 锁定资产必须去水印
`buddy-image-processing erase`（先 `connect_cloud_service` 取 token，`PIP_CACHE_DIR=E:/pip_cache`）。
未采用候选留 `_生成产物/`，**不得与锁定资产混用**（会换脸）。

### 16. 批量生成用「提示词前缀编码法」
提示词最前面加唯一编码 `【PA1】`/`【E5S01】` → 文件名自动带编码，永不撞名。
**不要依赖 `output_dir`** —— 并行会串目录，同秒完成的图会互相覆盖，PNG 无元数据无法分辨，被覆盖的只能作废重做。

### 17. 去水印分组并行、组内串行
erase 输出名是随机哈希 `processed_image_<hash>.png` → 必须逐张提交后**立即 move 回原名**（天然保序）。
每组独立工作目录，起 N 个进程。16 张 4 组约 4 分钟（纯串行 16 分钟）。

### 18. 尺寸统一 1024×1536
九宫格 / 差分 / 差分板**一律 1024×1536**（与主视觉同比例，i2i 才不跑偏）。

### 19. 降保真度看的是"参考图 vs 目标图"
不是"目标图是否特殊"。
色温时段一致 → `high`；不一致（如 A10 白昼灰黄 vs A01 夜景）→ `medium`。

### 20. 角色设定板挂角色锚点，不挂 A01
锚点一旦存在，该角色三视图/差分/服装卡一律挂锚点。
**实测挂 A01 会多出设定外的雨水泥渍。**

### 21. `input_fidelity` 分级
- 只改表情、构图姿势完全不变 → `high`（阿鸡一次成功）
- **要改构图/姿势/机位 → `medium` + 提示词必须写构图基线**
  （如"腰部以上半身构图，双手自然垂放在身体两侧"）

白先生第一轮 4 枚全翻车，就是因为用 `high` 锁死了姿势。

### 22. "不给脸"角色禁用标准正面三视图
负向词对「三视图正面板」**完全无效**（连测 8 候选全翻车）。

唯一解法 = **背面系三视图（背面 / 四分之三背面 / 侧面）+ 伞撑开举过头顶遮脸**。
伞顶必须写到明确高度："**伞面完全遮住头部**"。
写"挡胸口到下颌" = 伞顶只到下巴，脸全露。

### 23. 接受收敛结果
背面锚点 + `high` 只能出背面，降 `medium` 仍出背面 → 该角色资产全是背面系，不要追打。
**稳定输出的边界就是设定的边界。**

### 63. 生图用英文，I2V 用中文
SD1.5 的文本编码器是 CLIP（英文好）；Wan 的编码器是 umt5（中文好）。
**两套编码器，别混。** 把中文提示词喂给 SD1.5，出来的东西完全不对路。

### 64. `ref_weight` 按用途分级，不凭感觉调
| 用途 | 权重 |
|---|---|
| 保脸 + 换场景 | **0.45–0.55** |
| 保脸 + 同场景换机位 | 0.70–0.80 |
| 只改表情（构图不变） | 0.85–0.90 |

**实测**：S13 要"档案库里的林砚"，权重 0.8 → 出来的是**雨夜街头**。参考图把整个场景一起搬过来了。降到 0.5 才对。
权重的本质是"我把多少决定权交给参考图"。换场景就是要把场景的决定权收回来。

### 65. SD1.5 对精确道具交互服从度差
要"双手拿着一张旧照片"，两轮都没画出手里的照片。

**对策：这类镜头不硬要，改导演方案。**
S13 已改：不给照片，只给她看照片时的脸 —— 更符合本片"没看清"的主张。

### 66. API 调 `LoadImage` 必须带子目录前缀 + 文件名不能含中文
两个都犯会 HTTP 400 Bad Request，而且报错信息不告诉你是哪个原因。

```python
# 错
p["10"] = {"class_type": "LoadImage", "inputs": {"image": "林砚锚点.png"}}

# 对
ref_name = "%s_ref.png" % shot_id              # 英文名
p["10"] = {"class_type": "LoadImage",
           "inputs": {"image": "LOCALIMG_REF/%s" % ref_name}}   # 带子目录
```

# 第三组 · 声音与镜面（24–38）

### 24. 抽空五种用法不可复用不说明
EP07 惊吓后没释放（物理）/ EP08 开口前的静默（预警）/ EP09 一句话落地后的空（信息冲击）/ EP11 期待之后的空 / EP12 认知崩塌。
**复用须写明"为什么这次用它"。**

### 25. "渐弱" ≠ "抽空"
- **抽空** = 全环境音**归零**（−∞）
- **渐弱** = 渐降至零

EP07 S23 / EP10 S22 / EP12 S24 都是渐弱，不是抽空。

### 26. 呼吸声 dB 校准
EP01 −28dB → EP60 −8dB（20dB / 55 集）。
EP05–07 每集 2dB；**EP08 起 ≤0.5dB**；EP20–40 降到 0.3dB。

**中段按 2dB 跳，EP40 就会盖过对白。**

### 27. 呼吸声"位置先于音量"
靠声像 / 混响干湿 / 高频衰减做距离，**不靠推 fader**。
越近 = 混响越干（<5%）、高频越全、声像贴耳。

推 fader 只会让呼吸"更大声"；改混响才会让呼吸"更近"。两个不同的感觉。

### 28. "移花接木"事不过三
EP06 / EP09 / EP11，**EP12 起废弃**。
改成「距离恒定 + 数量增加」：EP12 一道 → EP18 三道 → EP23 四道 → EP40 数不清。

### 29. 镜中影像清晰度降一档
清楚就是不对。EP12 起全剧执行。

### 30. 镜面延迟量化
EP12 = 4s → EP20 = 8s → EP30 = 20s → **EP41 镜中开始做现实没做过的事** → EP52 完全脱钩。
必须在**同一块镜面**内发生，禁分屏/PiP。EP41 前镜子只"慢"，不主动。

### 31. "举证镜"不得删
EP07 S19（双手都在方向盘、十指可见）。缺则整集垮掉。
此类镜在分镜表里标注"举证镜"。

### 32. "一次真安全"
EP10 S17/S18 必须真安全，不加低频预示不加音乐。
观众察觉是铺垫，第三次就不灵。

### 33. 伏笔贴字与周围笔触同源
EP06「别回头」与喷漆同笔触亮度密度（**第一遍看不清是设计要求**）。
EP09「砚」右半边先糊。EP32 与 EP59「砚/晚」字卡同源、水泡后皆可辨。

### 34. 中文/数字留白清单
寻人启事 / 里程 / 计价器 / 仪表灯位 / 站牌「13路」/ 涂鸦 / 讣告 / 笔记本字迹 / 录音笔时长。

### 35. 每集一红，且必须是叙事信号
EP05 平安符 / EP06 13路暗红站牌 #8B2E2E / EP07 不明红色指示灯 / EP08 信号灯红灯 / EP09 老周尾灯 / EP10 红笔圈 / EP11 录音笔红灯（**常亮不闪**，闪 = 报警）/ EP12 安全出口灯。

### 36. 推理不点破
只给数字让观众自己算（EP10 上车时间 = 死亡时间；EP11 6 小时录音 − 4 小时车）。
**算出来的才算数。**

### 37. 冲突要可信不要狗血
反派写"麻木"不写"恶意"。
EP04 档案员拦她，理由是"查这个没好处，我见多了"——不是坏，是见过的太多了。

### 38. 每集一句话导演阐述必须能独立成立
不含剧名、不含"讲述了一个…的故事"。

# 第四组 · ComfyUI 工程（43–50）

### 43. 动态下拉框在 API 里必须传字符串
`"format": "mp4"`。传 dict 会被校验层吃掉 →
`SaveVideo.execute() missing 1 required positional argument: 'format'`

### 44. `comfyui.db.lock` 报错 = 已有实例在跑
**不是权限问题。绝不改权限、不删库。**

```bat
netstat -ano | findstr :8188
taskkill /PID <pid> /F
```

### 45. 本机所有 localhost 请求必须绕代理
`--noproxy '*'`。否则 `upstream connect failed / 10061`，
**极易被误判成"服务没起来"** —— 实际服务好好跑着，是代理抢了请求。

### 46. 后台进程不要用 `( cmd & )` 或工具调用内的 `&`
调用结束即被杀。且**不要中途 taskkill 正在使用的服务**。

正确做法：托管后台直接跑 `venv\Scripts\python.exe main.py`。

### 47. 本机没有 ffprobe
（ffmpeg essentials 版没带）
校验视频用 PyAV `av.open` 或 `ffmpeg -i` 读 stderr。

### 48. `SaveVideo` 输入是 VIDEO，`SaveWEBM` 输入才是 IMAGE
`SaveVideo` 必须前置 `CreateVideo`。

### 49. 成片镜号必须补零
`S01`–`S24`。`dir /b` 是字符串排序，不补零必乱序。

### 50. 零模型也能出片，但只能叫技术验证
静帧 → KenBurns 帧序列 → mp4，8GB 跑满帧 1024×1536 零显存。
**但见 51：这条只算技术验证，不得当交付。**

# 第五组 · 视频管线（51–62）

### 51. 静帧 + KenBurns 永远不能叫成片
成片每一帧必须来自 `Wan22ImageToVideoLatent → KSampler`。
验收量化：**相邻帧差均值 ≥0.30、首末帧差 ≥1.5**，否则判滑片退回。

**用户原话**："你不要再给我生成那些毫无意义的烂片了。"

### 52. 帧数只有一个真源
生成帧数从 `EP04_timeline_v2.json` 读，向上取到 **4n+1**（Wan 要求），出片后用 ffmpeg 裁到精确帧数。
**禁止在生成脚本里手写 length。**

```python
def gen_len(frames):
    return ((frames - 1 + 3) // 4) * 4 + 1
```

### 53. 视频正文禁止写画风
（电影感 / 胶片颗粒 / 冷调）
画风由首帧图决定，写在生图提示词里；写进 I2V 正文会**逐镜打架**。后期 LUT/颗粒是可选项，不是统一要求。

### 54. 视频正文禁止写长相 / 服装 / 发色 / 姓名
外观 100% 交给首帧参考图。**文字与图竞争 = 换脸。**
只写「一名女子」「一名中年男子」这类通用身份。

**这条最反直觉** —— 越详细的描述，出来的越不像。

### 55. 只写几秒内做得完的大动作
缓慢抬头、抬手、放下、停住、走过前景。
**不写眨眼、重心转移、手指细动** —— 模型画不对，还会挤掉真正该演的那一下。

### 56. 一镜一个运镜 + 机位锁死句
正向必须固定追加：`机位固定不动。`
负向必须显式禁：`推近/拉远/变焦/摇镜/平移/构图漂移/人物出画/裁掉头部`

**实测不锁，5 秒内把人推出画。**

### 57. 动作幅度必须按秒数预算
2.5s 内只能"擦过前景"，不能"走过整个画面"。
实测：老周 5s 版本第 4 秒就出画，末帧只剩空停车场。

出画必须有叙事目的，否则算失误。

### 58. 表情由首帧决定，I2V 不改表情基调
每切按情绪从 `EX_<角色>_表情差分板` 选帧，用法是**先用差分重做该镜关键帧（i2i）**，再进 I2V。
**不是直接拿差分图当首帧**（构图会错）。

差分板做了不用 = 白做。

### 59. 声音三层各归各
① 台词/剧内音乐（角色听得见）写正文
② 声景（雨、脚步、衣料、喘息）单独成句
③ 配乐单独成句

**声景也是动作指令** —— 不写雨在落，雨就是静止贴图。

### 60. 占位素材不得进入任何交付版本
源图必须是该镜专属关键帧。

### 61. 同场同光归批
同场景 + 同光照的镜头共用同一张环境参考图，连续生成，跨批查色温。

### 62. 每切必须认领剧本节拍
`sceneIndex + beats:[起,止]`。
每个节拍恰好被一个切认领、按顺序、连续；认领台词的秒数 ≤ 该切秒数。

## 如果只记三条

**54** —— 视频提示词不写长相服装姓名（否则换脸）
**52** —— 帧数 4n+1，只有一个真源（否则卡顿）
**57** —— 动作按秒数预算（否则人出画）

这三条是最容易犯、代价最大、修起来最贵的。
