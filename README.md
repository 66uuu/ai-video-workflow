## 三十秒上手

1. 起 ComfyUI（`ComfyUI`，默认 `http://127.0.0.1:8188`）。
2. 体检：`python 11_本地工具接入指南\bridge\selfcheck.py`
3. 查命令：`00_通用工作链_不限于漫剧\01_命令手册.md`
4. 想复用管线做新题材：`00_通用工作链_不限于漫剧\README.md` + `02_工作流程\`

---

## 三条红线

1. **帧数 4n+1**（Wan2.2 硬要求，脚本已用 `gen_len()` 自动处理）。
2. **挂了参考图/首帧，提示词里就不写长相、服装、姓名、画风**，也不要写第二个运镜。
3. **一条提示词只写一个几秒内能做完的动作**，结尾给终止态（停住/不动了）。

## 专项技能调用

需要专项能力时，先检索 `13_专项技能库`，不要把 651 个技能全部读入上下文：

```powershell
python 13_专项技能库\skill_router.py search "人物一致性 图生视频" --video-only
python 13_专项技能库\skill_router.py search "产品广告 TVC" --video-only
```

检索后只读取命中的主技能和必要辅助技能。技能包副本位于 `13_专项技能库\原始技能库`，原桌面 `skills` 文件夹保留为源，不互相覆盖。

## 成果落盘铁律（每次任务都照这条做）

**本仓库是技能包，不是作品仓库。** 每完成一次任务，在桌面新建一个成果文件夹，产物只写那里：

```
你的桌面\AI产物\YYYYMMDD_任务名\
├─ 图片\     首帧 / 关键帧 / 资产图 / 参考图
├─ 视频\     单镜原片、中间片段
├─ 成片\     拼接/混音/字幕后的最终交付
└─ 日志\     批量日志、质检结果、审计报告
```

- 文件夹名用「日期_任务名」，任务名用中文短词（例：`20261024_产品A展示`）。
- 一个任务一个文件夹，不复用、不混放；下一次任务重新建。
- **任何产物都不许写回本仓库**（包括临时 `_raw_*.mp4`、日志、对比图）。
- 任务结束后只把**结论与踩坑**写进 `_logs/` 或工作日志，产物留在桌面成果夹。

### 配套铁律：一切落 D 盘，不碰 C 盘

- 成果、中间片、抽帧、日志、模型、缓存**全部在 D 盘**（桌面本身就在 `你的桌面`）。
- C 盘只允许放**已安装的程序本体**（如 `.trae-cn\skills\prompt-optimizer`、ffmpeg 的 WinGet 目录）和系统临时目录；这些不算"成果"，不复制、不搬运。
- 禁止在 C 盘 `C:\Users\...\AppData` 下自建目录长期存产物。
- 仓库在 `你的桌面\AI生成视频\`，ComfyUI 在 `ComfyUI\`，工具输出默认也指 D 盘（`config.json` 的 `output_dir` 已改为显式 D 盘路径）。

工具侧用环境变量指到成果夹（脚本已支持）。新项目建议先用 `new_episode.py --project-root` 创建独立项目目录，再把 `NR_PROJECT_ROOT` 指向它：

```powershell
$env:IMG_OUT_ROOT="你的桌面\AI产物\20261024_任务名\图片"     # gen_image.py
$env:I2V_RAW_DIR="你的桌面\AI产物\20261024_任务名\视频"      # batch_local.py 临时原片
$env:I2V_LOG_DIR="你的桌面\AI产物\20261024_任务名\日志"      # batch_local.py 批量日志
$env:NR_PROJECT_ROOT="你的桌面\AI产物\20261024_任务名"       # 时间轴/镜头包/首帧所属项目
```

> 说明：脚本默认不会把成片写回本技能包；未指定项目时会拒绝生成，或把默认成果放到 D 盘成果区并要求补齐项目文件。
