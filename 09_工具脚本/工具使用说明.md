## 一、`batch_local.py` —— 批量 I2V（主力）

### 它做什么

读 `SHOTS_EP04.json`（提示词）+ `EP04_timeline_v2.json`（帧数）→ 逐镜提交到 ComfyUI → 收片 → 自动质检。

### 参数

| 参数 | 作用 |
|---|---|
| **无参数** | **先全部入队，再依次收片**（推荐，快 3 倍以上） |
| **`--submit-only`** | 只压队列，立刻退出（压完可以关终端） |
| **`--collect`** | 只收片，读 `_submitted.json` 里的 prompt_id；收完自动写 `重做清单.md/json` |
| **`--qa-all`** | **不连 ComfyUI**，只把 `video_i2v` 现有原片全检一遍并写重做清单 |
| **`--qa-all --with-drift`** | 同上 + NCC 漂移（只对通过运动质检的片子跑，约 20 秒/条） |
| **`--redo`** | **按重做清单自动重跑所有 FAIL 镜**（自动 --force；缺首帧的会报出来并跳过） |
| `--only S13,S20A` | 只做指定镜（逗号分隔） |
| `--force` | 已存在的也重做 |
| `--list` | 只列清单，不执行 |
| `--seed 20261018` | 指定种子（默认 20261018） |
| **`--profile draft\|fast\|std\|hq`** | **参数档位**，见下表 |
| `--draft` | 等价于 `--profile draft`（旧用法保留） |
| `--steps 16` | 覆盖步数（0 = 用档位/镜表的值） |
| `--height 672` | 覆盖高度，宽度按 2:3 自动算（16 的倍数） |
| `--sampler uni_pc` | 覆盖采样器（euler / uni_pc / dpmpp_2m） |
| `--scheduler beta` | 覆盖调度器（simple / beta / karras） |
| `--max-frames 72` | 帧数上限，防止误跑 121 帧 |

| 档位 | 分辨率 | 步数 | 采样器 | 每帧 | 用途 |
|---|---|---|---|---|---|
| `draft` | 384×576 | 12 | euler / simple | 1.27 s（实测） | 试动作 |
| `fast` | 448×672 | 16 | uni_pc / beta | ≈2.3 s | 审片 |
| `std` | 512×768 | 20 | uni_pc / beta | ≈3.8 s | 正式 |
| `hq` | 512×768 | 28 | dpmpp_2m / karras | ≈5.3 s | 特写 |

### ★ 默认路径已经是「先全部入队」

旧版是 `submit → 等 → submit`，两条之间有空闲期，ComfyUI 会把模型卸掉，
下一条又从零加载。实测（13 帧）：逐条 88 秒/条，一次入队后第 2 条起只要 24–27 秒。

24 镜折算：**约 35 分钟 → 约 11 分钟**。这个优化不需要你加任何参数。

### 什么时候还用 `--submit-only`

想压完就关终端、过几小时再来收片时用。**压完队列后 ComfyUI 自己跑，跟脚本断不断开没关系。**

你可以在压完队列后关掉终端、关掉我、去做别的事。只要 ComfyUI 服务不关，它会把队列跑完。

事后来收：

```bat
ComfyUI\venv\Scripts\python.exe batch_local.py --collect
```

### 断点续跑

`video_i2v/S<id>_i2v.mp4` 已存在的自动跳过。

所以：
- 中途崩了 → 重跑 `--submit-only`，只提交剩下的
- 想重做某一镜 → `--only S13 --force`

### 输出怎么读

```
[S01] ⏭ 已收                         ← 之前就有了
[S03] ✅ 72帧 | 相邻0.58 | 首末6.16 | 在画   ← 成功且质检通过
[S16] … 还在排队/渲染                  ← 没完成
[S17] ❌ 帧数 68 不符 72               ← 失败，看原因
--------------------------------------------------------------------
已收 1 / 未完成 10 / 失败 0
```

那一行 `相邻X | 首末Y | 在画` 就是质检结果，不用另外跑脚本。

### 判读标准

| 数值 | 含义 | 处理 |
|---|---|---|
| 相邻 < 0.30 | 几乎没动 | 重写提示词，给一个明确可见的变化 |
| 相邻 0.3–2 | 正常 | ✅ |
| 相邻 > 8 | 运动剧烈，可能失稳 | 看一眼，可能人出画了 |
| 首末 < 1.5 | 动作没完成或回到原点 | 加终止词"停住" |
| 不在画 | 主体走出画面 | 缩小动作幅度 |

## 二、`assemble_ep04.py` —— 合成出片

### 参数

| 参数 | 作用 |
|---|---|
| 无参数 | 全片。**缺镜头则拒绝出正片**，只出预览 |
| `--allow-partial` | 缺镜头也拼（中途看效果用） |
| `--native` | 不放大，保持 512×768 |
| `--grade` | **整集统一调色**：提对比 1.07 / 压饱和 0.90 / 冷阴影 / 轻锐化 |
| `--xfade 0.20` | **镜头间溶解 0.2 秒**（默认硬切）。总长会缩短 `(镜数-1)×fade`，31 镜 × 0.2s = 6.0s |
| `--no-desktop` | 不打包到桌面 |

### 为什么要 `--grade`

逐镜单独调色会在切镜时"发色跳"。整集统一过一次，31 个镜头才连得住一条色。
滤镜链：`eq（对比/饱和/亮度）→ colorbalance（冷阴影）→ unsharp（轻锐化）`，都是轻量参数，不改内容。

### 为什么要 `--xfade`

硬切在短剧里显"廉价"。0.15–0.25 秒溶解最稳；超过 0.4 秒会拖节奏。
注意：溶解后**总时长变了**，挂音轨/字幕时要以新片长为准（`audio_mix.py`、`mux_audio.py` 都是现探时长的，不用手填）。

实测（EP04，31 镜）：`--grade --xfade 0.20` → 91.02s → **85.00s**，42.4MB。

### 它做四件事

1. 按时间轴顺序找 `video_i2v/<镜号>_i2v.mp4`
2. 逐镜规范化：1024×1536 / 24fps / yuv420p / 补静音轨 / lanczos 2×
3. 按顺序 concat
4. 打包到桌面

### 输出

```
桌面\夜路司机_EP04_交付_<日期>\
├─ 正片 mp4
├─ 分镜原片\        模型原始输出，未二次处理
├─ 时间轴 csv/json
├─ SHOTS_EP04.json
├─ EP04_提示词包.md
└─ 交付说明.md
```

**"分镜原片"必须留。** 一旦规范化+拼接，就无法回头判断"某镜糊是模型问题还是放大问题"。原片是唯一证据链。

## 三、`gen_image.py` —— 批量生图

### 参数

| 参数 | 作用 |
|---|---|
| `--jobs IMAGES.json` | 按任务单批量跑 |
| `--prompt "..."` | 单张跑（配合 `--ref`） |
| `--negative "..."` | 负向词（不填用默认） |
| `--width 768 --height 1152` | 尺寸（默认 768×1152） |
| `--steps 28` | 步数（默认 28） |
| `--seed 0` | 种子（0 = 随机） |
| `--ref <路径>` | 参考图（绝对路径，正斜杠） |
| `--ref-weight 0.8` | 参考图权重（默认 0.8） |
| `--desktop` | 出图后复制到桌面 |
| `--probe` | 只探测环境，不出图 |

### 两种用法

**批量（推荐）**：

```bat
ComfyUI\venv\Scripts\python.exe gen_image.py --jobs "IMAGES.json" --desktop
```

**单张试**：

```bat
ComfyUI\venv\Scripts\python.exe gen_image.py ^
  --prompt "【TEST】1girl, portrait, soft natural daylight, bright and airy, 85mm, shallow depth of field" ^
  --ref "../08_资产库/_资产锁定/M_LINYAN_面部锚点_v01.png" ^
  --ref-weight 0.5 --width 512 --height 768 --desktop
```

### 权重怎么选

| 用途 | 权重 |
|---|---|
| 保脸 + 换场景 | **0.45–0.55** |
| 保脸 + 同场景换机位 | 0.70–0.80 |
| 只改表情（构图不变） | 0.85–0.90 |

**踩过的坑**：要"档案库里的林砚"，权重 0.8 → 出来雨夜街头。参考图把场景一起搬过来了。降到 0.5 才对。

### 两个必须注意的

1. **参考图文件名不能含中文**，且 `LoadImage` 必须带子目录前缀（`LOCALIMG_REF/xxx_ref.png`）。不带会 HTTP 400。
2. **`id` 必须写在提示词最前面**（`【S13】...`）。并行出图同秒完成会互相覆盖，PNG 无元数据，被覆盖的图无法分辨只能重做。

## 四、`_qa_check.py` —— 质检

**必须用 ComfyUI 的 venv 跑**，因为要 `av`（PyAV）。受管 Python 没装。

```bat
ComfyUI\venv\Scripts\python.exe _qa_check.py <视频路径>
```

算两个数：

| 检查 | 判据 |
|---|---|
| G5 真运动 | 相邻帧差 ≥0.30 **且** 首末帧差 ≥1.5 |
| G6 出画 | 末帧左右边带方差 < 首帧 55% 判"出画" |

`batch_local.py --collect` 已经内置调用，一般不用单独跑。

**为什么不能靠眼睛**：画面里的雨在动、光在闪，看着像在动，其实主体是静止的。必须算。

## 六之三、`drift_check.py` —— 量"人脸身材有没有变"

Wan2.2 TI2V-5B 只"参考"首帧不"锁定"首帧，误差随帧数累积。
这个脚本逐帧和首帧做**位移对齐后的结构相似度（NCC）**，
测的是"变形"，不是"走动"，所以人走两步不会误报。

**必须用 ComfyUI 的 venv**（需要 `av`）：

```bat
ComfyUI\venv\Scripts\python.exe drift_check.py video_i2v\*.mp4
ComfyUI\venv\Scripts\python.exe drift_check.py 某片.mp4 -v   :: 逐段明细
ComfyUI\venv\Scripts\python.exe drift_check.py 某片.mp4 --fast :: 粗扫（搜索范围减半，快约 4 倍）
ComfyUI\venv\Scripts\python.exe drift_check.py 某片.mp4 --json :: 机器读（batch_local --with-drift 用）
```

```
文件                          帧数   末段NCC    ΔRGB   运动  判定
------------------------------------------------------------------
S03_i2v.mp4                    49    0.912      1.4   2.71  一致性好
S07_i2v.mp4                    49    0.641      5.8   4.02  主体变形 ←
```

| 末段 NCC | 结论 | 处理 |
|---|---|---|
| ≥ 0.85 | 一致性好 | 直接用 |
| 0.70 – 0.85 | 轻微漂移 | 短镜头可接受 |
| < 0.70 | 主体明显变形 | 重拍，或把帧数砍短 |

`ΔRGB` 持续单向增大 = 色调漂移；`运动` 接近 0 = 死片。
最后会列出"一致性最差的三条"，只重做这几条就行。

> 这不是人脸识别，测的是"主体结构相对首帧变了多少"，人物/产品/建筑都适用。

## 六之五、`audio_mix.py` —— 音效 / 抽空 / 响度（第 9 环）

配音挂上去之后还缺三样：环境底噪、设计音效、抽空。这个脚本一次补齐，**零外部音效素材**——
全部用 ffmpeg 内置信号源（`anoisesrc` / `sine` / `tremolo`）现合成。

```bat
python audio_mix.py ^
  --video "..\夜路司机别回头_EP04_正片_20261023.mp4" ^
  --voice "..\_产出\配音_EP04\voice_track.wav" ^
  --auto --timeline "..\06_分镜与时间轴\EP04_timeline_v2.json" ^
  --out "..\_产出\EP04_混音.mp4"
```

| 参数 | 作用 |
|---|---|
| `--video / --voice / --out` | 成片（只取画面，视频流不重编码）/ 配音 wav / 输出 |
| `--auto --timeline` | 按时间轴自动排：全程雨底 + 引擎低频 + S19/S22 各开 0.9s 抽空 + S17 耳鸣 + 片尾闷响 |
| `--cues cues.json` | 手排音效表（结构见文件头注释） |
| `--lufs -16 --tp -1.5` | 响度目标，默认 -16 LUFS / -1.5 dBTP |
| `--list` | 打印可用音效名（12 种） |

### 响度为什么要跑三遍

| 做法 | 实测结果 | 结论 |
|---|---|---|
| 单遍 `loudnorm` | -21.15 LUFS | 长静音段会欠冲，差 5 dB |
| 静态增益 + `alimiter` | -19.21 LUFS | 峰值被限幅器压回去 |
| **两遍 loudnorm + 残差 + alimiter** | **-16.87 LUFS / TP -1.39** | ✅ 达标 |

第三遍不是玄学：动态 loudnorm 自己也会欠冲 2–3 dB，所以**先预演一遍读它自报的
`output_i`，把差值用静态增益补足，再用 `alimiter` 钉住 TP**（只削瞬间峰值，不动平均响度）。
`linear=true` 只在"抬升量 < TP 余量"时才用，否则静态增益会被 TP 卡住。

### 抽空（voids）为什么比加声音有效

整条混音 `volume=0` 硬切 0.9 秒，观众耳朵会主动去找声音——比再叠一层音效更有压迫感。
实现是在 amix **之后**插入 `volume=volume=0:enable='between(t,a,b)'`，保证绝对静音。

### 两个必须知道的

1. **`-t <时长>` 不能去掉**：`apad` 会无限补静音，少了 `-t` 会写出 13GB 的 wav 直到磁盘满。
2. 脚本是**两段式**：先渲 `mix.wav` 量响度，再封装 mp4。中间产物在 `%TEMP%\nr_mix_*`，正常结束会自动删。

## 六之六、`card_gen.py` —— 规则字卡 / 标题卡（第 10 环）

PIL 排版 + ffmpeg 叠化，三种版式：`title`（片头大标题）/ `rule`（夜路规则卡）/ `sub`（片尾小字）。

```bat
python card_gen.py --video 正片.mp4 --cards cards.json --out 带字卡.mp4
python card_gen.py --video 正片.mp4 --title "夜路司机 第04集" --auto --out 带字卡.mp4
python card_gen.py --video 正片.mp4 --cards cards.json --out out.mp4 --no-jitter
```

`cards.json`：

```json
{"cards": [
  {"text": "夜路司机", "sub": "第一规则", "from": 0.4, "to": 3.2, "style": "title"},
  {"text": "后座有人说话\n不要回头", "from": 4.0, "to": 8.0, "style": "rule", "tag": "规则 01"}
]}
```

| 参数 | 作用 |
|---|---|
| `--cards` | 字卡表（`text` 支持 `\n` 换行） |
| `--auto --title "..."` | 自动排：片头标题 + 片尾"本片音画均为本地生成" |
| `--no-jitter` | 关掉 1–2px 的细微抖动（默认开，像手持/放映不稳） |
| `--fade 0.32` | 淡入淡出秒数 |
| `--crf 18` | 重编码质量（叠字必须重编码，无法 copy） |

**版式已固化的细节**：标题=黑条底(alpha 190)+白字+描边；规则卡=红顶线(198,42,38)+黑卡(alpha 150)+
tag 贴在卡上方；副标题=灰白小字。字号跟画面高度走（H×0.07 / 0.044 / 0.030），换分辨率不用改。

字体自动找 `msyhbd.ttc` → `msyh.ttc` → 苹方 → Noto CJK，也可 `--font` 指定。

## 六之七、`new_episode.py` —— 开新集骨架

开新集以前要手工复制文件、手算帧数。**帧数不满足 4n+1，Wan2.2 I2V 直接报错**，这个坑每次都会踩。

```bat
python new_episode.py EP05 --shots 08_资产库\EP05_镜表.csv
```

镜表 CSV 四列即可：`镜号,秒数,场景,景别,内容`（utf-8-sig）。也可以给 JSON。

产出：

```
06_分镜与时间轴/EP05_timeline_v2.json    ← 已按 4n+1 吸附、无空隙
06_分镜与时间轴/SHOTS_EP05.json          ← prompt 留空，待填四段式
08_资产库/EP05_关键帧/                    ← 目录建好
```

自检两条（不过就报错，不会静默出坏数据）：

```

✓ 时间轴无空隙  每镜 start == 上一镜 end
```

**镜号必须补零**（`S01`–`S09`），否则 `dir /b` 按字符串排序会乱序。

## 六之十、`gen_jianying_draft.py` —— 生成剪映草稿（可选终段）

把时间轴 + 各镜 mp4 + 配音 + SRT 自动组装成**剪映专业版可编辑草稿**。
在剪映里打开就是排好的多轨，可直接精修（调色、转场、特效、导出）。
**不替代**上面的 ffmpeg 出片，是并行的一条"人工精修"分支。

```bat
python gen_jianying_draft.py ^
  --timeline "..\06_分镜与时间轴\EP04_timeline_v2.json" ^
  --video-dir "..\video_i2v" ^
  --audio "..\_产出\配音_EP04\voice_track.wav" ^
  --srt "..\_产出\配音_EP04\voice_track.srt" ^
  --bgm "BGM.mp3"
```

| 参数 | 作用 |
|---|---|
| `--timeline` | 时间轴 JSON，读 `shots[]` 的 shot_id / duration / dialogue / speaker |
| `--video-dir` | 各镜素材目录，按 `shot_id` 自动匹配 mp4 / 图片 |
| `--audio` / `--bgm` | 整集配音 / 背景音乐（BGM 默认音量 0.3） |
| `--srt` | 有 SRT 就导入字幕轨；不传则用 `dialogue` 生成 |
| `--drafts` | 剪映草稿目录（不传自动探测本机） |
| `--dry-run` | 只打印组装计划，不写草稿 |

生成的轨道：

```
视频主轨 ← 各镜 mp4（按时间轴顺序）
字幕轨   ← SRT 或台词
配音轨   ← 整集配音
BGM 轨   ← 背景音乐（音量 0.3）
```

### 三个必须知道的

1. **依赖装在系统 Python**：`python -m pip install pyJianYingDraft`。不要用 ComfyUI 的 venv。
2. **只新建草稿，不改写已有草稿**：剪映 6+ 的 `draft_content.json` 加密，脚本不碰你的原工程。
3. **本机剪映 11.7 不能脚本自动导出**：pyJianYingDraft 的自动导出只支持剪映 6.8 及以下。
   草稿生成后需在剪映里手动点导出；要全自动出片继续用 `assemble_ep04.py`。

> 素材是本地绝对路径引用，草稿生成后别移动素材文件。

## 八、常见故障速查

| 现象 | 原因 | 修法 |
|---|---|---|
| `upstream connect failed` / `10061` | 没绕代理 | 加 `--noproxy '*'` |
| `comfyui.db.lock` 报错 | **已有实例在跑**，不是权限问题 | `netstat -ano \| findstr :8188` → `taskkill /PID x /F` |
| `No module named 'av'` | 用了受管 Python | 换 `ComfyUI\venv\Scripts\python.exe` |
| `No module named 'google'` | **报错文案误导，实为缺 protobuf** | `pip install protobuf sentencepiece` |
| `SaveVideo.execute() missing 'format'` | `format` 传了 dict | 传字符串 `"format": "mp4"` |
| HTTP 400 Bad Request | 参考图中文名 或 缺子目录前缀 | 改英文名 + `LOCALIMG_REF/` |
| 队列突然清空 | **重启了 ComfyUI** | 重新 `--submit-only`（已出的会自动跳过） |
| 后台进程起不来 | 用了 `cmd /c start /b` 或工具调用内的 `&` | 用托管后台直接跑 `venv/Scripts/python.exe main.py` |
| `av.error.PermissionError [Errno 13]`／`[WinError 5] 登录失败` | **ComfyUI 由后台任务/沙箱方式拉起**，写 `output`、`user` 全被拒 | 用 WMI 脱离启动（见 `01_命令手册.md`），起后跑一发探针确认能落盘 |
| `Filtering and streamcopy cannot be used together` | `-vf subtitles` 与 `-c:v copy` 同用 | 烧字幕时切 `libx264 -crf 18`（`mux_audio.py --burn` 已内置） |
| ffmpeg 写 mp4 报 `Permission denied` | **在后台任务里写非工作区目录** | 改前台执行；后台任务只做读和计算 |
| `No space left on device` | `apad` 没配 `-t`，wav 无限增长 | 加 `-t <时长>`；清 `%TEMP%\nr_mix_*` |
| 帧数差 3–4 帧 | 忘了 4n+1 裁切，或用了 `-t` 不是 `-frames:v` | 检查裁切命令 |
| 视频乱序 | 文件名没补零 | `S01`–`S09` 必须补零，`dir /b` 是字符串排序 |
| 响度怎么调都不到 -16 | 单遍 loudnorm / 静态增益 | 用 `audio_mix.py`（两遍 + 残差 + alimiter） |

## 九、完整的一次生产（照抄）

```bat
:: 0. 起服务
双击 ComfyUI\启动.bat

:: 1. 出关键帧
ComfyUI\venv\Scripts\python.exe gen_image.py --jobs IMAGES.json --desktop

:: 2. 改 SHOTS_EP04.json 写四段式提示词

:: 3. 压队列（压完可以关终端）
ComfyUI\venv\Scripts\python.exe batch_local.py --submit-only

:: 4. 等（约 5 分钟/镜，可以干别的）

:: 5. 收片 + 质检
ComfyUI\venv\Scripts\python.exe batch_local.py --collect

:: 6. 看不合格的，改提示词，--only 重做
ComfyUI\venv\Scripts\python.exe batch_local.py --only S16 --force

:: 7. 出片（统一调色 + 镜头间溶解）
ComfyUI\venv\Scripts\python.exe assemble_ep04.py --grade --xfade 0.20 --no-desktop

:: 8. 叠字卡（可选，片头标题 / 规则卡 / 片尾）
ComfyUI\venv\Scripts\python.exe card_gen.py --video 正片.mp4 --auto --title "夜路司机 第04集" --out 带字卡.mp4

:: 9. 配音（TTS，按时间轴算预算）
ComfyUI\venv\Scripts\python.exe tts_local.py --timeline ..\06_分镜与时间轴\EP04_timeline_v2.json --out ..\_产出\配音_EP04

:: 10. 挂音轨 + 烧字幕
ComfyUI\venv\Scripts\python.exe mux_audio.py --video 带字卡.mp4 --audio ..\_产出\配音_EP04\voice_track.wav --srt 字幕.srt --burn --out 有声.mp4

:: 11. 音效 / 抽空 / 响度
ComfyUI\venv\Scripts\python.exe audio_mix.py --video 有声.mp4 --voice ..\_产出\配音_EP04\voice_track.wav --auto --timeline ..\06_分镜与时间轴\EP04_timeline_v2.json --out 最终.mp4
```

**第 7–11 步可以一条命令跑完**：双击 `一键全链路出片.bat`（或 `一键全链路出片.bat EP05`）。
